## 1. 概要

ブックマーク自動取込のルールを作る・直す画面です。ルールは、起動時などに条件に合うブックマークを取込先と突き合わせ、追加・更新・削除を反映します。

上から「取込先 → ルール名 → 条件（取込元・フォルダ・名前・URL）→ このルールで取り込まれるもの → オプション設定（表示名）」の順に並びます。条件を変えると、すぐ下の一覧が変わります。入力欄は登録画面と同じく、左にラベル、右に欄を置きます。

名前と URL の条件は「その文字を含むもの」だけで、正規表現は使いません。

**キーボードショートカット**: Escape キーで閉じます（入力内容は破棄されます）。

## 4. 機能詳細

### 4.1. 取込元を選ぶ

- 開いた直後にインストール済みのブラウザを探す。新しく作るときは Chrome（無ければ見つかった最初のブラウザ）の最初のプロファイルを選ぶ。既存のルールを編集するときは保存されているプロファイルにする
- プロファイルは 1 つだけ選ぶ。複数のプロファイルから取り込みたいときは、プロファイルごとにルールを作る（全プロファイルを混ぜると、同じ名前のフォルダが 1 つにまとまり、どのプロファイルのものか分からなくなるため）
- 「すべてのプロファイル」や複数のプロファイルで保存されていたルールを編集で開くと、見つかった最初のプロファイル（無ければブラウザの最初のプロファイル）になる。そのときは「複数・すべてのプロファイルで保存されていたルールです。保存すると「〈プロファイル〉」だけになります」と知らせる
- 保存されていたプロファイルが見つからず最初のプロファイルに替わるときは、フォルダの選択も外す（プロファイルを選び替えたときと同じ）
- ブラウザ・プロファイルを変えるとフォルダの選択はクリアされる（フォルダの集合が変わるため）

### 4.2. フォルダを選ぶ

- フォルダを選ばなければ全フォルダが対象
- 選んだフォルダは、いつもサブフォルダも含めて扱う
- 「取り込む」は選んだフォルダの中だけ、「除いて、残りを取り込む」は選んだフォルダの外をすべて取り込む（あとから増えたフォルダも入る）

### 4.3. 絞り込む

- フォルダ・名前・URL の条件をすべて満たすブックマークが「このルールで取り込まれるもの」に並ぶ。自動取込の実行と同じ結果になる
- 名前・URL は入れた文字をそのまま含むかで比べる（大文字小文字を区別しない）。記号も文字どおりに比べる

### 4.4. 表示名を整える

- 表示名は、フォルダ名付与（「[フォルダ] 名前」の形）→ 頭に付ける文字 → 後ろに付ける文字の順。下の一覧にもそのまま出る
- 一番上のフォルダは、フォルダの木と同じく「ブックマーク バー」「その他のブックマーク」「モバイルのブックマーク」と付ける（例: フルパスなら「[ブックマーク バー/開発] 名前」。ブラウザ内部の名前 `bookmark_bar` などは出さない）。言葉は QDL の表示言語に合わせる。取り込み済みのアイテムも、次にルールを実行したときにこの名前に変わる。表示言語を切り替えたときも同じで、次の取込でこのフォルダを名前に付けたアイテムがすべて「更新」になる（仕様。2026-10-25 に決めた）

### 4.5. 取込先を選ぶ

- アプリ取込画面の [取込先を選ぶ](./app-import-modal.md#44-取込先を選ぶ) と同じ帯
- 新しく作るときの初期値は、最初のタブの先頭のデータファイル。編集のときは保存されている取込先
- 編集するルールの取込先がどのタブにも無いデータファイルなら、帯の代わりに「取込先」とそのファイル名、「（どのタブにも無いデータファイル）」「変更」を出す。フッターは「〈ファイル名〉に取り込む」になる。「変更」を押すまでは、そのファイルのまま保存する

### 4.6. 保存する

1. 取込先が新しいタブ・データファイルなら、ここで作る（新しいタブを作るときに設定でタブを表示していなければ、表示するかを確認ダイアログで聞く）。作れなかったときは警告のトーストで理由を出し、画面は開いたままにする
2. ルールを保存する。ルール名が空なら条件から付けた名前にする（フォルダを取り込むならフォルダ名、除くなら「ブックマーク（〈フォルダ〉 を除く）」、名前の条件があれば「〈フォルダ名かブックマーク〉〈文字〉」、何も無ければ「ブックマーク全件」）。保存に失敗したときは、エラーのトースト「ルールを保存できませんでした: 〈理由〉」を出し、画面は開いたままにする
3. 実行はしない。実行は設定画面の「実行」「今すぐ全ルール実行」か起動時

### 4.7. 閉じる

- キャンセル・Escape・オーバーレイのクリックで閉じる。入力内容は破棄される

## 5. 以前との違い

v0.8.0-beta.13 までは次の作りでした。

- アイテム管理から開く取込画面と同じフォームで、画面名は「ブックマーク自動取込 - 新規ルール作成／ルールを編集」。区画を縦に並べ、プレビューは一番下だった
- URL と名前の条件は正規表現（「URLパターン（正規表現）」「名前パターン（正規表現）」）で、読めない正規表現は無視していた
- 「サブフォルダのブックマークも含める」の切り替えがあった
- 取込先（「インポート先」）は既存のデータファイルから選ぶだけだった
