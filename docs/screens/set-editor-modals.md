## 1. 概要

登録・編集画面で種別がセットのとき、セットの欄（行の一覧）から開く 3 つの小さな画面です。どれも登録・編集画面の上に重ねて開き、閉じると元の画面に戻ります。ここでの変更は行の一覧に反映するだけで、保存は登録・編集画面の「登録」「更新」のときです。

### 対象の画面

| 画面 | 開き方 | 役割 |
| --- | --- | --- |
| [セットに追加するアイテム](#2-セットに追加するアイテム) | 「＋ アイテムを追加」、または行の詳細の「アイテムを選ぶ」「別のアイテムにする」 | 登録済みのアイテムを選んで、行として足す。行の詳細からは、行で開くアイテムを 1 つだけ選ぶ |
| [今の位置を記録](#3-今の位置を記録) | 「📍 今の位置を記録」 | 開いているウィンドウの今の位置を、行に取り込む。行に無いウィンドウを行として足す |
| [行の詳細](#4-行の詳細) | 行の「✏️」、または行のダブルクリック | 1 つの行の開くもの・動かすウィンドウ・位置・開くときの動きを直す |

### 共通の動き

- 外側（暗くした部分）のクリックと Escape キーで閉じる。上にウィンドウ選択モーダルを重ねているときは、Escape はそちらだけを閉じる
- Tab・Shift+Tab のフォーカスは画面の中で循環する
- 画面の中のキー操作は、下の登録・編集画面に伝わらない

### 2.3. アイテムを絞り込む

#### 選べるアイテム

- データファイルの単一アイテム（URL・ファイル・フォルダ・アプリ・カスタム URI）・ウィンドウ操作アイテムと、フォルダ取込で展開したアイテム。セット・クリップボード・フォルダ取込そのものは出さない
- ワークスペースのアイテム編集から開いたときは、ワークスペースの通常アイテム・ウィンドウ操作アイテムも出す
- 並びは、同じタブ（ワークスペースから開いたときはワークスペース）のアイテムが先で、その中はデータファイルの並びのまま

#### 処理フロー

1. 検索入力欄の文字を名前に部分一致で探す（大文字小文字を区別しない）
2. タブを選んでいるときは、そのタブのアイテムだけに絞る
3. 両方の条件に合うアイテムを表示する

### 2.4. アイテムを選んで追加する

#### アクション

- アイテム行をクリックしてチェックを付け外しし、「n 件を追加」をクリック

#### 処理フロー

1. チェックを付けたアイテムを、一覧の並びのまま行の一覧の末尾に足す
   - 登録済みのアイテムは、アイテムを指す行になる。アイテムを直すと、このセットにも効く
   - フォルダ取込で展開したアイテムは、パスを書いた行になる（名前は展開したアイテムの名前）
2. 画面を閉じ、検索・タブ・選択を元に戻す

### 2.5. 閉じる

- 「キャンセル」・外側のクリック・Escape キーで、追加せずに閉じる。検索・タブ・選択は元に戻す

### 2.6. 行の詳細から 1 つだけ選ぶ

行の詳細の「アイテムを選ぶ」「別のアイテムにする」から開いたときは、行で開くアイテムを 1 つだけ選ぶ形になる。並びと絞り込みは「＋ アイテムを追加」から開いたときと同じ。

- タイトルは「この行で開くアイテム」。選択数は出さない
- アイテム行はチェックボックスの代わりにラジオで、1 つだけ選べる。「追加済み」は出さない
- 追加ボタンの代わりに「選ぶ」（選んでいないときは押せない）。押すと、行が開くものをそのアイテムにして閉じる。動かすウィンドウ・位置・行の名前は変わらない

### 3.3. 開いたとき

1. すべての仮想デスクトップの開いているウィンドウを調べる。QuickDashLauncher 自身のウィンドウは除く
2. 行とウィンドウを自動で結び付ける。上の行から順に、まだどの行とも結び付いていないウィンドウを探す（1 つのウィンドウは 1 つの行とだけ。最小化中のウィンドウは使わない）
   - 動かすウィンドウ（exe 名・ウィンドウタイトル）を持つ行は、それに合うウィンドウ
   - 持たない行は、開くものから推測する。アプリは実行ファイルのパス、フォルダはエクスプローラーでフォルダ名のタイトル、ファイルはファイル名を含むタイトル
   - URL・カスタム URI の行は、どのウィンドウに開くか分からないので自動では探さない
3. 結び付いた行・結び付かなかった行・行に無いウィンドウ・最小化中のウィンドウに分けて表示する

ウィンドウを調べられなかったときは、ウィンドウが 1 つも無いものとして表示する（エラーは出さない）。

### 3.4. 位置を取れた行

#### アクション

- 行の右のプルダウンで「このまま」（既定）・「別のウィンドウにする」・「位置を記録しない」を選ぶ

#### 処理フロー

- **このまま**: 何もしない。記録すると、そのウィンドウの今の位置を行に取り込む
- **別のウィンドウにする**: ウィンドウ選択モーダル（[アイテム登録・編集モーダル - ウィンドウ選択モーダル](./register-modal.md#522-ウィンドウ選択モーダル)）を開き、選んだウィンドウをその行に結び付ける。そのウィンドウがほかの行に結び付いていたら、その行からは外す
- **位置を記録しない**: 行をウィンドウから外し、「位置を取れなかった行」に移す

#### 表示条件

- 行がタブとして開く種類（フォルダ・URL）なら、「既にあるウィンドウにタブで開くと、そのウィンドウごと動きます」と添える
- 結び付いたウィンドウが最小化中なら「最小化中なので位置は記録しません。元の大きさに戻してから記録してください」と添え、位置の代わりに「前の位置のまま」（前に位置を記録していないなら「位置は記録しない」）と出す
- 結び付いたウィンドウが管理者権限で動いていれば「管理者権限で動いているため、QDL から動かせないことがあります」と添える

### 3.5. 位置を取れなかった行

#### 表示内容

行の名前の下に「{理由}。このまま記録すると: {結果}」を出す。

| 理由 | 出る場合 |
| --- | --- |
| 「URL は自動では探せません」 | 動かすウィンドウを持たない URL・カスタム URI の行 |
| 「「位置を記録しない」にしました」 | 位置を取れた行で「位置を記録しない」を選んだ行 |
| 「合うウィンドウがありません」 | それ以外 |

| 結果 | 出る場合 |
| --- | --- |
| 「前の位置のまま（{位置}）」 | 前に位置を記録した行（「位置を記録しない」を選んだ行を除く） |
| 「開くだけ」 | 前に位置を記録していない行と、「位置を記録しない」を選んだ行 |

#### アクション

- 「ウィンドウを選ぶ」でウィンドウ選択モーダルを開き、選んだウィンドウをその行に結び付ける（行は「位置を取れた行」に移る）

### 3.6. 行に無いウィンドウ

#### アクション

- 見出しをクリックして開閉する
- ウィンドウの右のプルダウンで「追加しない」（既定）・「行として追加」・「この行の位置にする」の下に並ぶ行の名前を選ぶ
- 「行として追加」にしたウィンドウの ✏️ をクリックする（ほかを選んでいる間は押せない）

#### 処理フロー

- **追加しない**: 何もしない
- **行として追加**: 記録すると、このウィンドウを新しい行として行の一覧の末尾に足す。行の名前はウィンドウタイトル（空なら exe 名）、動かすウィンドウと位置はこのウィンドウから取る。開くものは持たない「動かすだけ」の行になる（ほかのアプリが起動したときの引数は取れず、実行ファイルを開いても開いていたファイルは開かないため）。開くものは後から行の詳細で足す（[4.3](#43-欄を直す)）。1 つ以上選ぶと、一覧の下に足した行の注意を 1 回だけ出す
- **行の名前を選ぶ**: このウィンドウをその行に結び付ける（行は「位置を取れた行」に移る）。選べるのは、まだウィンドウと結び付いていない行だけ
- **✏️**: 足す行の行の詳細（[4](#4-行の詳細)）を開く。記録する前に、開くもの・ウィンドウタイトル（一部だけで探す）などを直せる。直した内容は「記録する」で行に入り、「キャンセル」なら捨てる。ウィンドウタイトルを一部だけにすると「タイトル全体」の印は消える

最小化中・管理者権限のウィンドウには、[3.4](#34-位置を取れた行) と同じ注意を添える。

### 3.7. 最小化中のウィンドウ

- 位置を取れないので、見るだけ。行と結び付けたいときは、元の大きさに戻してから開き直す

### 3.8. 記録する

#### アクション

- 「記録する」をクリック

#### 処理フロー

1. ウィンドウと結び付いた行は、動かすウィンドウと位置を取り込む
   - 動かすウィンドウは、行の前のものがそのウィンドウにも合えばそのまま残す。合わない（手で選んだ・付け替えた）ときは、ウィンドウから決め直す。exe 名で決め、同じ exe のウィンドウがほかにもあるときなどはウィンドウタイトルも加える
   - 位置は、ウィンドウの今の位置・大きさ・仮想デスクトップ（最大化中なら最大化）にする。最小化中のウィンドウは位置を取らず、前の位置のままにする
2. 「位置を記録しない」にした行は、動かすウィンドウと位置を外す
3. ほかの位置を取れなかった行は変えない
4. 「行として追加」にしたウィンドウを、行の一覧の末尾に足す（✏️ で直していれば、直した内容で）
5. 画面を閉じる

### 3.9. 閉じる

- 「キャンセル」・外側のクリック・Escape キーで、何も変えずに閉じる

### 4.3. 欄を直す

- 入力した内容は、閉じたときに行に反映する
- exe 名とウィンドウタイトルの両方を空にすると、動かすウィンドウを持たない行になる

#### 開くもの

- **なし（動かすだけ）**: 開くものを外す
- **アイテム**: 「アイテムを選ぶ」「別のアイテムにする」で、セットに追加するアイテムの画面を 1 つだけ選ぶ形で開く（[2.6](#26-行の詳細から-1-つだけ選ぶ)）。選んだアイテムを行が開くものにする。動かすウィンドウ・位置・行の名前は変わらない。アイテムを選ぶまでは、開くものの無い動かすだけの行のまま
- **パス**: パスと引数を行に書く。切り替えた最初は空（実行ファイルなどを自動では入れない）。パスが空のまま閉じると、動かすだけの行になる

#### ウィンドウタイトル

- 候補の部品は、開いたときのタイトルを「 - 」「 | 」「 — 」で分けて作る。区切りが無ければ候補は出さない。開いたときのタイトルに * があれば、今合うウィンドウが 1 つのときはそのウィンドウのタイトルから作る
- 候補を押すと、欄が「\*{部品}\*」になる（タイトルの一部を含むウィンドウを探す）
- 「↺ 元に戻す」を押すと、欄を開いたときのタイトルに戻す
- 「今合うウィンドウ」は、画面を開いたときに開いていたウィンドウのうち、exe 名とウィンドウタイトルの欄に今合うものを数える。欄を直すたびに数え直す
- 待つ秒数に 0 以下を入れると、空（30 秒）として扱う
- 欄の意味（開いていたらどうするか・前面に出すか・待つ秒数など）は [セット](../features/set.md) を参照

### 4.4. 開いているウィンドウから位置を取る

#### アクション

- 「開いているウィンドウから位置を取る」をクリックし、ウィンドウ選択モーダル（[アイテム登録・編集モーダル - ウィンドウ選択モーダル](./register-modal.md#522-ウィンドウ選択モーダル)）でウィンドウを選ぶ

#### 処理フロー

1. 選んだウィンドウから、動かすウィンドウ（exe 名。ほかのウィンドウとの区別にウィンドウタイトルが要るときはタイトルも）を決めて入れる
2. ウィンドウの今の位置・大きさ・仮想デスクトップ（最大化中なら最大化）を位置に入れる
3. 選んだウィンドウについて、次の注意を位置の枠に出す
   - 最小化中: 位置は取らず、動かすウィンドウだけ入れて「最小化中のウィンドウなので、動かすウィンドウだけ取りました。位置は元の大きさに戻してから取ってください」
   - 管理者権限で動いている: 「管理者権限で動いているため、QDL から動かせないことがあります」

### 4.5. 閉じる

- 「閉じる」・外側のクリック・Escape キーで、直した内容を行に反映して閉じる。直す前に戻すボタンは無い

## 5. キーボード操作

3 つの画面で共通。

| キー | 動作 |
| --- | --- |
| Escape | 画面を閉じる（行の詳細は直した内容を反映して閉じる）。上にウィンドウ選択モーダルを重ねているときは、そちらだけを閉じる |
| Tab / Shift+Tab | 画面の中でフォーカスを循環する |
| 入力欄の中の編集キー | 通常の入力として扱う |
