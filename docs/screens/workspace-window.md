## 1. 概要

よく使うアイテムを登録して、画面右端の専用ウィンドウで素早くアクセスできる機能です。グループ化、名前変更、並び替えに対応します。

**キーボードショートカット**: `Ctrl+W` (表示/非表示切り替え)

### 主要機能

- **アイテム管理**: メイン画面からアイテムを追加・削除・名前変更。グループの右クリックからも、メインウィンドウのアイテムを選ぶか、新しく入力して追加できる
- **クリップボードペースト**: Ctrl+VでURL、ファイルパス、ファイル、テキスト・画像（クリップボードアイテム）を直接追加
- **グループ管理**: アイテムをグループに分類して整理。アイテムはどれかのグループに入る（グループの外には置けない。読み込みのときにグループに入っていないアイテムは「未分類」という名前の普通のグループに入る。[ワークスペース機能](../features/workspace.md#構成)）
- **ドラッグ&ドロップ**: アイテムの並び替えやグループ間移動
- **参照とコピー**: メインウィンドウのアイテムは既定で参照として追加し、メインウィンドウで直すとワークスペースにも反映する。右クリックで参照とコピーを行き来できる（[ワークスペース機能 - 参照とコピー](../features/workspace.md#参照とコピー)）
- **メインウィンドウへ移す**: コピーのアイテムをメインウィンドウへドラッグするか右クリックの「🚀 メインウィンドウへ移して参照にする」で、メインウィンドウのアイテムへ移し、ワークスペース側を参照に変える
- **キーワード絞り込み**: キーワード検索+スコープ選択（すべて/グループ/アイテム）でアイテムを絞り込む
- **コンテキストメニュー**: 右クリックでグループ操作・アイテム操作・タブの操作。余白の右クリックでグループの追加・貼り付けなど
- **ウィンドウカスタマイズ**: 不透明度調整、サイズ変更、ピン留め
- **アーカイブ**: グループ単位でアーカイブ・復元

| **スタイル** | `src/renderer/styles/components/WorkspaceWindow.css`。メインウィンドウのアイテムとつなぐ画面の中身は `WorkspaceLinkCopies.css`（枠は `SetEditor.css` と共用） |
| **子ウィンドウ** | アイテムの編集: `src/renderer/components/WorkspaceItemEditPage.tsx`（フォームは `WorkspaceItemEditModal`）。グループに追加するアイテム（メインウィンドウのアイテムから選ぶ）: `src/renderer/components/WorkspaceItemPickerPage.tsx`。新しく入力して追加: `src/renderer/components/WorkspaceNewItemPage.tsx`（どちらも [5.8.9](#589-グループを右クリックしてアイテムを追加)）。指すアイテムを選ぶ: `src/renderer/components/WorkspaceLinkPickerPage.tsx`（[5.20](#520-指すアイテムを選ぶ)）。メインウィンドウのアイテムとつなぐ: `src/renderer/components/WorkspaceLinkCopiesPage.tsx`（[5.21](#521-メインウィンドウのアイテムとつなぐ)） |
| **表示条件** | メイン画面で`Ctrl+W`、メイン画面のヘッダーの ⭐ ボタン。開いていて 📌 なしなら、メイン画面の表示時に一緒に出る |
| **画面タイプ** | ウィンドウ（AlwaysOnTop切り替え可能、フレームレス） |
| **サイズ** | 幅380px。高さは内容の高さに合わせて自動で変わる（画面の左端・右端に置く設定では、出すたびに作業領域いっぱいにしてから内容に合わせ直す）（最小150px、最大は画面の作業領域の高さ）。2px 以内の差は合わせ直さない（ループ防止）が、中身がはみ出して縦のスクロールバーが出ているときは、広げる分は小さくても合わせる。中身の高さには最後のグループの下の余白も含める（A3-185） |
| **サイズ変更** | 8方向（4隅・4辺）のハンドルをドラッグしてリサイズできる。4隅は隣り合う2辺、4辺はその辺が動く（最小: 幅300px × 高さ400px） |
| **配置位置** | 既定は画面右端。⚙️ メニューの「⬅️ 左端に寄せる」「➡️ 右端に寄せる」で切り替え、ドラッグで移動可能 |
| **透過** | 設定画面のワークスペースウィンドウの節の「見た目」にある「不透明度」スライダー（0%=完全透明、100%=完全不透明）で調整（ワークスペースウィンドウ本体だけ）。「背景だけを透明にする」をオンにするとウィンドウ背景だけが透過され、アイテムやボタンは不透明のまま表示（切り離しウィンドウにも効く。オンの間は不透明度は使えない）。設定の変更は開き直さなくても反映される |

| 5.21 | メインウィンドウのアイテムとつなぐ | タブを右クリック → メインウィンドウのアイテムとつなぐ | パスと引数が同じコピーをまとめて参照にする | [詳細](#521-メインウィンドウのアイテムとつなぐ) |

## 5. 機能詳細

### 5.1. 絞り込みを変更

#### アクション

- ヘッダーの「🔍」ボタンをクリックして（または`Ctrl+F`で）絞り込みバーを表示し、キーワードを入力してアイテムを絞り込む

#### 処理フロー

1. ヘッダーの「🔍」ボタンをクリックすると絞り込みバーが表示される（`Ctrl+F`でも表示され、入力欄にフォーカスする。切り離しウィンドウでは`Ctrl+F`は効かない）
2. 絞り込みバーのキーワード入力欄にテキストを入力（フォーカスは自動的に入力欄に移動）
3. スコープ選択ドロップダウンで検索対象を選択：
   - **すべて**: グループ名・アイテム名の両方を検索。キーワードはアイテム名と、それが入っているグループ（親のグループを含む）の名前にまたがってよい（例: 「株 xlsm」で「株」グループの xlsm のアイテム）
   - **グループ**: グループ名のみを検索
   - **アイテム**: アイテム名のみを検索（参照はメインウィンドウの表示名でも当たる）
4. 入力したキーワードに一致するアイテム・グループが表示される（メインウィンドウの検索と同じく、スペース区切りのキーワードをすべて含むものに絞る。大文字小文字区別なし）
5. Escapeキーでキーワードをクリアして絞り込みバーを閉じる（1回の押下で両方行う）
6. 絞り込みバーの「×」ボタンでもキーワードをクリアして絞り込みバーを閉じる

#### 注意

- 参照は、ワークスペースでの表示名とメインウィンドウのアイテムの表示名のどちらに一致しても表示される
- キーワードをクリアすると全アイテムが再表示される

### 5.2. すべて展開ボタンをクリック

#### アクション

- ヘッダーの「🔽」ボタンをクリック
- タブ・余白の右クリックの「🔽 すべて展開」（タブの右クリックで選んでいないタブを選んだときは、そのタブに切り替えてから展開する）

#### 処理フロー

1. 表示中のタブのグループセクションをすべて展開する（ほかのタブのグループは変えない）。アーカイブ表示中はアーカイブのグループを展開する
2. 各セクションのアイテムが表示される

### 5.3. すべて折りたたむボタンをクリック

#### アクション

- ヘッダーの「🔼」ボタンをクリック
- タブ・余白の右クリックの「🔼 すべて折りたたむ」（タブの右クリックは 5.2 と同じく、そのタブに切り替えてから）

#### 処理フロー

1. 表示中のタブのグループセクションをすべて折りたたむ（ほかのタブのグループは変えない）。アーカイブ表示中はアーカイブのグループを折りたたむ
2. 各セクションのアイテムが非表示になる
3. 折りたたみは UI 状態として保存する。アーカイブの折りたたみは保存せず、アーカイブを表示している間だけ保つ（ほかの変更で一覧を読み直しても戻らない）

### 5.4. 追加メニューをクリック

#### アクション

- ヘッダーの「➕」ボタンをクリックし、ボタンの下に出るメニューから選ぶ
  - 「➕ グループを追加」: 今のワークスペースにグループを追加する（下の処理フロー）
  - 「➕ ワークスペースを追加」: 新しいワークスペース（タブ）を作る（[5.17.2](#5172-タブを追加)）

#### 処理フロー（グループを追加）

1. 新しいグループを作成
2. グループ名を「グループ {N}」（Nは現在のグループ数+1）にする（編集モードには入らない）
3. グループをリストの末尾に追加
4. データを保存

アーカイブを表示しているときは、今のワークスペースの表示に戻してから追加する。空のワークスペースの［＋ グループを追加］ボタン、タブ・余白の右クリックの「➕ グループを追加」も同じ動き（タブの右クリックで選んでいないタブを選んだときは、そのタブに切り替えてから追加する）。

#### 表示条件

- ボタンは常時表示

### 5.5. アーカイブタブをクリック

#### アクション

- タブバーの「🗄️」タブをクリック

#### 処理フロー

1. タブバーのアーカイブタブに切り替え
2. アーカイブされたグループを一覧表示
3. 各グループのコンテキストメニュー（「📋 テキストでコピー」「↩️ ワークスペースへ復元」「🗑️ アーカイブから削除」）から復元または完全削除が可能
4. アーカイブ表示中に効く操作はアイテムの起動とグループの折りたたみ/展開だけ。名前変更・アイテム削除・並べ替えなどの変更操作は効かない
5. 「🗑️ アーカイブから削除」は、グループが空でも必ず確認ウィンドウ「アーカイブから削除」を表示する。文面は「「{グループ名}」をアーカイブから完全に削除してもよろしいですか？」に続けて、含まれるサブグループ・アイテムの個数と「アイテムごと削除され、元に戻せません。」。ボタンは「削除」「キャンセル」で、チェックボックスはない

### 5.6. ピン留めボタンをクリック

#### アクション

- ヘッダーの「📌」ボタンをクリック、または右クリック

#### 処理フロー

メインウィンドウ・切り離しウィンドウの 📌 と同じ決まりで動く（[ウィンドウ制御](../architecture/window-control.md#概要)）。ワークスペースは最初から表示固定。

1. クリック: 表示固定のオン・オフを切り替える（常に最前面のときはなしに戻す）
2. 右クリック: 「📌 表示固定（隠さずに残す）」「⬆️ 常に最前面」のチェック付きメニューを出し、選んだ段階にする
3. 常に最前面のときだけ、ウィンドウをほかのウィンドウより前面に固定する
4. ボタンの色とツールチップを今の段階に合わせる
5. ピン留めしている間は、メインウィンドウと一緒に隠れない。ホットキーでメインウィンドウを出すとき、ほかのウィンドウの下にあっても手前に出る。Win+D（デスクトップの表示）で最小化されていれば、元の大きさに戻してから手前に出す
6. ピン留めしていない（なし）間は、開いていればメインウィンドウと一緒に出て、一緒に隠れる
7. 段階は保存し、閉じても覚えている

### 5.7. 閉じるボタンをクリック

#### アクション

- ヘッダーの「×」ボタンをクリック

#### 処理フロー

1. ウィンドウを閉じる（非表示にする）。📌 に関係なく閉じる
2. 「閉じた」状態を覚え、メインウィンドウと一緒に出なくなる（メイン画面の `Ctrl+W`・⭐ ボタンで隠したときも同じ）
3. ワークスペースデータと 📌 の段階は保持される

### 5.8. グループヘッダー操作

グループヘッダーに対する操作は以下の2つです：

- **ヘッダークリック**: グループの折りたたみ/展開を切り替え
- **右クリックコンテキストメニュー**: すべて開く・アイテムの追加・サブグループ追加・名前変更・色変更・複製・ほかのグループを折りたたむ・テキストでコピー・ワークスペースを移動・アーカイブ・削除などの操作

> グループヘッダー上にインライン操作ボタン（✏️🎨📦🗑️）は表示されません。これらの操作はすべて右クリックコンテキストメニューから実行します。

#### 5.8.1. 折りたたみボタンをクリック

##### アクション

- グループヘッダーをクリック（折りたたみアイコン▼をクリック、またはヘッダー全体をクリック）

##### 処理フロー

1. グループの折りたたみ状態を切り替え
2. 折りたたみON時：
   - グループ内のアイテムを非表示
   - 折りたたみアイコン（▼）が回転して折りたたみ状態を表す
3. 折りたたみOFF時：
   - グループ内のアイテムを表示
   - 折りたたみアイコンが通常表示
4. クリックしたグループを `Ctrl+V` の貼り付け先にし、見出しに黄色の枠を付ける（グループの中のアイテムをクリックしても、そのグループが貼り付け先になる。[5.13](#513-ctrlvでペースト)）

#### 5.8.2. グループを右クリックして「名前を変更」

##### アクション

- グループヘッダーを右クリック → コンテキストメニューから「✏️ グループ名を変更」を選択

##### 処理フロー

1. グループ名の編集モードに入る
2. テキスト入力フィールドに変更
3. 現在のグループ名を選択状態で表示
4. フォーカスを入力フィールドに移動
5. Enter（日本語入力の変換を確定する Enter では確定しない）またはフォーカスを外すと確定する。前後の空白は除き、空のまま、または変更なしなら元の名前に戻る。Escape で取り消す

#### 5.8.3. グループを右クリックして「色を変更」

##### アクション

- グループヘッダーを右クリック → コンテキストメニューから「🎨 色を変更」を選択

##### 処理フロー

1. カラーピッカー（モーダル）を表示。`Escape`キーまたはモーダルの外側のクリックで閉じる
2. 以下の色トークンから選択可能（色を選んでいないグループは、階層で既定の色が変わる。トップレベルは青、サブグループは青緑、その下は灰色）：
   - 青
   - 緑
   - 赤
   - 黄
   - 水色
   - 灰色
   - 紫
   - 青緑
   - ピンク
   - 藍
   - オレンジ
   - シアン

   色は 4 列のマスで並び、マウスを重ねると上の名前が出る（英語表示では Blue, Green, Red, Yellow, Light blue, Gray, Purple, Teal, Pink, Indigo, Orange, Cyan）。今の色のマスは枠を太くし、白い ✓ を重ねて示す（選択中の状態として読み上げにも伝える）
3. 色を選択するとモーダルが閉じる
4. グループヘッダーの背景色を変更
5. データを保存

#### 5.8.4. グループを右クリックして「アーカイブ」

##### アクション

- グループヘッダーを右クリック → コンテキストメニューから「🗄️ グループをアーカイブ」を選択

##### 処理フロー

1. 子ウィンドウ「グループのアーカイブ」を開いて確認する（このウィンドウは閉じるまで操作できない）。文面は「「{グループ名}」をアーカイブしてもよろしいですか？」に続けて「このグループには（サブグループ {M} 件と、）{N} 件のアイテムが含まれています。」「アーカイブしたグループは後で復元できます。」。ボタンは「アーカイブ」「キャンセル」
2. 「アーカイブ」の場合：
   - グループと子孫サブグループ、そのすべてのアイテムをアーカイブに移動
   - ワークスペースから削除
   - アーカイブデータを保存
3. 「キャンセル」の場合：処理を中止

#### 5.8.5. グループを右クリックして「削除」

##### アクション

- グループヘッダーを右クリック → コンテキストメニューから「🗑️ グループを削除」を選択

##### 処理フロー

1. グループが空（アイテムもサブグループもない）の場合は、確認なしでそのまま削除する
2. それ以外は子ウィンドウ「グループの削除」を開いて確認する（このウィンドウは閉じるまで操作できない）。文面は「「{グループ名}」を削除してもよろしいですか？」に続けて「このグループには（サブグループ {M} 件と、）{N} 件のアイテムが含まれています。」。その下に赤字で「中に入っているものもすべて消えます。残したいときは、削除せずに「アーカイブ」を使ってください。」。ボタンは「削除」「キャンセル」
3. 「削除」の場合：
   - グループと子孫サブグループを、中のアイテムごと削除（アイテムを移す先は無い）
   - データを保存
4. 「キャンセル」の場合：処理を中止

確認の子ウィンドウ（5.8.4・5.8.5・5.9.3 と、アーカイブから削除）が確認する内容を受け取れなかったときは、文面の代わりに「確認する内容が見つかりません。」と「閉じる」ボタンを出す。

#### 5.8.6. グループを右クリックして「サブグループを追加」

##### アクション

- グループヘッダーを右クリック → コンテキストメニューから「➕ サブグループを追加」を選択

##### 処理フロー

1. 選択したグループの子として新しいサブグループを作成
2. サブグループ名を「サブグループ {N}」（Nは親グループ直下のサブグループ数+1）にする（編集モードには入らない）
3. データを保存

##### 表示条件

- 深さの上限（2階層）に達しているグループでは、このメニュー項目自体が表示されない

#### 5.8.7. グループを右クリックして「テキストでコピー」

##### アクション

- グループヘッダーを右クリック → コンテキストメニューから「📋 テキストでコピー」を選択

##### 処理フロー

1. グループ名とグループ内アイテムの一覧をテキスト形式に整形
2. クリップボードにコピーし、画面の右下に「「{グループ名}」をテキストでコピーしました」と出す（失敗したら「…テキストでコピーできませんでした」）

#### 5.8.8. グループを右クリックして「ワークスペースを移動」

##### アクション

- グループヘッダーを右クリック → コンテキストメニューから「📁 ワークスペースを移動」→ サブメニューから移動先ワークスペースを選択

##### 処理フロー

1. 選択したグループとその子孫サブグループの所属ワークスペースを移動先に変える
2. 選択したグループがサブグループだった場合は、親グループから外して移動先の最上位に置く
3. グループ内のアイテムの所属ワークスペースも合わせて変える（データの項目は [ワークスペースファイル形式](../architecture/file-formats/workspace-format.md)）
4. アーカイブ済みのグループに対して実行した場合（メニュー名は「↩️ ワークスペースへ復元」）は、復元しつつ指定したワークスペースに追加される
5. データを保存

##### 表示条件

- 他にワークスペースが存在するときだけメニュー項目が表示される（自ワークスペース1つのみの場合は非表示）

#### 5.8.9. グループを右クリックして「アイテムを追加」

##### アクション

- グループヘッダーを右クリック → コンテキストメニューから「➕ アイテムを追加」→ サブメニューから次のどちらかを選択
  - 「🔍 メインウィンドウのアイテムから選ぶ…」: メインウィンドウのアイテムを選んで入れる（下の「メインウィンドウのアイテムから選ぶ」）
  - 「✏️ 新しく入力して追加…」: 編集ウィンドウと同じフォームで新しいアイテムを入力して入れる（下の「新しく入力して追加」）

##### 処理フロー（メインウィンドウのアイテムから選ぶ）

1. 「グループ「{グループ名}」に追加するアイテム」の画面を、独立した子ウィンドウで開く。開き元（本体または切り離しウィンドウ）と同じディスプレイの中央に 850x800（作業領域で切り詰め）で開き、開き元に対してモーダル。開き元のウィンドウのサイズ・位置は変わらない。同じ追加先の画面が開いていれば前面に出す
2. 画面の上の帯に、追加先（「追加先」・ワークスペース名 › 親グループ名 › グループ名。サブグループでないときは親グループ名を出さない）を出す
3. 一覧には、メインウィンドウのすべてのタブのアイテム（単一アイテム・フォルダ取込で展開したアイテム・セット・クリップボード）を、データファイルの並びのまま出す。検索・タブでの絞り込み・複数選択・「n 件を追加」は[セットに追加するアイテム](./set-editor-modals.md#2-セットに追加するアイテム)と同じ。アイテムにはタブの名前を右に添える
4. すでにこのグループにあるアイテムは「追加済み」と出し、チェックできない。グループの参照が指しているアイテムは追加済み。コピーは元のアイテムを指す情報を持たないので、パス（大文字・小文字は区別しない）と引数が同じものを追加済みとみなす。パスの無いコピー（セット・クリップボード・パスの無い単一アイテム）は追加済みにならない
5. 「n 件を追加」で、選んだアイテムを一覧の並びのままグループに追加する。追加のしかたはメインウィンドウの「⭐ ワークスペースに追加」と同じで、既定は参照（フォルダ取込で展開したアイテムはコピーで追加し、「参照できないアイテムなので、コピーで追加しました」と知らせる）。ボタンの左のチェックボックス「コピーで追加（メインウィンドウと切り離す）」（既定はオフ）をオンにすると、コピーで追加する（[ワークスペース機能](../features/workspace.md#アイテムの追加元と作られるアイテム)）。グループを折りたたんでいたら開く
6. トーストで知らせて画面を閉じる。1 件ならアイテム名、2 件以上なら「n 件のアイテム」に「グループ「{グループ名}」に追加しました」を添える。途中で失敗したときは、入れたものは残し、画面は開いたままにする
7. 「キャンセル」・Escape・ウィンドウの × では何も追加せずに閉じる
8. 開いたときに追加先のグループが見つからない（開くまでの間に削除されたなど）ときは、一覧の代わりに「追加先のグループが見つかりません（削除された可能性があります）。」と「閉じる」ボタンを出す

##### 処理フロー（新しく入力して追加）

1. 「ワークスペースにアイテムを追加」の画面を、独立した子ウィンドウで開く。開き方（位置・大きさ・モーダル）は[編集](#511-コンテキストメニュー操作)の編集ウィンドウと同じ。同じ追加先の画面が開いていれば前面に出す
2. 欄は編集ウィンドウと同じで、空の単一アイテムから始める。違いは次のとおり
   - タイトルは「ワークスペースにアイテムを追加」で、その上に追加先の帯（上の「メインウィンドウのアイテムから選ぶ」と同じ）を出す
   - 種別を選べる（単一アイテム・セット・クリップボード）。フォルダ取込はデータファイル向けの種別なので出さない。種別を変えたときの欄の入れ替えはメインの登録画面と同じ（[種別変更時の初期化処理](./register-modal.md#種別変更時の初期化処理)）
   - フッターは「⚡ 試しに実行」「キャンセル」「追加」。削除のボタンは無い。「⚡ 試しに実行」は入力中の中身で動かす（クリップボードは、まだ保存した中身が無いので押せない）
3. 「追加」で入力を確かめる（名前が空・パスの誤り・セットの行が 0 件・クリップボードの中身が無いときは、編集と同じ文言で止めて開いたままにする）。通れば、そのグループの末尾に追加し、グループを折りたたんでいたら開く。クリップボードを取り込んでいたら、その中身を確定する
4. トーストでアイテム名に「グループ「{グループ名}」に追加しました」を添えて知らせ、画面を閉じる。追加に失敗したときはエラーのトーストで「ワークスペースへの追加に失敗しました」と出し、開いたままにする
5. 「キャンセル」・Escape・ウィンドウの × では何も追加せずに閉じる（取り込んだクリップボードは捨てる）
6. 開いたときに追加先のグループが見つからないときは、フォームの代わりに「追加先のグループが見つかりません（削除された可能性があります）。」と「閉じる」ボタンを出す

##### 表示条件

- ワークスペース本体・切り離しウィンドウのグループに出す。アーカイブのグループには出さない
- 「➕ アイテムを追加」はサブグループの追加と同じ組に置く。一番上のグループでは、先頭に切り離しの組があるので上から 2 つ目の組、サブグループでは先頭の組になる

#### 5.8.10. グループを右クリックして「すべて開く」

##### アクション

- グループヘッダーを右クリック → コンテキストメニューの先頭の「▶ すべて開く」を選択

##### 処理フロー

1. グループのアイテムを、サブグループの中も含めて並び順に集める（元のアイテムが見つからない参照は除く）
2. 開けるアイテムが無ければ、トーストで「「{グループ名}」には開けるアイテムがありません」と知らせて終わる
3. 5 件以上なら、確認ウィンドウ（タイトル「すべて開く」、本文「「{グループ名}」の n 件のアイテムを順に開きますか？」、ボタン「開く」）で確かめる
4. 1 件ずつ、アイテムをクリックしたときと同じように開く（5.9.1）。起動が重ならないよう 0.3 秒ずつあける

##### 表示条件

- ワークスペース本体・切り離しウィンドウのグループに出す。アーカイブのグループには出さない

#### 5.8.11. グループを右クリックして「グループを複製」

##### アクション

- グループヘッダーを右クリック → コンテキストメニューから「📄 グループを複製」を選択

##### 処理フロー

1. 「{元の名前} のコピー」という名前で、元と同じ色のグループを、元と同じ親（一番上のグループなら同じワークスペース）の最後に作る
2. サブグループは元の名前・色のまま作り直し、アイテムはすべて複製して新しいグループに入れる（参照は参照のまま）
3. クリップボードアイテムは保存データも複製する（元と同じデータを指したままにしない）

#### 5.8.12. グループを右クリックして「ほかのグループを折りたたむ」

##### アクション

- グループヘッダーを右クリック → コンテキストメニューから「🔼 ほかのグループを折りたたむ」を選択

##### 処理フロー

1. 選んだグループと、その親のグループを開く
2. 同じワークスペースのほかのグループ（サブグループを含む）をすべて折りたたむ。折りたたみは UI 状態として保存する（ヘッダーの 🔼 と同じ）

##### 表示条件

- ワークスペース本体のグループに出す。切り離しウィンドウには出さない（ほかのグループが無いため）

### 5.9. アイテムカード操作

アイテムカードには以下の機能があります：

- クリックで起動
- Shift+クリックで親フォルダを開く（ファイル・フォルダ・アプリ。メインウィンドウの Shift+Enter と同じ。それ以外の種類は普通に開く）
- ×ボタンで削除
- マウスホバーで詳細表示
- 右クリックで編集・名前の変更などのメニュー（5.11）

ダブルクリックには何も割り当てていない（メインウィンドウと同じ）。キーボードでの操作（`F2` など）は無い。ワークスペースには選択中のアイテムが無いため。

#### 5.9.1. アイテムをクリック

##### アクション

- アイテムカードをクリック

##### 処理フロー

1. アイテムを起動（開く）
2. アイテムの種別に応じて実行：
   - URL: 既定のブラウザで開く
   - ファイル: 関連付けられたアプリで開く
   - フォルダ: エクスプローラーで開く
   - アプリケーション: 実行ファイルを起動
   - パスの無い単一アイテム: 対象ウィンドウが開いていれば切り替え、開いていなければ何も開かずに「開いていないので切り替えませんでした」と知らせる（[メインウィンドウ - アイテムをクリック](./main-window.md#56-アイテムをクリック)）
   - クリップボード: 保存した中身をクリップボードに書き戻し、書き戻せたら「クリップボードにコピーしました」とトーストで知らせる（書き戻せないときはエラーのトースト）
   - 参照: 指す先のメインウィンドウのアイテムの今の中身で、上の種別ごとに開く（セットならメインウィンドウのセットを開く）。元のアイテムが見つからない参照は開かず、トーストで「「{名前}」は開けません。元のアイテムが見つかりません」と知らせる（指す先がフォルダ取込なら、理由は「フォルダ取込は参照できません」）
   - セット: メインウィンドウと同じように行を開き、ウィンドウ位置を記録した行はウィンドウを動かす（[メインウィンドウ - アイテムをクリック](./main-window.md#56-アイテムをクリック)）。行が指すアイテムは、データファイルとワークスペースの両方から探す（同じ id ならワークスペースのアイテムを使う）。トーストは本体側で出し、「n 件のアイテムを起動します」と、名前の分かる行の先頭 3 件の名前を出す（行の名前をデータファイルのアイテムからも引くため）。実行中のセットを押し直したときは何もせず、トーストも出さない

#### 5.9.2. アイテム名をその場で変更

##### アクション

- アイテムを右クリック → 「🏷️ 表示名を変更」（参照では「🏷️ 表示名を変更（ワークスペースだけ）」）

##### 処理フロー

1. アイテム名の編集モードに入る
2. テキスト入力フィールドに変更
3. 現在のアイテム名を選択状態で表示
4. フォーカスを入力フィールドに移動
5. Enter（日本語入力の変換を確定する Enter では確定しない）またはフォーカスを外すと確定する。前後の空白は除き、空のまま、または変更なしなら元の名前に戻る。Escape で取り消す
6. 参照では、ワークスペースでの表示名を付ける（メインウィンドウのアイテムの表示名は変わらない）。ワークスペースでの表示名があるときに空にして確定するか、メインウィンドウの表示名と同じ名前にすると、ワークスペースでの表示名を消し、以後はメインウィンドウの表示名を出す

#### 5.9.3. 削除ボタンをクリック

##### アクション

- アイテムカードの「×」ボタンをクリック（ホバー時に表示）

##### 処理フロー

1. 確認の子ウィンドウ「ワークスペースから削除」を開く（このウィンドウは閉じるまで操作できない）。文面は「「{アイテム名}」をワークスペースから削除しますか？」、ボタンは赤の「ワークスペースから削除」と「キャンセル」
2. 「ワークスペースから削除」の場合：アイテムをワークスペースから削除し、データを保存
3. キャンセルの場合：何もしない

#### 5.9.4. アイテムにマウスホバー

##### アクション

- アイテムカードにマウスカーソルをホバー

##### 処理フロー

1. ツールチップを表示
2. ツールチップには以下の情報を表示：
   - 参照のとき、先頭に「🔗 メインウィンドウのアイテム: {メインウィンドウの表示名}」と、タブが分かれば「タブ: {タブ名}」。以下の行は指す先のアイテムの中身（メモもメインウィンドウのもの）
   - 1行目（参照ではその次の行）: 種別に応じた内容（通常アイテムはパス。パスの無い単一アイテムは「開いているウィンドウに切り替えるだけ: {exe 名} / {タイトル}」。ほかは「セット: N 件」「クリップボード: プレビュー」）
   - 「行: 名前1、名前2、名前3」（セットのとき。名前の分かる行の先頭 3 件。残りの行（名前の分からない行を含む）があれば「ほか n 件」を添える。名前が 1 つも分からなければこの行は出さない。行が指すアイテムの名前はワークスペースのアイテムから引く）
   - 「リンク先: …」（通常アイテムでショートカットの場合）
   - 「引数: …」（通常アイテムで設定されている場合）
   - 「メモ: …」（設定されている場合）
   - 空行のあと「追加日時: …」（表示言語の書式の日付と時刻、秒なし）

元のアイテムが見つからない参照のツールチップは、「⚠ 元のアイテムが見つかりません（最後に見た表示名: {名前}）」と「右クリックで、別のアイテムを指すか、ワークスペースから削除できます」の 2 行だけ（指す先がフォルダ取込なら、1 行目は「⚠ フォルダ取込は参照できません（最後に見た表示名: {名前}）」）。

##### ツールチップ表示例

**通常のアイテム:**

```
C:\Users\Desktop\myapp.exe

追加日時: 2025/12/18 10:30
```

**引数・メモ付きアイテム:**

```
C:\Program Files\Code\Code.exe
引数: --new-window
メモ: 作業用

追加日時: 2025/12/18 10:30
```

**ショートカットファイル:**

```
C:\Users\Desktop\app.lnk
リンク先: C:\Program Files\App\app.exe

追加日時: 2025/12/18 10:30
```

**参照:**

```
🔗 メインウィンドウのアイテム: Visual Studio Code
タブ: 開発
C:\Program Files\Code\Code.exe
メモ: 作業用

追加日時: 2025/12/18 10:30
```

### 5.10. 未分類セクション操作（廃止）

未分類という専用の区画（折りたたみ・見出しの右クリックを含む）は無くなった。アイテムはどれかのグループに入る。読み込みのときにグループに入っていないアイテム（古い版で書いたファイル・手編集など）は、ワークスペースごとに「未分類」という名前の普通のグループ（ワークスペースの最後に作る。改名・削除できる）に入る（[ワークスペース機能](../features/workspace.md#構成)）。番号はほかの節のリンクを保つために残している。

### 5.11. コンテキストメニュー操作

#### アクション

- アイテムを右クリック

#### 処理フロー

1. 右クリックした位置にOSのネイティブメニューを出す
2. アイテムの種類（コピー・参照・元のアイテムが見つからない参照）に応じてメニュー項目を出し分ける

#### メニュー項目

| メニュー項目 | 説明 | 表示条件 |
| --- | --- | --- |
| **✏️ 編集** | 独立した編集ウィンドウを開く | コピーのみ |
| **✏️ 編集（メインウィンドウのアイテム）** | メインウィンドウを表示し、指す先のアイテムをメインウィンドウの編集画面で開く | 参照のみ（元のアイテムが見つからない参照を除く） |
| **🏷️ 表示名を変更** | アイテム名を編集モードに | コピーのみ |
| **🏷️ 表示名を変更（ワークスペースだけ）** | ワークスペースでの表示名を編集モードに（5.9.2） | 参照のみ（元のアイテムが見つからない参照を含む） |
| **📝 メモを表示** | メモをモーダルで表示（参照はメインウィンドウのアイテムのメモ） | メモがあるアイテムのみ |
| **🛡️ 管理者として実行** | アプリを管理者として起動する（UAC の確認が出る） | アプリ（exe・.lnk・.bat/.cmd など。ストアアプリを除く。参照は指す先のアイテムの種別で決まる） |
| **──────────────** | 区切り線 | 他にワークスペースがあるときのみ |
| **📁 ワークスペースを移動 ▶** | サブメニューから移動先ワークスペースと、その中のグループを選択 | 他にワークスペースがあるときのみ |
| **📁 グループへ移動 ▶** | サブメニューから同じワークスペースのグループを選んで移す（サブグループは字下げして親の下に並ぶ。今入っているグループは選べない） | 同じワークスペースにほかのグループがあるとき（アーカイブの表示中は出さない） |
| **──────────────** | 区切り線 | 全アイテム |
| **📄 コピーにする（メインウィンドウと切り離す）** | 参照を、指す先のアイテムの今の中身を持つコピーにする | 参照のみ（元のアイテムが見つからない参照を除く） |
| **🔁 別のアイテムを指す…** | 指すアイテムを選ぶウィンドウを開く（[5.20](#520-指すアイテムを選ぶ)） | 参照のみ（元のアイテムが見つからない参照を含む） |
| **🚀 メインウィンドウへ移して参照にする ▶** | 選んだタブ（データファイル）へ移し、ワークスペース側を参照に変える（移す先に同じアイテムがあれば、それを指す参照にする） | コピーのみ |
| **──────────────** | 区切り線 | 通常アイテムのみ（パスの無い単一アイテムを除く。以下のパスの項目も同じ。参照は指す先のアイテムの種別で決まり、元のアイテムが見つからない参照には出さない） |
| **📋 パスをコピー** | アイテムのパス（引数なし）をクリップボードにコピー | 通常アイテムのみ |
| **📋 親フォルダのパスをコピー** | 親フォルダのパスをコピー | 通常アイテムで、URL・カスタムURI以外 |
| **📂 親フォルダを開く** | 親フォルダをエクスプローラーで開く | 通常アイテムで、URL・カスタムURI以外 |
| **──────────────** | 区切り線 | ショートカットのリンク先があるときのみ |
| **📋 リンク先のパスをコピー** | ショートカットのリンク先パスをコピー | ショートカットのリンク先があるときのみ |
| **📋 リンク先の親フォルダのパスをコピー** | リンク先の親フォルダのパスをコピー | ショートカットのリンク先があるときのみ |
| **📂 リンク先の親フォルダを開く** | リンク先の親フォルダを開く | ショートカットのリンク先があるときのみ |
| **──────────────** | 区切り線 | 全アイテム |
| **🗑️ ワークスペースから削除** | ワークスペースから完全に削除 | 全アイテム |

#### 各メニュー項目の処理

並びはメインウィンドウの右クリックに合わせている（編集を先頭に置き、パスの項目は後ろ）。起動はクリックでできるので、メニューには置かない。

**表示名を変更:**

- アイテム名の編集モードに入る（5.9.2）

**管理者として実行:**

- アイテムをクリックしたときと同じトーストを出してから、Windows の UAC の確認を出し、許可されたらアプリを管理者として起動する。引数・作業フォルダはクリックで開くときと同じものを渡す。参照は、メインウィンドウのアイテムの今の中身で開く
- 起動できたら起動の記録に数える。UAC で「いいえ」を押したときは何も知らせず、数えない。それ以外で起動できなかったときは、クリックで開けなかったときと同じエラーのトーストで知らせる（[右クリックメニュー - 管理者として実行](./context-menu.md#415-管理者として実行)）
- 管理者として開いたウィンドウは、権限の低い QuickDashLauncher からウィンドウ位置を当てたり前面に出したりできないことがある

**編集（メインウィンドウのアイテム）:**

- メインウィンドウを表示してから、指す先のアイテムをメインウィンドウの編集画面で開く。編集画面の見出しの下には、ワークスペースで参照している数を青い帯で出す（[アイテム登録・編集モーダル仕様書](./register-modal.md#3-画面項目一覧)）。保存すると、参照しているワークスペースのアイテムにも反映する
- 開く前に指す先のアイテムが見つからなくなっていたら、トーストで「メインウィンドウのアイテムが見つかりません」と知らせる

**コピーにする（メインウィンドウと切り離す）:**

- 参照を、指す先のアイテムの今の中身を持つコピーに置き換える（位置・グループはそのまま）。表示名はワークスペースでの表示名があればそれ、メモはメインウィンドウのアイテムのものを写す。クリップボードアイテムは保存データを複製する（[ワークスペース機能 - 参照とコピー](../features/workspace.md#参照とコピーを行き来する)）
- 成功したらトーストで「「{名前}」をコピーにしました」、失敗したらエラーのトーストで知らせる

**別のアイテムを指す…:**

- 指すアイテムを選ぶウィンドウを開く（[5.20](#520-指すアイテムを選ぶ)）

**メモを表示:**

- メモを閲覧用のモーダルに出す。「コピー」でメモをクリップボードにコピーし、「閉じる」・Escape・外側のクリックで閉じる（メインウィンドウの「メモを表示」と同じ）

**パスをコピー:**

- アイテムのパス（引数は含まない）をクリップボードにコピーし、画面の右下に「{パス・親フォルダのパスなど}をコピーしました」と出す（メインウィンドウと同じ。失敗したら「…のコピーに失敗しました」）

**親フォルダのパスをコピー:**

- 親ディレクトリパスをクリップボードにコピーし、画面の右下に「{パス・親フォルダのパスなど}をコピーしました」と出す（メインウィンドウと同じ。失敗したら「…のコピーに失敗しました」）

**親フォルダを開く:**

- エクスプローラーで親フォルダを開く（アイテムは選択しない）。フォルダが見つからないときは何もしない

**リンク先のパスをコピー (.lnkファイルのみ):**

- ショートカットのリンク先パスをクリップボードにコピーし、画面の右下に「{パス・親フォルダのパスなど}をコピーしました」と出す（メインウィンドウと同じ。失敗したら「…のコピーに失敗しました」）

**リンク先の親フォルダのパスをコピー (.lnkファイルのみ):**

- リンク先の親ディレクトリパスをクリップボードにコピーし、画面の右下に「{パス・親フォルダのパスなど}をコピーしました」と出す（メインウィンドウと同じ。失敗したら「…のコピーに失敗しました」）

**リンク先の親フォルダを開く (.lnkファイルのみ):**

- リンク先の親フォルダをエクスプローラーで開く（リンク先は選択しない）。フォルダが見つからないときは何もしない

**編集:**

- 独立した編集ウィンドウを開き、表示名・パス・引数・ウィンドウ切り替えなどを詳細編集する（コピーだけ。参照の中身はメインウィンドウの編集画面で直す）
- 欄はメインの[アイテム登録・編集](./register-modal.md)と同じ（パス欄のアイコン取得・変換、「オプション設定」の折りたたみの中の引数・カスタムアイコン、単一アイテムの「オプション設定（ウィンドウ切り替え・ウィンドウ位置）」（[対象ウィンドウ・ウィンドウ位置・開くときの動き](./register-modal.md#55-ウィンドウ切り替えウィンドウ位置を入力)）、クリップボードの取り込み欄など）。違いは次のとおり
  - タイトルは「ワークスペースアイテムの編集」。タイトル横のアイコンはメインと同じく、設定したアイコンがあればそれ、無ければ種別の絵文字
  - 保存先（タブ・データファイル）の欄が無い（保存先はワークスペース。上の保存先の帯とフッターの「〜 に登録」も出ない）
  - 種別は表示だけで変えられない（フォルダ取込は無い）
  - セットの「＋ アイテムを追加」で、データファイルのアイテムに加えてワークスペースのアイテムも選べる（[セットの編集画面](./set-editor-modals.md#2-セットに追加するアイテム)）
  - 「⚡ 試しに実行」は保存前の編集中の内容で動かし、実行の間は編集画面を開いた元のウィンドウ（ワークスペース本体か切り離しウィンドウ）を最前面に固定する（もともと固定していなければ、終わったら戻す）。クリップボードアイテムは、取り直した直後や書きかけのテキストがあっても保存済みの中身をコピーして試す。保存済みの中身が無い・実データのファイルが見つからないときだけ押せず、ツールチップ「保存したクリップボードの中身が無いので試せません」を出す（メインの登録画面は、まだ保存していない中身のときも押せない）（[試しに実行ボタンをクリック](./register-modal.md#515-試しに実行ボタンをクリック)）
  - クリップボードアイテムの実データのファイルが見つからないときは、メインと同じく内容欄に警告を出し、そのまま「保存」を押すと「保存したクリップボードの中身が見つかりません。取り込み直すか、テキストを書いてください」で止める（[内容を書く・取り込む](./register-modal.md#519-内容を書く取り込む)）
  - 削除のボタンは「ワークスペースから削除」
- 通常のアイテムは、ファイル・フォルダをドロップするとパスを置き換える（表示名などはそのまま。新しいパスの種別を判定し直す）。ほかの種別ではドロップを受けない
- 編集ウィンドウは開き元（本体または切り離しウィンドウ）と同じディスプレイの中央に 850x800（作業領域で切り詰め）で開き、開き元に対してモーダル。**ワークスペースウィンドウのサイズ・位置は変わらない**（以前はウィンドウを広げて右端へ動かしていた）
- 「保存」で変更を保存して閉じ、ワークスペース側は保存を受けて表示を読み直す。保存に失敗したときは編集ウィンドウにエラーのトーストで「ワークスペースアイテムの更新に失敗しました」と出し、開いたままにする。クリップボードを取り直していたら、保存のときに取り込んだ中身を確定する
- セットは、行が 0 件のままでは保存できない。「保存」を押すと、行の一覧の下に「セットに行を 1 つ以上入れてください」と出す（メインの登録・編集と同じ）
- 「キャンセル」と Escape は閉じるだけ（取り直したクリップボードは捨てる）
- 開いたときに編集するアイテムが見つからない（開くまでの間に削除されたなど）ときは、フォームの代わりに「編集するアイテムが見つかりません（削除された可能性があります）。」と「閉じる」ボタンを出す
- 「ワークスペースから削除」は、カードの × と同じ確認の子ウィンドウ（編集ウィンドウが親。名前は保存済みの名前。タイトル「ワークスペースから削除」、本文「「{アイテム名}」をワークスペースから削除しますか？」、赤のボタン「ワークスペースから削除」）を出し、確かめたらアイテムをワークスペースから削除して閉じる。削除に失敗したときはエラーのトーストで「ワークスペースからの削除に失敗しました」と出し、開いたままにする
- 詳細は [ウィンドウ制御](../architecture/window-control.md#アイテム編集ウィンドウ独立した子ウィンドウ)

**ワークスペースを移動:**

- サブメニューに他のワークスペース名（今のワークスペースは出さない）が並び、その下の段に、そのワークスペースのグループが並ぶ。選んだグループへアイテムを移動する（メインウィンドウの「⭐ ワークスペースに追加 ▸」と同じ選び方。[右クリックメニュー仕様書](./context-menu.md#44-ワークスペースに追加)）
  - グループはサブグループを字下げして親の下に並べ、末尾に区切り線と「➕ 新しいグループを作って入れる」（「グループ {N}」をそのワークスペースの最後に作り、そこへ移す）
  - グループが 1 つも無いワークスペースには「➕ 「未分類」グループを作って入れる」だけを出す（「未分類」グループを作って移す）
- アーカイブ済みのアイテムに対して実行した場合は、復元しつつ指定したワークスペースのグループに追加される

**メインウィンドウへ移して参照にする:**

- メインウィンドウのメニューの「⭐ ワークスペースに追加」の逆向き。ワークスペースのアイテム（コピー）をメインウィンドウのアイテム（データファイル）へ移し、ワークスペース側をその参照に変える。参照はもうメインウィンドウにあるので出さない
- サブメニューにメインウィンドウのタブが並び、選んだタブへ移す。データファイルが 2 つ以上あるタブは、その下にデータファイルが並ぶ。登録画面は開かない
- 移したアイテムは、移す先のデータファイルの末尾に新しい id で足す。ワークスペース側は id・グループ・並び順を保ったまま参照になる
- 終わるとトーストで「「{名前}」をメインウィンドウの「{タブ}」タブへ移し、ワークスペースのアイテムは参照にしました」と知らせる
- 通常アイテムで、移す先のデータファイルにパスと引数が同じアイテムが既にあれば、新しく作らずにそのアイテムを指す参照にする（メインウィンドウに重複を作らない。ウィンドウ切り替え・カスタムアイコン・常に管理者として実行が違うときは新しく足す）。トーストは「メインウィンドウの「{タブ}」タブに同じアイテムがあったので、「{名前}」はそれを指す参照にしました」
- クリップボードアイテムは、保存データを複製せず、移したアイテムが引き継ぐ
- セットは、ワークスペースのアイテムを指す行をパスを書いた行に置き換えて移す（メインウィンドウのセットはワークスペースのアイテムを探さないため）。ワークスペースの参照を指す行は、参照が指すメインウィンドウのアイテムの行にする（[ワークスペース機能](../features/workspace.md#メインウィンドウへ移す)）
- アイテムをメインウィンドウへドラッグ&ドロップしても移せる（[5.12.6](#5126-メインウィンドウへ移す)）

**ワークスペースから削除:**

- 確認の子ウィンドウを通してから、アイテムをワークスペースから完全に削除（5.9.3と同様）

### 5.12. ドラッグ&ドロップ操作

ワークスペースウィンドウでは以下のドラッグ&ドロップ操作が可能です：

- アイテムの並び替え（同じグループ内）
- アイテムのグループ間移動（`Ctrl`を押しながらドロップすると複製）
- グループの並び替え・別のグループの中への移動
- グループのウィンドウの外へのドロップ（切り離し。[5.19](#519-グループを切り離す)）
- ネイティブファイル・フォルダ・URLの追加
- メインウィンドウからのアイテム追加（ウィンドウ検索結果を含む。既定は参照、`Ctrl` を押しながらドロップするとコピー）
- アイテムをメインウィンドウへドロップして移す（[5.12.6](#5126-メインウィンドウへ移す)）

#### 5.12.1. アイテムの並び替え（同じグループ内）

##### アクション

- 同じグループ内でアイテムをドラッグ&ドロップ

##### 処理フロー

1. アイテムをドラッグ開始
2. ドラッグ中の視覚的フィードバックを表示
3. ドロップ先のアイテムにホバー時、挿入位置を表示
4. ドロップ時：
   - アイテムの順序を変更
   - データを保存
5. ドラッグを終了

##### 補足

- 別のグループのアイテムの位置にドロップすると、そのグループへ移動する（5.12.2を参照）
- `Ctrl`を押しながらドロップすると、移動ではなく複製を作る。クリップボードアイテムは保存データも複製する（元と同じデータを指したままにしない。グループの複製と同じ）

#### 5.12.2. アイテムのグループ間移動

##### アクション

- アイテムを別のグループヘッダーまたはグループ内にドラッグ&ドロップ（`Ctrl`を押しながらドロップすると、移動せずに複製）

##### 処理フロー

1. アイテムをドラッグ開始
2. ドラッグ中の視覚的フィードバックを表示
3. ドロップ先のグループにホバー時、グループをハイライト表示
4. ドロップ時：
   - ドロップ先のグループにアイテムを移動
   - データを保存
5. ドラッグを終了

##### ドロップ先の種類

- **グループヘッダー**: ドロップした位置（ヘッダーの高さ方向）で挙動が変わる。上端付近はそのグループの前、中央はそのグループの中（グループ内へ移動）、下端付近はそのグループの後に置く（深さの上限でサブグループにできないグループは、上半分が前、下半分が後）
- **グループ内のアイテム**: そのアイテムの位置に挿入
- トップレベルのグループの前後（グループの外）には置けない。そこへ落としても移動しない

#### 5.12.3. グループの並び替え

##### アクション

- グループヘッダー（名前部分以外）をドラッグ&ドロップ

##### 処理フロー

1. グループヘッダーをドラッグ開始
2. ドラッグ中の視覚的フィードバックを表示
3. ドロップ先のグループにホバー時、挿入位置を表示
4. ドロップ時：
   - グループの順序を変更
   - データを保存
5. ドラッグを終了

##### ドロップ先の種類

- **グループヘッダーの上端付近・下端付近**（高さの上 25%・下 25%）: そのグループの前・後に並べる。ドロップ先のグループと同じ階層へ移る（サブグループをトップレベルのグループの前後に落とすと、トップレベルになる）
- **グループヘッダーの中央**（高さの中央 50%）: そのグループの中へ入れ、サブグループにする
- 中へ入れると入れ子が 2 階層を超えるとき（ドラッグしたグループ自身がサブグループを持つときも含む）は、中央の判定がなく、上半分が前・下半分が後になる
- 自分の子孫のグループの中へは入れられない（ドロップしても移動しない）
- どこにも受け付けられない場所（ウィンドウの外）でドロップすると、グループを切り離す（[5.19](#519-グループを切り離す)）

##### 注意

- グループ名部分をドラッグすると編集モードに入る可能性があるため、グループ名以外の部分をドラッグしてください

#### 5.12.4. ネイティブファイル・フォルダ・URLの追加

##### アクション

- エクスプローラーからファイル・フォルダをドラッグ&ドロップ
- ブラウザからURLをドラッグ&ドロップ

##### 処理フロー

**ドラッグ中（ドロップ前）:**

1. ドラッグ状態を更新
2. 半透明オーバーレイを表示
3. ドラッグ中の視覚効果を適用

**ドロップ時:**

1. ドロップされたファイル・フォルダ・URLを取得
2. ドロップ先を判定：
   - グループヘッダーまたはグループ内：そのグループに追加
   - その他（グループの外）：グループのあるワークスペースでは追加せず、警告のトーストで「グループの上に落としてください（グループの外には置けません）」と知らせる。グループが 1 つも無いワークスペースでは、「未分類」という名前のグループを作って入れる
3. パス・名前・追加日時を持つアイテムを作り、ドロップ先のグループに入れてワークスペースに追加
4. データを保存
5. 追加できたものを 1 件ずつトーストで知らせる。追加できなかったもの（ファイルが無い・書き込みに失敗したなど）は、件数と名前をエラーのトーストでまとめて知らせる
6. ドラッグ状態を解除してオーバーレイを非表示

ワークスペースを書き換える操作（追加・削除・名前の変更・移動・並べ替え・アーカイブなど）が失敗したときは、どの操作でもトーストで知らせる（[IPC チャンネル](../architecture/ipc-channels.md)の「失敗を利用者に知らせる」）。

##### 対応形式

- **ファイル**: .exe, .lnk, .pdf, .docx, などすべてのファイル
- **フォルダ**: ディレクトリ
- **URL**: http://, https:// で始まるもの（カスタムURIスキーマ（obsidian://, vscode://, など）はドロップでは追加できない。追加するには`Ctrl+V`でペーストする）

#### 5.12.5. メイン画面からのアイテム追加

##### アクション

- メイン画面のアイテム一覧のアイテムをワークスペースウィンドウのグループにドラッグ&ドロップ

##### 処理フロー

1. ドラッグしたアイテムを、ドロップ先のグループに追加する（メインウィンドウ側のアイテムはそのまま残る。グループのあるワークスペースでグループの外に落としたときは、[5.12.4](#5124-ネイティブファイルフォルダurlの追加) と同じく追加せずに知らせる）。既定は参照で、`Ctrl` を押しながらドロップするとコピー（[ワークスペース機能 - 参照とコピー](../features/workspace.md#参照とコピー)）
   - フォルダ取込で展開したアイテムは参照できないので、コピーで追加し、トーストで「参照できないアイテムなので、コピーで追加しました」と知らせる
   - コピーのクリップボードアイテムは保存データも複製し、メインウィンドウ側と共有しない（片方を消しても、もう片方は復元できる）。元の保存データが無くて複製できないときは、元を指したまま追加する。参照は複製せず、メインウィンドウのアイテムの保存データを使う
   - ウィンドウ検索結果は、パスの無い単一アイテム（対象ウィンドウは exe 名とタイトルの一部一致。決め方はセットの行と同じ＝[セットの編集画面 3.4](./set-editor-modals.md#34-ウィンドウを選んで追加する)。実行ファイルのパスは入れない）に変換して追加する
   - ウィンドウ検索結果を `Ctrl` を押しながらドロップしたときだけ、今のウィンドウ位置も記録する（既定は切り替えるだけ。ウィンドウ検索結果はもともとコピー）
2. 追加したことをトーストで知らせる（ウィンドウ位置を記録したときは「開いているときに、このウィンドウを記録したウィンドウ位置に戻します」と添える）。失敗したときはトーストで「ワークスペースへの追加に失敗しました」と表示する

##### 対応アイテム

- 通常アイテム・セット・クリップボード（メイン画面のアイテム。パスの無い単一アイテムを含む）
- ウィンドウ検索結果（開いているウィンドウ）。右クリックの「⭐ ワークスペースに追加 ▸」「⭐ ウィンドウ位置ごとワークスペースに追加 ▸」（入れるグループをその場で選ぶ）でも同じ結果になる

#### 5.12.6. メインウィンドウへ移す

##### アクション

- ワークスペースウィンドウ（切り離しウィンドウを含む）のアイテムを、メインウィンドウへドラッグ&ドロップ

##### 処理フロー

1. メインウィンドウの上にドラッグしている間、メインウィンドウに「ドロップしてメインウィンドウへ移す（ワークスペースのアイテムは参照になります）」と表示する
2. ドロップすると、メインウィンドウで今選んでいるタブの先頭のデータファイルへ移し、ワークスペース側をその参照に変える。登録画面は開かない（[メインウィンドウ - ドラッグ&ドロップ操作](./main-window.md#518-ドラッグドロップ操作)）
3. 終わるとトーストで知らせる（右クリックの「🚀 メインウィンドウへ移して参照にする」と同じ。[5.11](#511-コンテキストメニュー操作)）
4. 参照をドロップしたときは移さず、警告のトーストで「「{名前}」はメインウィンドウのアイテムを参照しています（もうメインウィンドウにあります）」と知らせる。元のアイテムが見つからない参照のときは「「{名前}」は元のアイテムが見つからないので、メインウィンドウへ移せません」と知らせる

##### 制限

- 対象は 1 つのアイテムだけ。グループをドラッグしても移さない
- メインウィンドウのタブの上にドロップしても、移す先は選べない（選ぶときは右クリックから）
- メインウィンドウの登録画面が開いている間は、メインウィンドウはドロップを受けない

### 5.13. Ctrl+Vでペースト

#### アクション

- Ctrl+Vキーを押下（v0.5.1以降）、または余白の右クリックの「📋 貼り付け」（[5.22](#522-余白を右クリック)）

#### 処理フロー

1. クリップボードに入っている形式（テキスト・HTML・リッチテキスト・画像・ファイル）を確かめる
2. 中身で振り分ける：
   - **ファイル**（エクスプローラーでコピー）: コピーしたファイル・フォルダのパスでアイテムを追加
   - **テキスト**: 1 行で URL → URL アイテム（ファビコンを取得）／カスタム URI → カスタム URI のアイテム／Windows のパス → そのパスのアイテム／それ以外・複数行 → クリップボードアイテム
   - **画像・HTML・リッチテキストだけ**: クリップボードアイテム
3. クリップボードアイテムは、クリップボードの中身を保存してから追加する
4. 貼り付け先のグループ（今のワークスペースで最後にクリックしたグループ。見出しに黄色の枠が付く）に追加し、ワークスペースの中のトーストで「{名前} を「{グループ名}」に追加しました」と知らせる（ファイルを 2 つ以上貼ったときは「{n} 件のアイテム を…」）。閉じたグループに貼ったときは、グループを開いて入ったものを見せる
   - ワークスペースを切り替えると、貼り付け先の選択は外れる（前のワークスペースのグループには入らない）
   - グループの外（タブの並び・一覧の余白など）を左クリックしても外れる。ボタン・入力欄・ダイアログ・メニュー・ウィンドウの縁（大きさを変えるつまみ）では外さない。右クリックの「📋 貼り付け」は左クリックを伴わないので、選んだグループに貼れる（A3-186）
   - 黄色の枠は前面のウィンドウにだけ出す（`Ctrl+V` が効くのは前面のウィンドウだけ。本体と切り離しウィンドウを両方出したとき、両方に枠が出てどこに貼り付くか分からなかった。A3-186）。選んだグループは覚えておき、ウィンドウが前面に戻ると枠も戻す
   - グループのあるワークスペースでグループを選んでいないときは追加せず、警告のトーストで「貼り付ける先のグループの見出しをクリックしてから、貼り付けてください」と知らせる
   - グループが 1 つも無いワークスペースでは、「未分類」という名前のグループを作って入れる
5. 入力欄にフォーカスがあるときは何もしない（通常の貼り付けになる）

#### 対応形式

- **ファイル・フォルダ**: エクスプローラーでコピーしたファイル・フォルダ
- **URL / カスタム URI / Windows のパス**: テキスト形式
- **それ以外のテキスト・画像**: クリップボードアイテム（起動時にクリップボードへ書き戻す）

#### 制限

- パスの実在は確かめない（ネットワークパスの応答待ちを避ける）
- 画像のサムネイルはアイコンにしない（既定の 📋 アイコン）

### 5.17. ワークスペースタブ操作

ウィンドウ上部のタブバーでワークスペース（タブ）を管理します。

#### 5.17.1. タブをクリック

##### アクション

- タブバーのタブをクリック

##### 処理フロー

1. クリックしたワークスペースをアクティブにする
2. そのワークスペースに属するグループ・アイテムを表示
3. アクティブなワークスペースを記憶し、次にワークスペースウィンドウを開いたときもそのタブを選ぶ（そのワークスペースが削除されていれば先頭のタブを選ぶ）

#### 5.17.2. タブを追加

##### アクション

- ヘッダーの ➕ のメニュー（[5.4](#54-追加メニューをクリック)）、タブの右クリック、またはタブの並びの空いた所（タブの無い所）の右クリックから「➕ ワークスペースを追加」を選択。空いた所の右クリックのメニューは「➕ ワークスペースを追加」だけ

##### 処理フロー

1. 「ワークスペース {N}」（Nは現在のワークスペース数+1）という名前で新しいワークスペースを作成
2. タブバーの末尾に追加

#### 5.17.3. タブの名前を変更

##### アクション

- タブをダブルクリック、または右クリック → コンテキストメニューから「✏️ 名前を変更」を選択

##### 処理フロー

1. タブ名の編集モードに入る
2. テキスト入力フィールドに変更、現在の名前を選択状態で表示
3. Enter キー（日本語入力の変換を確定する Enter では確定しない）またはフォーカスを外すと確定、Escape キーでキャンセル。前後の空白は除き、空のまま、または変更なしなら元の名前に戻る

#### 5.17.4. タブを削除

##### アクション

- タブを右クリック → コンテキストメニューから「🗑️ 削除」を選択

##### 処理フロー

1. 確認ウィンドウ（タイトル「ワークスペースの削除」）を危険操作の表示で、ほかの確認と同じ別の小さなウィンドウに出す（ワークスペースウィンドウの高さが低くても切れない）。文面は「ワークスペース「{ワークスペース名}」を削除しますか？」と、次の行に「所属するグループとアイテムもすべて削除されます。」。ボタンは「削除」「キャンセル」
2. 「削除」の場合：
   - ワークスペースと、それに属するグループ・アイテムをすべて削除
   - データを保存
3. キャンセルの場合：処理を中止

##### 表示条件

- ワークスペースが2つ以上あるときだけ、コンテキストメニューに「🗑️ 削除」が表示される（最後の1つは削除不可）

#### 5.17.5. タブを並べ替え

##### アクション

- タブをドラッグ&ドロップ

##### 処理フロー

1. タブのドラッグを開始
2. ドロップ先のタブの位置に応じて挿入位置を決定
3. ワークスペースの並び順を更新してデータを保存

#### 5.17.6. アーカイブタブとの関係

- タブバーの「🗄️」ボタン（ワークスペースタブの右。右端に固定）はワークスペースタブとは別枠で、アーカイブ一覧表示に切り替える（5.5を参照）
- アクティブなワークスペースタブとアーカイブ表示は排他（同時に選択状態にはならない）

#### 5.17.7. タブを右クリックして「メインウィンドウのアイテムとつなぐ」

##### アクション

- タブを右クリック → コンテキストメニューから「🔗 メインウィンドウのアイテムとつなぐ…」を選択（「✏️ 名前を変更」の次。ワークスペースが 1 つでも出る）

##### 処理フロー

1. そのワークスペースの「メインウィンドウのアイテムとつなぐ」ウィンドウを開く（[5.21](#521-メインウィンドウのアイテムとつなぐ)）

#### 5.17.8. タブを右クリックして追加・すべて展開／折りたたむ

##### アクション

- タブを右クリック → コンテキストメニューから選択。メニューの並びは「✏️ 名前を変更」「🔗 メインウィンドウのアイテムとつなぐ…」、区切り線、「➕ グループを追加」「➕ ワークスペースを追加」、区切り線、「🔽 すべて展開」「🔼 すべて折りたたむ」、区切り線と「🗑️ 削除」（ワークスペースが 2 つ以上のとき）

##### 処理フロー

1. 「➕ グループを追加」: 右クリックしたタブのワークスペースにグループを追加する（選んでいないタブなら、そのタブに切り替えてから。[5.4](#54-追加メニューをクリック)）
2. 「➕ ワークスペースを追加」: 新しいワークスペースを作る（[5.17.2](#5172-タブを追加)）
3. 「🔽 すべて展開」「🔼 すべて折りたたむ」: 右クリックしたタブのワークスペースのグループをすべて開く・閉じる（選んでいないタブなら、そのタブに切り替えてから。[5.2](#52-すべて展開ボタンをクリック)・[5.3](#53-すべて折りたたむボタンをクリック)）

### 5.18. 設定メニューを開く

#### アクション

- ヘッダーの「⚙️」ボタンをクリックしてメニューを開き、項目を選ぶ（メニューの外をクリックすると閉じる）
- メニューの幅は項目の長さに合わせる（ウィンドウより広くなるときだけ折り返す）。⚙ ボタンのすぐ下に、ヘッダーの右端にそろえて出す

#### メニュー項目と処理

| 項目 | 処理 |
| --- | --- |
| ⚙️ 設定 | 管理ウィンドウを設定タブで開く |
| ⬅️ 左端に寄せる | 設定の「表示する場所」を「左端」にし、マウスカーソルがあるディスプレイを配置先にする（設定に保存し、すぐに移動する） |
| ➡️ 右端に寄せる | 設定の「表示する場所」を「右端」にし、マウスカーソルがあるディスプレイを配置先にする（設定に保存し、すぐに移動する） |

- 「⚙️ 設定」と「左端に寄せる」の間に区切り線を入れる
- メニューを開くときに設定を読み、今の「表示する場所」が左端なら「左端に寄せる」に、右端なら「右端に寄せる」に ✓ を付ける（「最後に置いた場所」のときはどちらにも付けない）

表示位置などの設定項目は [設定ファイルの形式 - ワークスペース設定](../architecture/file-formats/settings-format.md#38-ワークスペース設定) を参照。

### 5.19. グループを切り離す

#### アクション

- グループヘッダー（名前部分以外）をドラッグし、ワークスペースウィンドウの外でドロップする
- 切り離せるのは一番上のグループだけ。サブグループは右クリックに項目が出ず、外へドロップしても切り離さない（切り離したいときは、一番上のグループに移してから）。前に切り離したサブグループや、切り離したあとでサブグループにしたものは、次に起動したときに開き直さない
- グループヘッダーを右クリック → 「🪟 別のウィンドウに切り離す」を選ぶ（アーカイブタブでは出ない）。すでに切り離してあるグループでは、項目名が「🪟 切り離しウィンドウを表示」になる

#### 処理フロー

1. そのグループを表示する切り離しウィンドウを開く。すでに開いていれば、そのウィンドウを前面に出すだけ
2. 位置は、前回の位置が画面内にあればそこ、なければドロップした位置（右クリックのときはメニューを選んだ位置）の近く（幅 380px）
3. ワークスペースウィンドウ側にも、同じグループはそのまま表示される（同じデータを両方から操作できる）

#### 切り離しウィンドウの表示

- 切り離したグループと、その子孫のサブグループ・アイテムだけを表示する。ヘッダー・タブバー・絞り込みバーはない
- 一番上の行は切り離したグループの見出しで、右端に「📌」と「×」を置く。折りたたむと、この 1 行だけになる。グループの件数は出さない（サブグループも）
- 一番上の見出しを押したまま動かすと、ウィンドウが動く（4px 以上動かしたら、タイトルバーを掴んだときと同じ Windows の移動に切り替える。画面端への吸着も効く）。動かさずに離せばクリックで折りたたみ／展開、右クリックはグループのメニュー。一番上の見出しはドラッグで並べ替えない。アイテムやサブグループのあいだのすき間を掴んでも動かせる
- ウィンドウのタイトルは「{グループ名} - QuickDashLauncher」で、タスクバーや Alt+Tab で見分けられる（グループ名を変えると追従する）
- 高さは内容に合わせて自動で変わる。8 方向のハンドルでサイズも変えられる
- アイテムの起動・名前の変更・右クリックメニュー・ドラッグによる並べ替えなどは、ワークスペースウィンドウと同じように使える。`Ctrl+F` の絞り込みは使えない

#### 📌 の 3 段階

📌 のクリックで表示固定のオン・オフ、右クリックのメニューで常に最前面を選ぶ（メインウィンドウ・ワークスペースと同じ）。ツールチップは今の段階を表示する。

| モード | 動作 |
| --- | --- |
| なし | メインウィンドウと一緒に出て、一緒に隠れる |
| 表示固定 | メインと一緒に隠れない。ホットキーでメインウィンドウを出すとき、手前に出る |
| 常に最前面 | 表示固定に加えて、ほかのウィンドウより前面に表示する |

隠れる条件の詳細は [ウィンドウ制御 - ウィンドウ非表示の判定](../architecture/window-control.md#ウィンドウ非表示の判定) を参照。

#### 閉じる・復元

- 「×」で閉じると、そのグループの切り離しの状態（位置・📌・折りたたみ）を忘れる。切り離したグループのヘッダーを右クリック → 「📥 ワークスペースに戻す」も同じ動き（切り離しウィンドウの中のサブグループの右クリックには出ない）
- アプリを終了したときに開いていた切り離しウィンドウは、次に起動したときに同じ位置・📌 で開き直す。📌 ありのものはすぐに出し、なしのものは隠したまま作って、最初のホットキーでメインと一緒に出す（グループが残っているものだけ。ワークスペースを開いていなくても開き直す。表示位置の設定が「メインウィンドウと同じディスプレイ」（既定）なら、ピン留めしていないものはメイン側のディスプレイの同じ位置に開く）
- 位置・📌・折りたたみは `workspace-ui-state.json` に保存する（[ワークスペースファイル形式](../architecture/file-formats/workspace-format.md#4-workspace-ui-statejson)）
- 全仮想デスクトップへの表示と、モニター端への吸着（スナップ）は設定で変える。全仮想デスクトップへの表示は、表示するたびに当て直す（[設定ファイルの形式 - ワークスペース設定](../architecture/file-formats/settings-format.md#38-ワークスペース設定)）

### 5.20. 指すアイテムを選ぶ

#### アクション

- 参照を右クリック → 「🔁 別のアイテムを指す…」（元のアイテムが見つからない参照も同じ）
- コピーを参照にするときは、右クリックの「🚀 メインウィンドウへ移して参照にする」か、タブの右クリックの「🔗 メインウィンドウのアイテムとつなぐ…」（[5.21](#521-メインウィンドウのアイテムとつなぐ)）を使う

#### 処理フロー

1. 「指すアイテムを選ぶ」の画面を、独立した子ウィンドウで開く。開き方（位置・大きさ・モーダル）は[グループに追加するアイテム](#589-グループを右クリックしてアイテムを追加)と同じ。同じアイテムの画面が開いていれば前面に出す
2. 画面の上に説明の帯「選んだメインウィンドウのアイテムを指す参照にします。表示とメモはメインウィンドウのアイテムのものになります。」、見出しは「「{名前}」が指すメインウィンドウのアイテム」（ウィンドウのタイトルも同じ）
3. 一覧には、参照できるメインウィンドウのアイテム（すべてのタブの通常アイテム・パスの無い単一アイテム・セット・クリップボード。フォルダ取込で展開したアイテムは出さない）を出す。検索欄とタブでの絞り込みは[セットに追加するアイテム](./set-editor-modals.md#2-セットに追加するアイテム)と同じで、選べるのは 1 つだけ
4. パスと引数（大文字・小文字と末尾の区切り文字は区別しない）が右クリックしたアイテムと同じメインウィンドウのアイテムがあれば、一覧を「同じパスのアイテム」「ほかのアイテム」に分け、同じパスのものを先に並べる（コピーの通常アイテムのとき。無ければ分けない）
5. 参照の今の指す先は「今の指す先」と出し、選べない
6. 「選ぶ」で、右クリックしたアイテムを、選んだアイテムを指す参照に置き換える（id・位置・グループ・追加日時は保つ）
   - コピーのとき: 表示名がメインウィンドウの表示名と違えば、ワークスペースでの表示名にする。コピーのメモは、メインウィンドウのアイテムにメモが無ければメインウィンドウのアイテムへ移す（両方にあれば、コピーのメモは消える）。トーストで「「{名前}」をメインウィンドウのアイテムの参照にしました」
   - 参照のとき: ワークスペースでの表示名は引き継ぐ。トーストで「「{名前}」の指すアイテムを変えました」
7. 置き換えたら画面を閉じ、ワークスペース側は表示を読み直す。失敗したときはエラーのトーストで知らせ、画面は開いたままにする
8. 「キャンセル」・Escape・ウィンドウの × では何も変えずに閉じる
9. 開いたときに右クリックしたアイテムが見つからない（開くまでの間に削除されたなど）ときは、一覧の代わりに「ワークスペースのアイテムが見つかりません（削除された可能性があります）。」と「閉じる」ボタンを出す

### 5.21. メインウィンドウのアイテムとつなぐ

#### アクション

- ワークスペースのタブを右クリック → 「🔗 メインウィンドウのアイテムとつなぐ…」（[5.17.7](#5177-タブを右クリックしてメインウィンドウのアイテムとつなぐ)）

#### 処理フロー

「つなぐ」は、コピーを参照にすること（[用語集](../architecture/glossary.md)の「参照」）の画面での言い方。

1. 「メインウィンドウのアイテムとつなぐ」の画面を、独立した子ウィンドウで開く。開き方は [5.20](#520-指すアイテムを選ぶ) と同じ。同じワークスペースの画面が開いていれば前面に出す
2. 画面の上に説明の帯を出す。左に「ワークスペース 🔗 メインウィンドウ」の図、右に見出し「同じアイテムが {n} 件、メインウィンドウにもあります」と「つなぐと、メインウィンドウで直したパスやメモがワークスペース「{ワークスペース名}」にも反映されます。ワークスペースでの名前と並び順はそのままです。」
3. 対象は、そのワークスペース（アーカイブを除く）のコピーの通常アイテムのうち、パスと引数（大文字・小文字と末尾の区切り文字は区別しない）が同じメインウィンドウのアイテムがあるもの。2 つの区分に分けて、1 行ずつチェックボックス付きで出す
   - 「✋ どれとつなぐか選んでください {n}」（上）: 同じパスのメインウィンドウのアイテムが 2 件以上ある行。行の枠は点線
   - 「✓ そのままつなげます {n}」（下）: 候補が 1 件の行。区分の右に「すべて選ぶ」「すべて外す」（この区分の行だけを変える）。行の上に列の見出し「ワークスペース」「メインウィンドウ」
4. 行は「☐ {アイコン} {名前} 🔗 {つなぐ先}」の左右 2 列。チェックした行は青い面にし、🔗 を濃くする。アイコンは先頭の候補のアイコンをアイコンのキャッシュから読む（無ければ種別の絵文字。取りに行かない）
   - 左の名前の下: 表示名がメインウィンドウの表示名と違えば「名前はそのまま」（つないだあと、ワークスペースでの表示名になる）、同じなら「名前もメインウィンドウと同じ」。選ぶ区分の行は「メインウィンドウに候補が {n} つ」
   - 右: 候補が 1 件の行はメインウィンドウの表示名と、下に小さな札で「タブ: {タブ名}」と次のもの
     - メモがコピーにだけある: 「📝 メモをメインウィンドウへ移す」（つなぐとき、実際にメインウィンドウのアイテムへ移す）
     - メモが両方にあって違う: 「⚠ メモが両方にあって違う（つなぐとこのメモは消えます）」。この行は既定でチェックを外す。候補が 1 件の行のうち、同じメインウィンドウのアイテムへメモを移す行が 2 件以上あるときは、メモを移せるのは一覧で先の 1 件だけなので、2 件目からはこの表示になり、チェックを外す
     - ウィンドウ切り替え・カスタムアイコン・常に管理者として実行が違う: 「⚠ ウィンドウ切り替え・アイコン・管理者として実行が違う（つなぐとメインウィンドウのものになります）」
   - 右（選ぶ区分の行）: つなぐ先を選ぶ欄（「どれとつなぐ？」と候補の「{表示名}（タブ: {タブ名}）」）。既定ではチェックできず、選ぶとチェックして点線の枠を外す（「どれとつなぐ？」に戻すとチェックを外し、点線に戻す）
5. 候補が 1 件の行は既定でチェックする（上のメモが両方にあって違う行を除く）
6. 選ぶ区分にまだ選んでいない行があれば、ボタンの左に「選んでいない {n} 件はつなぎません」と出す
7. パスで比べられないコピー（クリップボード・セット・パスの無い単一アイテム）があれば、一覧の下に折りたたんだ「ここに出ないアイテム（{n} 件）」を出す。開くと「クリップボード・セット・パスの無い単一アイテムは、メインウィンドウのどれと同じかを見分けられないので出していません。1 件ずつつなぐときは、アイテムの右クリックの「🚀 メインウィンドウへ移して参照にする」を使います。」
8. 対象が無いときは、説明の帯と一覧の代わりに「メインウィンドウとつなげるアイテムはありません。」と出す
9. 「{n} 件をつなぐ」（何もチェックしていなければ押せない）で、チェックした行を参照に変える。変え方は [5.20](#520-指すアイテムを選ぶ) でコピーを参照にするときと同じ。トーストで「{n} 件をメインウィンドウのアイテムとつなぎました」と知らせて閉じる。途中で失敗したときは、変えたものは残し、エラーのトーストで知らせて画面は開いたままにする
10. 「キャンセル」・Escape・ウィンドウの × では何も変えずに閉じる
11. 開いたときにワークスペースが見つからないときは、一覧の代わりに「ワークスペースが見つかりません（削除された可能性があります）。」と「閉じる」ボタンを出す

### 5.22. 余白を右クリック

#### アクション

- グループ・アイテムの無い所（一覧の余白、空のワークスペースの表示）を右クリック

#### 処理フロー

1. 右クリックした位置にOSのネイティブメニューを出す。グループ・アイテムの上の右クリックは、それぞれのメニュー（[5.8](#58-グループヘッダー操作)・[5.11](#511-コンテキストメニュー操作)）になる
2. 選んだ項目を今のワークスペースに対して行う

#### メニュー項目

| メニュー項目 | 説明 |
| --- | --- |
| **➕ グループを追加** | 今のワークスペースにグループを追加（[5.4](#54-追加メニューをクリック)） |
| **📋 貼り付け** | `Ctrl+V` と同じ（[5.13](#513-ctrlvでペースト)）。右端に Ctrl+V を添える |
| **🔽 すべて展開**・**🔼 すべて折りたたむ** | ヘッダーの 🔽・🔼 と同じ（[5.2](#52-すべて展開ボタンをクリック)・[5.3](#53-すべて折りたたむボタンをクリック)） |

並びは「➕ グループを追加」「📋 貼り付け」、区切り線、「🔽 すべて展開」「🔼 すべて折りたたむ」の順。以前あった「未分類」の見出しの右クリック（「➕ アイテムを追加 ▸」「📁 グループにまとめる」）は、未分類の区画ごと無くなった（[5.10](#510-未分類セクション操作廃止)）。

#### 表示条件

- ワークスペース本体だけ。アーカイブ表示中と切り離しウィンドウでは出さない

## 6. キーボード操作

| キー | 動作 |
| --- | --- |
| `Ctrl+W` | メインウィンドウで押すと、ワークスペースウィンドウの表示/非表示を切り替える（全仮想デスクトップに表示しない設定で、表示したまま別のデスクトップにあるときは、隠さずに今のデスクトップへ呼び寄せる。Win+D（デスクトップの表示）で最小化されているときは、隠さずに元の大きさに戻す） |
| `Ctrl+F` | 絞り込みバーを開き、入力欄にフォーカスする（切り離しウィンドウでは効かない） |
| `Ctrl+V` | クリップボードからファイル・フォルダ・URL・テキスト・画像をペーストして追加（v0.5.1以降。テキスト・画像はクリップボードアイテム） |
| `Enter` | 編集モードで名前を確定（日本語入力の変換を確定する Enter は除く） |
| `Escape` | 絞り込みバーの入力欄にフォーカスがあるとき: キーワードをクリアして絞り込みバーを閉じる。編集モード中: 編集をキャンセル |
