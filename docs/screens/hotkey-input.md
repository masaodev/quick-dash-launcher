## 1. 概要

ホットキー入力コンポーネントは、起動ホットキーとアイテム検索ホットキー（管理ウィンドウでは「ウィンドウ検索で起動」）の設定に使う専用入力フィールドです。キーボードのキー組み合わせを視覚的に入力でき、リアルタイムでバリデーションを実行します。

### 主要機能

- **キー録画**: クリックして録画モードに入り、押したキーを記録
- **修飾キー対応**: Ctrl、Alt、Shift、CmdOrCtrlの組み合わせ
- **リアルタイムバリデーション**: 入力されたホットキーの有効性をチェック
- **視覚的フィードバック**: 録画中の状態表示

## 4. 機能詳細

### 4.1. 録画モード開始

#### アクション

- 入力フィールドをクリック

#### 処理フロー

1. 入力が無効にされているときは何もしない
2. 録画モードに入る
3. それまでに記録したキーを消す
4. 入力フィールドにフォーカスする

#### 表示条件

- 通常時（録画中でない）: 入力フィールドにホットキーの値（例: `Alt+Space`）を表示する。値がないときは案内文（既定は「ホットキーを入力...」。呼び出し元が変えられる）を表示する。クリックで録画を開始する
- 録画中（キー未入力）: 入力フィールドの見た目が変わり、「キーを押してください...」と表示する。入力フィールドの横に「録画中...」とキャンセルボタンが出る
- 録画中（キー入力あり）: 押したキーを表示する（[4.2](#42-キー入力処理)）
- 入力が無効のとき: 入力フィールドが無効の見た目になり、クリックしても録画モードに入らない。クリアボタンも押せない

### 4.2. キー入力処理

#### 対応キー

| キータイプ         | 対応キー                                     | 正規化                  |
| ------------------ | -------------------------------------------- | ----------------------- |
| 修飾キー           | Control → Ctrl、Meta → CmdOrCtrl、Alt、Shift | あり                    |
| 英数字キー         | A-Z、0-9                                     | 大文字に変換            |
| ファンクションキー | F1-F12                                       | なし                    |
| 特殊キー           | Space、Enter、Tab、Escape、Delete、Backspace | あり（例: ` ` → Space） |

上の表にないキーは無視されます。同じキーを複数回押しても1つとして数えます。

#### 処理フロー（キーを押したとき）

1. 録画中でなければ何もしない
2. デフォルト動作とイベント伝播を抑止
3. キーを正規化する（上の表のとおり）
4. 修飾キーの場合：入力中のキーに加える
5. 英数字キーの場合：大文字に変換して加える
6. ファンクションキーの場合：そのまま加える
7. 特殊キーの場合：そのまま加える

#### 処理フロー（キーを離したとき）

1. 録画中でなければ何もしない
2. デフォルト動作とイベント伝播を抑止
3. 入力中のキーが2つ以上あるかを確かめる
4. 修飾キーと非修飾キーの両方があるかを確かめる
5. 両方ある場合：
   - 修飾キー、非修飾キーの順に「+」でつないだホットキーを作る
   - そのホットキーを新しい値として呼び出し元に渡す
   - 録画モードを終了する
   - フォーカスを外す

#### 表示条件

- 録画中にキーを押すと、押したキーを「 + 」でつないで入力フィールドに表示する（例: `Ctrl + Alt`）。確定するまでキーの追加を受け付ける

### 4.3. ホットキー確定条件

有効なホットキーとして確定するには:

1. 2つ以上のキーが押されている
2. 少なくとも1つの修飾キーが含まれる
3. 少なくとも1つの非修飾キーが含まれる

#### 有効な例

- `Ctrl+A`
- `Alt+Space`
- `Ctrl+Shift+F1`
- `Ctrl+Alt+Delete`

#### 無効な例

- `A`（修飾キーなし）
- `Ctrl+Shift`（非修飾キーなし）
- `Ctrl`（キーが1つだけ）

修飾キーの数に上限はなく、3つ以上の修飾キーを含むホットキーも確定します。ただし、確定したあとのバリデーション（[4.4](#44-バリデーション)）で形式エラーになります。

### 4.4. バリデーション

#### 処理フロー

1. ホットキーの値が変わると、値を検証する
2. 結果（有効か無効か、無効ならその理由）を呼び出し元に通知する

#### バリデーション内容

ホットキーの値に対して以下がチェックされます。他のアプリケーションとの競合やシステム予約キーかどうかは確認しません。値が空のときは検証せず、下の「バリデーション結果」のとおり扱います。

| チェック                                                                                                                                                                            | 無効のときのメッセージ             |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| 形式が「修飾キー + 1つ以上のキー」でない（先頭は修飾キー。2つ目は修飾キーまたはキー、3つ目以降はキーだけ。キーは英数字1文字、Space、Enter、Tab、Escape、Delete、Backspace、F1-F12） | ホットキーの形式が正しくありません |

修飾キーは2つまでです。3つ以上含むホットキー（例: `Ctrl+Shift+Alt+A`）は形式エラーになります。

#### バリデーション結果

| 結果                                       | 呼び出し元への通知                         |
| ------------------------------------------ | ------------------------------------------ |
| 有効                                       | 有効                                       |
| 無効                                       | 無効と、その理由のメッセージ               |
| 検証そのものに失敗                         | 無効と、「ホットキーの検証に失敗しました」 |
| 値が空（呼び出し元が空を有効としている）   | 有効                                       |
| 値が空（呼び出し元が空を有効としていない） | 通知しない                                 |

### 4.5. 録画キャンセル

#### アクション

- 「キャンセル」ボタンをクリック、または入力フィールドからフォーカスを外す

録画中にEscapeやTabを押してもキャンセルにはならず、キーとして記録されます。

#### 処理フロー

1. 録画モードを終了する（ホットキーの値は変えない）
2. 入力中のキーを消す
3. 録画中インジケーターを非表示にする

## 5. キーボード操作

入力フィールドに文字を直接タイピングして入力することはできません。ホットキーは録画モード（[4.1](#41-録画モード開始)）で押したキーから作ります。

| キー                    | 動作                                                                                                   |
| ----------------------- | ------------------------------------------------------------------------------------------------------ |
| Tab（録画中でないとき） | 入力フィールドにフォーカスを移す／外す。フォーカスが移っただけでは録画は始まらない（クリックで始まる） |
| 任意のキー（録画中）    | キーとして記録する（[4.2](#42-キー入力処理)）。Escape や Tab もキャンセルにはならず記録される          |
