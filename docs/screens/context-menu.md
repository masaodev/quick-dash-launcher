## 1. 概要

右クリックメニューは、メインウィンドウのアイテムリストで右クリックしたときに表示される**ネイティブElectronメニュー**です。アイテムのパス操作や編集機能を提供します。

ウィンドウ検索結果（ウィンドウ検索モードで一覧に出る、開いているウィンドウ）を右クリックしたときは、本書のメニューではなく別のメニューが表示されます。詳細は[メインウィンドウ仕様書のウィンドウ検索モード](./main-window.md#526-ウィンドウ検索モード)を参照してください。

メニューは右クリックしたアイテムに合わせて、その都度組み立てられます。アイテムの種類と、ショートカット（.lnk）・メモの有無で表示する項目が変わります（[3. 画面項目一覧](#3-画面項目一覧)）。

本書では、次の 2 つのメニューも扱います。

- **一覧の余白のメニュー**: メインウィンドウの一覧の、アイテムの無い所を右クリックしたときのメニュー（[4.12](#412-一覧の余白の右クリック)）
- **文字入力欄のメニュー**: すべてのウィンドウの文字入力欄を右クリックしたときのメニュー（[4.13](#413-文字入力欄の右クリック)）

OS 標準のメニューなので、表示と閉じ方は次のとおりです。

- カーソル位置に表示され、画面の端やウィンドウの外でも切れない
- 項目をクリックすると、メニューが閉じてその操作を実行する
- メニューの外をクリックすると、何もせずに閉じる

**キーボードショートカット**: Escapeキーでメニューを閉じることができます。

### 主要機能

- **パスのコピー**: アイテムのパス、親フォルダのパスをクリップボードにコピー
- **フォルダを開く**: 親フォルダをエクスプローラーで開く
- **ショートカット対応**: .lnkファイルの場合、リンク先のパス操作も提供
- **アイテム編集**: アイテム登録・編集ウィンドウ（[register-modal.md](./register-modal.md)）でアイテムを編集
- **セットのウィンドウ位置を更新**: セットの行のウィンドウ位置を、今の画面から取り直す
- **削除**: 確認してからアイテムをデータファイルから削除する
- **一覧の余白から追加**: アイテムの追加・クリップボードのパス・URL からの追加・ブックマーク取込・アプリ取込
- **文字入力欄の編集**: 元に戻す・やり直し・切り取り・コピー・貼り付け・すべて選択

## 3. 画面項目一覧

メニューの項目は上から次の順に並びます。「表示条件」に挙げていない種類のアイテムでは、その項目は表示されません。

| 項目名 | アイコン | 内容・説明 | 表示条件 | 機能詳細 |
| --- | --- | --- | --- | --- |
| 編集 | ✏️ | アイテム登録・編集ウィンドウでアイテムを編集 | 常時表示 | [4.1](#41-編集) |
| メモを表示 | 📝 | アイテム名とメモをモーダルで表示 | メモが登録されている場合 | [4.2](#42-メモを表示) |
| ウィンドウ位置を更新 | 📍 | セットの行のウィンドウを今の画面から探し、ウィンドウ位置を取り直して保存 | ウィンドウ位置を記録した行があるセット | [4.3](#43-ウィンドウ位置を更新) |
| ワークスペースに追加 ▸ | ⭐ | サブメニューで選んだワークスペースのグループに、アイテムを追加（既定は参照） | 常時表示 | [4.4](#44-ワークスペースに追加) |
| ワークスペースにコピーを追加 ▸ | 📄 | サブメニューで選んだワークスペースのグループに、アイテムのコピーを追加 | 参照できるアイテム（フォルダ取込で並んだアイテムを除く） | [4.4](#44-ワークスペースに追加) |
| パスをコピー | 📋 | アイテムのフルパスをコピー（URL・カスタムURIはその文字列）。右端に `Ctrl+C` を添える | ファイル・フォルダ・アプリ・URL・カスタムURI | [4.5](#45-パスをコピー) |
| 親フォルダのパスをコピー | 📋 | 親フォルダのパスをコピー。右端に `Ctrl+Shift+C` を添える | ファイル・フォルダ・アプリ | [4.6](#46-親フォルダのパスをコピー) |
| 親フォルダを開く | 📂 | 親フォルダをエクスプローラーで開く。右端に `Shift+Enter` を添える | ファイル・フォルダ・アプリ | [4.7](#47-親フォルダを開く) |
| リンク先のパスをコピー | 📋 | ショートカットが指すファイルのパスをコピー | ショートカット（.lnk）を登録したアイテム | [4.8](#48-リンク先のパスをコピー) |
| リンク先の親フォルダのパスをコピー | 📋 | リンク先ファイルの親フォルダのパスをコピー | ショートカット（.lnk）を登録したアイテム | [4.9](#49-リンク先の親フォルダのパスをコピー) |
| リンク先の親フォルダを開く | 📂 | リンク先の親フォルダをエクスプローラーで開く | ショートカット（.lnk）を登録したアイテム | [4.10](#410-リンク先の親フォルダを開く) |
| 削除… | 🗑️ | 確認してからアイテムを削除 | フォルダ取込で並んだアイテム・ブックマーク自動取込のアイテム以外 | [4.11](#411-削除) |
| この取込から外す… | 🚫 | 元のフォルダ取込の編集画面を、除外フィルタにこのファイル名を足した状態で開く | フォルダ取込で並んだアイテムだけ | [4.14](#414-この取込から外す) |

### アイテムの種類による違い

- **ファイル・フォルダ・アプリ**: すべての項目が表示される（リンク先の項目はショートカットのときだけ）
- **URL・カスタムURI**: 親フォルダがないため、親フォルダ関連の項目は表示されない
- **セット・クリップボード・パスの無い単一アイテム**: パスを持たないため、パス関連の項目（「パスをコピー」以降）は表示されない
- **ウィンドウ位置を記録した行があるセット**: 「📍 ウィンドウ位置を更新」が加わる
- **ショートカット（.lnk）を登録したアイテム**: 上記に加えて、リンク先を操作する 3 項目が加わる
- **フォルダ取込で並んだアイテム・ブックマーク自動取込のアイテム**: 「🗑️ 削除…」は表示されない
- **フォルダ取込で並んだアイテム**: 代わりに、いちばん下（区切り線の後）に「🚫 この取込から外す…」が加わる

### 区切り線

- パス関連の項目が表示されるアイテム: 「✏️ 編集」「📝 メモを表示」と「⭐ ワークスペースに追加 ▸」の間、「⭐ ワークスペースに追加 ▸」（と「📄 ワークスペースにコピーを追加 ▸」）とパス操作項目の間、リンク先の項目の前にそれぞれ区切り線が入る
- パス関連の項目が表示されないアイテム（セット・クリップボード・パスの無い単一アイテム）: 区切り線は入らない
- 「📍 ウィンドウ位置を更新」の前後には区切り線が入る
- 「🗑️ 削除…」の前には区切り線が入る（いちばん下に置く）

### 一覧の余白のメニュー

| 項目名 | アイコン | 内容・説明 | 機能詳細 |
| --- | --- | --- | --- |
| アイテムを追加… | 📄 | 登録画面を開く | [4.12](#412-一覧の余白の右クリック) |
| クリップボードのパス・URL から追加… | 📋 | クリップボードのファイル・フォルダ・URL を初期値に登録画面を開く | [4.12](#412-一覧の余白の右クリック) |
| ──────────── | | 区切り線 | - |
| ブラウザのブックマークから追加 | 🔖 | ブックマーク取込を開く | [4.12](#412-一覧の余白の右クリック) |
| インストール済みアプリから追加 | 💻 | アプリ取込を開く | [4.12](#412-一覧の余白の右クリック) |

### 文字入力欄のメニュー

「元に戻す」「やり直し」、区切り線、「切り取り」「コピー」「貼り付け」、区切り線、「すべて選択」の順に並ぶ（[4.13](#413-文字入力欄の右クリック)）。

### Windows のウィンドウメニューは出さない

メインウィンドウ・ワークスペースウィンドウ・切り離しウィンドウの、ドラッグで動かせる所（検索欄のまわりなど）を右クリックしても、Windows のウィンドウメニュー（移動・サイズ変更・最大化など）は出さない（`src/main/utils/systemContextMenu.ts`）。大きさや最大化は QDL が決めるので、このメニューは使い道が無いため。

## 4. 機能詳細

### 4.1. 編集

#### アクション

- 「✏️ 編集」をクリック（メインウィンドウでは、選択中のアイテムに F2 キーでも同じ動き。メニューの右端に F2 と表示する）

#### 処理フロー

1. メニューを閉じる
2. アイテム登録・編集ウィンドウ（[register-modal.md](./register-modal.md)）が別ウィンドウで開く

### 4.2. メモを表示

#### アクション

- 「📝 メモを表示」をクリック

#### 表示条件

- アイテムにメモが登録されていて、空白以外の文字を含む場合

#### 処理フロー

1. メニューを閉じる
2. アイテム名とメモを表示するモーダルを開く（[メインウィンドウ - メモを表示](./main-window.md#5101-メモを表示)）

### 4.3. ウィンドウ位置を更新

#### アクション

- セットを右クリックして「📍 ウィンドウ位置を更新」をクリック

#### 表示条件

- ウィンドウ位置を記録した行が 1 つ以上あるセット

#### 処理フロー

1. メニューを閉じる
2. すべての仮想デスクトップの開いているウィンドウを調べる（最小化中のウィンドウは除く）
3. ウィンドウ位置を記録した行のうち対象ウィンドウのある行ごとに、行の対象ウィンドウ（exe 名・ウィンドウタイトル）に合うウィンドウを探す。1 つのウィンドウは 1 つの行にだけ当てる。合うウィンドウが複数の仮想デスクトップにあれば、行の仮想デスクトップにあるものを先に使う
4. 見つかった行は、そのウィンドウの今のウィンドウ位置を取り直す。仮想デスクトップは、編集画面の「📍 ウィンドウ位置を更新」と同じく今のデスクトップの番号を入れる（番号が空だった行にも入れる。全デスクトップに表示中で番号が無ければ空にし、仮想デスクトップが 1 つなら入れない）
5. 位置が変わった行があれば、データファイルに保存して画面に反映する
6. 結果をトーストで知らせる

行の追加・削除はしない。ウィンドウ位置を記録していない行と、ウィンドウが見つからなかった行は前のままにする。対象ウィンドウの無い行は、位置を記録していても探さず前のままにし、見つからなかった行の数にも入れない。行を足すときは編集画面の「＋ ウィンドウを追加」（[セットの編集画面 - ウィンドウを追加](./set-editor-modals.md#3-ウィンドウを追加)）、結び付けるウィンドウを選び直すときは編集画面の「📍 ウィンドウ位置を更新」（[セットの編集画面 - ウィンドウ位置を更新](./set-editor-modals.md#4-ウィンドウ位置を更新)）を使う。

#### 表示内容

トーストの本文は「{セットの名前}: 」に続けて次を出す。

| 状況 | トースト |
| --- | --- |
| 位置が変わった行がある | 成功で「ウィンドウ位置を更新しました（変わった行 n）」 |
| 位置が変わった行が無い | 成功で「変わる行はありません」 |
| 見つからなかった行がある | 上に続けて「見つからなかった行 n 件は前のウィンドウ位置のままです」を足し、警告で出す |

### 4.4. ワークスペースに追加

#### アクション

- 「⭐ ワークスペースに追加 ▸」のサブメニューで、入れるグループを選ぶ
- 「📄 ワークスペースにコピーを追加 ▸」のサブメニューで、入れるグループを選ぶ（コピーで追加する）

#### サブメニュー

- ワークスペースが 2 つ以上あるときは、ワークスペース名が並び、その下の段にそのワークスペースのグループが並ぶ。ワークスペースが 1 つのときは、ワークスペースの段を省いてグループを直接並べる
- グループは、サブグループを字下げして親の下に並べる
- グループの後に区切り線と「➕ 新しいグループを作って入れる」を置く。選ぶと「グループ {N}」をそのワークスペースの最後に作り、そこへ入れる
- グループが 1 つも無いワークスペースには「➕ 「未分類」グループを作って入れる」だけを出す。選ぶと「未分類」という名前のグループを作って入れる
- ワークスペースには、どのグループにも入らないアイテムの置き場は無いので、入れる先のグループはここで選ぶ（[ワークスペース機能](../features/workspace.md#構成)）

#### 処理フロー

1. メニューを閉じる
2. アイテムを、選んだグループに追加する
3. 追加したことをトーストで知らせる（アイテムの種類によらない）

#### 追加されるもの

- 選んだグループの末尾に入る
- 「⭐ ワークスペースに追加」は、右クリックしたアイテムを指す参照を足す。元のアイテムを後で変えると、ワークスペース側にも反映する（[ワークスペース機能 - 参照とコピー](../features/workspace.md#参照とコピー)）。フォルダ取込で並んだアイテムと、データファイルに見つからないアイテムは参照できないので、コピーを足し、トーストで「参照できないアイテムなので、コピーで追加しました」と知らせる
- 「📄 ワークスペースにコピーを追加」は、右クリックしたアイテムのコピーを足す。元のアイテムを後で変えても、ワークスペース側は変わらない。この項目は、参照できるアイテム（通常アイテム・パスの無い単一アイテム・セット・クリップボード。フォルダ取込で並んだアイテムを除く）にだけ出る
- コピーでは、ウィンドウ設定（タイトル・位置・サイズ）を持つアイテムは、その設定もコピーする
- セットはセットのまま（行・開き方も）追加し、ワークスペースから起動するとメインウィンドウと同じように行を開く
- コピーのクリップボードアイテムは保存データも複製し、メインウィンドウ側と共有しない（片方を消しても、もう片方は復元できる）。元の保存データが無くて複製できないときは、元を指したまま追加する
- 追加元ごとに作られるアイテムの違いは [ワークスペース機能 - アイテムの追加元と、作られるアイテム](../features/workspace.md#アイテムの追加元と作られるアイテム) を参照

#### エラーハンドリング

- 追加に失敗したら、エラーのトーストで「ワークスペースを変更できませんでした: {エラーの内容}」と表示する（成功時と同じく、アイテムの種類によらない）。QDL の外でのワークスペースファイルの変更との競合・ファイルの破損・再読み込み中・書き込みの失敗のときは、その内容を警告のトーストで表示する

### 4.11. 削除

#### アクション

- 「🗑️ 削除…」をクリック

#### 表示条件

- id のあるアイテム。フォルダ取込で並んだアイテム（消すとフォルダ取込のアイテムごと消えるため）と、ブックマーク自動取込のアイテム（消しても次の取込で戻るため）には出さない

#### 処理フロー

1. メニューを閉じる
2. メインウィンドウの中に確認ダイアログ（危険操作の表示）を出す。文面は登録・編集画面の削除と同じ「「<表示名>」を削除してもよろしいですか？」で、ワークスペースから参照されているアイテムなら、次の行に「ワークスペースから {N} 件参照されています。削除すると、その参照は「元のアイテムが見つかりません」になります。」を添える（[アイテム登録・編集 - 削除ボタンをクリック](./register-modal.md#518-削除ボタンをクリック)）。ボタンは「削除」「キャンセル」
3. 確認ダイアログを出している間は、Enter・Escape などのキーは確認ダイアログだけが受ける（一覧のアイテムを開かず、Escape でメインウィンドウを隠さない）
4. 「削除」で、データファイルからアイテムを削除する。一覧は読み直される
5. キャンセルした場合は何もしない

#### エラーハンドリング

- 削除に失敗したら、エラーのダイアログで「アイテムの削除に失敗しました」と表示する

### 4.12. 一覧の余白の右クリック

#### アクション

- メインウィンドウの一覧の、アイテムの無い所（一覧の下の余白・一覧が空のときの案内）を右クリック

#### 表示条件

- 通常検索のときだけ。ウィンドウ検索では出さない

#### 処理フロー

- **📄 アイテムを追加…**: ヘッダーの ➕ の「📄 アイテムを追加…」と同じく、登録画面を開く（[メインウィンドウ - アイテム登録ボタン押下](./main-window.md#522-アイテム登録ボタン押下)）
- **📋 クリップボードのパス・URL から追加…**: クリップボードを読み、エクスプローラーでコピーしたファイル・フォルダがあればそのパスを、無ければパス・URL の形のテキストを初期値にして登録画面を開く（ファイルをドロップしたときと同じ。[メインウィンドウ - ドラッグ&ドロップ操作](./main-window.md#518-ドラッグドロップ操作)）。どちらも無い（ただの文字列だけ、または空）ときは、警告で「クリップボードにファイル・フォルダ・URL がありません」と知らせる
- **🔖 ブラウザのブックマークから追加**・**💻 インストール済みアプリから追加**: ➕ の同じ項目と同じく、管理ウィンドウでブックマーク取込・アプリ取込を開く

### 4.13. 文字入力欄の右クリック

#### アクション

- 文字入力欄（検索欄・登録画面の入力欄など）を右クリック

#### 表示条件

- すべてのウィンドウの文字入力欄。アイテム・グループのように画面が自分の右クリックメニューを出す所では出さない

#### 処理フロー

1. 「元に戻す」「やり直し」「切り取り」「コピー」「貼り付け」「すべて選択」を出す。今できない操作（選んでいない文字の切り取り・コピーなど）は押せない
2. 選んだ操作を入力欄に行う

### 4.14. この取込から外す

#### アクション

- フォルダ取込で並んだアイテムを右クリック →「🚫 この取込から外す…」

#### 処理フロー

1. 元のフォルダ取込の行の編集画面（[アイテム登録・編集](./register-modal.md)）を開く
2. 読み込みが済んだら、フォルダ取込オプションの「除外フィルタ」にそのアイテムのファイル名を足し、オプションの欄を開いておく。足し方は次のとおり（データの形は文字列 1 つのまま）
   - 空なら、そのファイル名だけ（`*`・`?`・`[`・`{`・`,` などはその文字として当たるよう `\` を付ける）
   - すでにそのファイル名に当たるなら、変えない
   - 全体が `{…}` なら中に足し、それ以外は `{今の値,ファイル名}` にまとめる
3. 保存はしない。除外フィルタを見て「保存」を押すと、次の読み込みからそのアイテムが並ばなくなる。キャンセルすれば何も変わらない

#### 注意

- 除外フィルタはファイル名だけに当てるので、取込の中の別のフォルダにある同じ名前のファイルも一緒に外れる
- 消したいときに消せないのは、並んだアイテムを保存しておらず、読み込むたびにフォルダから作っているため。フォルダ取込の行そのものは、アイテム管理か CLI の `qdl remove` で消す
