## 起動フロー

**アプリケーション起動時:**

1. **スプラッシュウィンドウ** を表示（起動中の初期化処理を実行）
2. 初期化完了後：
   - 初回起動時（`hotkey`が未設定）: **初回設定画面** を表示
   - 2回目以降: **メインウィンドウ** を表示

**初回設定完了後:**

- **初回設定画面** → **メインウィンドウ** へ遷移

## 画面の種類と特性

区分は [画面一覧](./README.md#画面一覧) と同じ。

### ウィンドウ

| 画面名 | 特性 | 表示条件 |
| --- | --- | --- |
| **スプラッシュウィンドウ** | 起動時の一時的なローディング画面 | アプリ起動時に自動表示 |
| **初回設定画面** | 初回起動時のみ表示される設定画面 | `hotkey`が未設定の場合 |
| **メインウィンドウ** | 主要なランチャー画面 | `Alt+Space`（既定）で表示/非表示 |
| **管理ウィンドウ** | 設定・アイテム管理を行う画面<br>3つのタブで構成：<br>- ⚙️ 設定タブ<br>- ✏️ アイテム管理タブ<br>- 📖 ヘルプタブ | `Ctrl+E` または設定メニューから |
| **ワークスペースウィンドウ** | よく使うアイテムを登録する専用ウィンドウ | `Ctrl+W`（メインウィンドウ内で有効）<br>メインウィンドウのヘッダーの ⭐ ボタン<br>開いていて 📌 なしなら、メインと一緒に出る |
| **グループの切り離しウィンドウ** | ワークスペースのグループ 1 つを独立して表示するウィンドウ | グループヘッダーをウィンドウの外へドラッグ<br>前回分はワークスペースウィンドウの初回表示時に復元 |

**特記事項:**

- **メインウィンドウ** と **ワークスペースウィンドウ** は独立したウィンドウで、同時に表示可能
- **管理ウィンドウ** は単一ウィンドウで、既に開いている場合は前面に表示。タブ切り替えで各機能にアクセス
- **メインウィンドウ**・**ワークスペースウィンドウ**・**グループの切り離しウィンドウ** とそれらの子ウィンドウの間でフォーカスが移っても、メインウィンドウは隠れない（管理ウィンドウへ移ると隠れる）
- **スプラッシュウィンドウ** は起動時のみ表示され、初期化完了後に自動的に閉じる

### 子ウィンドウ

開き元とは別のウィンドウとして開き、開き元のウィンドウのサイズ・位置は変えない。

| 画面名 | 特性 |
| --- | --- |
| **アイテム登録・編集** | アイテムの新規登録・編集。メインウィンドウか管理ウィンドウから開く |
| **アイコン取得結果** | アイコン一括取得の結果（成功・エラー）を表示 |
| **ワークスペースアイテム編集** | ワークスペースのアイテムを編集。ワークスペースウィンドウか切り離しウィンドウから開く |
| **ワークスペースの確認** | グループの削除・アーカイブを確認する。開いている間は開き元を操作できない |

**特記事項:**

- メインウィンドウの子ウィンドウ（アイテム登録・編集、アイコン取得結果）を開いている間は、メインウィンドウが非表示にならない（モーダルモード）

### モーダル

開いている画面の上に重ねて表示し、閉じるまで下の画面は操作できない。

| 画面名 | 特性 |
| --- | --- |
| **ブックマーク取込画面** | ブラウザ／HTML のブックマークをフォルダの木から選んで取り込む。フォルダごと選んだときは自動取込のルールにもできる |
| **ブックマークの取込ルールの追加・編集** | フォルダ・名前・URL・表示名を決めた自動取込のルールを作る・直す |
| **アプリ取込画面** | インストール済みアプリを選んで取り込む |
| **バックアップスナップショットモーダル** | バックアップのスナップショット一覧を表示する |
| **メモ表示モーダル** | アイテムのメモを表示する |
| **セットに追加するアイテム** | セットに行として足すアイテムを選ぶ |
| **ウィンドウを追加** | 開いているウィンドウを選んで、セットに行として足す |
| **ウィンドウ位置を更新** | 開いているウィンドウから、セットの今ある行のウィンドウ位置を取り直す |
| **行の詳細** | セットの 1 つの行の開くもの・対象ウィンドウ・ウィンドウ位置・開くときの動きを直す |
| **ウィンドウ選択モーダル** | 開いているウィンドウから選択する |

### 共通ダイアログ

| 画面名 | 特性 |
| --- | --- |
| **AlertDialog** | エラー・警告・成功・情報メッセージの表示 |
| **ConfirmDialog** | ユーザー確認が必要な操作（削除、変更破棄など） |
| **FilePickerDialog** | ファイル選択（ブックマークインポート、カスタムアイコン選択） |

**特記事項:**

- どの画面からも呼び出す共通の部品。モーダルと同じく、表示中は下の画面を操作できない
