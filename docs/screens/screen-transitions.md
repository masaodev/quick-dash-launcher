## 起動フロー

**アプリケーション起動時:**

1. **スプラッシュウィンドウ** を表示（起動中の初期化処理を実行）
2. 初期化完了後：
   - 初回起動時（`hotkey`が未設定）: **初回設定画面** を表示
   - 2回目以降: **メインウィンドウ** を表示

**初回設定完了後:**

- **初回設定画面** → **メインウィンドウ** へ遷移

## 画面の種類と特性

### ウィンドウ

| 画面名                           | 特性                                                                                                               | 表示条件                                                                                                         |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| **スプラッシュウィンドウ**       | 起動時の一時的なローディング画面                                                                                   | アプリ起動時に自動表示                                                                                           |
| **初回設定画面**                 | 初回起動時のみ表示される設定画面                                                                                   | `hotkey`が未設定の場合                                                                                           |
| **メインウィンドウ**             | 主要なランチャー画面                                                                                               | `Alt+Space`（デフォルト）で表示/非表示                                                                           |
| **管理ウィンドウ**               | 設定・アイテム管理を行う画面<br>3つのタブで構成：<br>- ⚙️ 基本設定タブ<br>- ✏️ アイテム管理タブ<br>- 📖 ヘルプタブ | `Ctrl+E` または設定メニューから                                                                                  |
| **ワークスペースウィンドウ**     | よく使うアイテムを登録する専用ウィンドウ                                                                           | `Ctrl+W`（ランチャーウィンドウ内で有効）<br>⚙️ メニュー「🗂️ ワークスペースを表示」<br>設定で自動表示が有効なとき |
| **グループの切り離しウィンドウ** | ワークスペースのグループ 1 つを独立して表示するウィンドウ                                                          | グループヘッダーをウィンドウの外へドラッグ<br>前回分はワークスペースウィンドウの初回表示時に復元                 |

**特記事項:**

- **メインウィンドウ** と **ワークスペースウィンドウ** は独立したウィンドウで、同時に表示可能
- **管理ウィンドウ** は単一ウィンドウで、既に開いている場合は前面に表示。タブ切り替えで各機能にアクセス
- **メインウィンドウ**・**ワークスペースウィンドウ**・**グループの切り離しウィンドウ** とそれらの子ウィンドウの間でフォーカスが移っても、メインウィンドウは隠れない（管理ウィンドウへ移ると隠れる）。詳細は [ウィンドウ制御](../architecture/window-control.md#ウィンドウ非表示の判定)
- **スプラッシュウィンドウ** は起動時のみ表示され、初期化完了後に自動的に閉じる

### モーダル

| 画面名                                           | 特性                                                                                                                    |
| ------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| **アイテム登録・編集モーダル**                   | アイテムの新規登録・編集を行うモーダル                                                                                  |
| **ブックマーク取込画面**                         | ブラウザ／HTML のブックマークを条件で絞り込み、今回だけ取り込むかルールとして保存するモーダル（設定のルール編集と共通） |
| **グループアイテム選択モーダル**                 | グループに追加するアイテムを選択するモーダル                                                                            |
| **ウィンドウ選択モーダル**                       | 開いているウィンドウから選択するモーダル                                                                                |
| **アイコン取得進捗詳細モーダル**                 | アイコン一括取得の結果を表示するモーダル                                                                                |
| **ワークスペースアイテム編集モーダル**           | ワークスペースのアイテムを編集するモーダル                                                                              |
| **ワークスペースの確認**                         | グループの削除・アーカイブを確認する子ウィンドウ                                                                        |
| **アプリインポートモーダル**                     | インストール済みアプリを選んで取り込むモーダル                                                                          |
| **バックアップスナップショットモーダル**         | バックアップのスナップショット一覧を表示するモーダル                                                                    |
| **メモ表示モーダル**                             | アイテムのメモを表示するモーダル                                                                                        |
| **今のウィンドウから追加（LayoutCaptureModal）** | 開いているウィンドウの配置を取り込むモーダル                                                                            |

**特記事項:**

- モーダルは親画面の上に表示され、閉じるまで親画面の操作は不可
- モーダル表示中はメインウィンドウが非表示にならない（モーダルモード）
- メイン・ワークスペース・切り離しウィンドウとそれらの子ウィンドウの間でフォーカスが移っても、メインウィンドウは隠れない（管理ウィンドウへ移ると隠れる）。詳細は [ウィンドウ制御](../architecture/window-control.md#ウィンドウ非表示の判定)

### ダイアログ

| 画面名               | 特性                                                         |
| -------------------- | ------------------------------------------------------------ |
| **AlertDialog**      | エラー・警告・成功・情報メッセージの表示                     |
| **ConfirmDialog**    | ユーザー確認が必要な操作（削除、変更破棄など）               |
| **FilePickerDialog** | ファイル選択（ブックマークインポート、カスタムアイコン選択） |

**特記事項:**

- ダイアログはすべての画面から呼び出される共通コンポーネント
- モーダルと同様に、表示中は親画面の操作は不可
