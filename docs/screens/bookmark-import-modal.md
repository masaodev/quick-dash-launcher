## 1. 概要

ブラウザのブックマークから使うものを選び、ランチャーのアイテムにする画面です。アプリ取込画面と同じく、一覧にチェックを入れて取り込みます。一覧はブラウザのフォルダの木で、フォルダにチェックを入れると中のブックマーク（サブフォルダも）がまとめて選ばれます。1 件ずつ選ぶこともできます。開いた時点では何も選ばれていません。

取込先の初期値は「アイテム管理で選んでいるタブに新しいデータファイル『ブックマーク』を作って入れる」です。既存のデータファイルや、新しいタブ（とそのデータファイル）も選べます。新しいタブ・データファイルは「取り込む」を押した時点で作ります（キャンセルしたら何も作りません）。

フォルダごと選んだときは、フッターの「〜を、これからも自動で取り込む」をオンにして、自動取込のルールとして保存できます。名前の条件や表示名を付けたルールは、設定の [ブックマークの取込ルールの追加・編集画面](./bookmark-rule-modal.md) で作ります。

**キーボードショートカット**: Escape キーで閉じます（選択は破棄されます）。

## 4. 機能詳細

### 4.1. 取込元を選ぶ

- 開いた直後にインストール済みのブラウザを探し、最初のブラウザの最初のプロファイルを選ぶ。ブラウザが無ければ HTML ファイルにする
- 取込元・プロファイルが決まるとフォルダ付きの一覧を読み、一番上のフォルダを開いた状態で出す。読み直すと選択は空に戻る
- プロファイルは 1 つだけ選ぶ。全プロファイルを混ぜると、同じ名前のフォルダが 1 つにまとまり、どのプロファイルのものか分からなくなるため
- HTML ファイルは Netscape 形式（ブラウザの書き出し形式）を読み、フォルダの入れ子を復元する。フォルダの外にあるブックマークは一覧の最後に並ぶ

### 4.2. 探す

- 検索欄に入れると、一覧はフォルダの木から、名前か URL に入れた文字を含むブックマークの一覧に変わる
- 見出しのチェックで、見つかった分をまとめて選ぶ・外す
- 検索で選んだ分は、検索を消しても選んだまま残る
- 検索は探すためだけで、ルールの条件にはならない（名前の条件のあるルールは [取込ルールの画面](./bookmark-rule-modal.md) で作る）

### 4.3. 選ぶ

- フォルダのチェックは、そのフォルダの中のブックマーク（サブフォルダも）をまとめて選ぶ・外す
- ブックマークは、行のどこかをクリックするか、チェックで 1 件ずつ選ぶ・外す
- フォルダの行は、行をクリックするか ▸ で開閉する（開くと ▸ が下を向く）
- 見出しの右の件数は選択の合計を出す。「選択を解除」ですべて外す

### 4.4. これからも自動で取り込む

- 次の両方を満たすときだけ、チェックを使える。満たさないときは理由を出す
  - 選んだ中身が、いくつかのフォルダの中身ぜんぶ（サブフォルダも）になっている。1 件ずつ選んだ分が混ざると「1 件ずつ選んだ分があるので自動取込にできません。フォルダごと選ぶと使えます」
  - 取込元がブラウザで、検索していない。HTML ファイルは「HTML ファイルは自動取込にできません」、検索中は「検索中は自動取込にできません。検索を消して、フォルダごと選ぶと使えます」
- 保存するルールの中身
  - 取込元: 選んでいるブラウザとプロファイル
  - フォルダ: 選んだフォルダ（いちばん上のもの。サブフォルダも対象）。ブックマークを全部選んでいれば「すべてのフォルダ」になり、あとから増えたフォルダも対象
  - 名前・URL の条件と表示名は付けない
- ルール名が空なら、フォルダ名（全部なら「ブックマーク全件」）にする

### 4.5. 取込先を選ぶ

- アプリ取込画面の [取込先を選ぶ](./app-import-modal.md#44-取込先を選ぶ) と同じ。新しいタブ・データファイルの名前の初期値は「ブックマーク」
- 「登録済み」の印は、既存のデータファイルならそのファイルと、新しいデータファイルならそのタブのデータファイルすべてと URL で照らして付ける

### 4.6. 取り込む

#### 処理フロー

1. 取込先が新しいタブ・データファイルなら、ここで作る（アプリ取込画面と同じ）
2. 自動で取り込むをオンにしていないとき: 選んだブックマークを、アイテム管理の編集中の内容に追加する（未保存の変更として入り、「変更を保存」で確定）。自動取込の印は付かない。既存のデータファイルに入れるときは「重複時の処理」に従う（スキップは登録済みの URL を入れない。上書きは既存の ID と自動取込の印を引き継いで内容を置き換える）
3. 自動で取り込むをオンにしたとき: ルールを設定に足し、続けてそのルールを実行する（データファイルへ直接書く）。結果はトーストで知らせ、手動分との重複があれば警告にする。実行に失敗したときは、ルールは保存したまま警告のトーストで知らせる
4. 画面を閉じ、アイテム管理で取込先のタブ・データファイルを開く。オンにしていないときはトースト「N 件を〈取込先〉に追加しました（保存で確定）」を出す

#### エラーハンドリング

- 新しいタブ・データファイルを作れなかったときは、警告のトーストで理由を出し、画面は開いたままにする（何も取り込まない）
- 自動で取り込むをオンにしたとき、ルールの保存に失敗したら、警告のトースト「ルールを保存できませんでした: 〈理由〉」を出し、取込先のタブ・データファイルを開き、画面は開いたままにする

### 4.7. 閉じる

- キャンセル・Escape・オーバーレイのクリックで閉じる。選択・検索・取込先は破棄される

## 5. 以前との違い

v0.8.0-beta.13 までは次の作りでした。

- 画面名は「ブラウザのブックマークの追加」。設定のルール編集と同じフォームで、条件（フォルダの木・「選択フォルダのみ／除外」・「サブフォルダも含める」・URL と名前のパターン（正規表現）・表示名）で絞り込み、結果は一番下のプレビューで見ていた
- 先頭に「ルール名」の欄があり、フッターに「今回だけ取り込む (N 件)」と「ルールとして保存」の 2 つのボタンがあった
- 取込先（「インポート先」）は既存のデータファイルから選ぶだけだった

v0.7.37 までは、手動取込は専用の画面（フラット一覧をチェックで選ぶ）で、自動取込のルール編集とは別の画面だった。
