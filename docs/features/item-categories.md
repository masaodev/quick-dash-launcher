# アイテムの種別

登録するアイテムの 5 つの種別（単一アイテム・フォルダ取込・セット・クリップボード・WSグループ）と、それぞれで何ができるかの説明です。種別は登録画面の「種別」で選びます（WSグループだけは、管理ウィンドウのアイテム管理で「＋ アイテムを追加」の ▼ から作ります）。保存される形は [データファイル形式](../architecture/file-formats/data-format.md)、用語は [用語集](../architecture/glossary.md) を参照してください。

## 単一アイテム

URL、アプリケーション、ファイル、フォルダ、カスタム URI を 1 件ずつ登録します。どれとして開くかはパスの形から決まります。

| 登録できるもの | 例 |
| --- | --- |
| Web サイト | `https://github.com`、`https://www.notion.so` |
| アプリケーション | `C:\Program Files\Google\Chrome\Application\chrome.exe`、`notepad.exe` |
| ファイル | `C:\Users\YourName\Documents\report.xlsx` |
| フォルダ | `C:\Projects`、`C:\Users\YourName\Downloads` |
| カスタム URI | `obsidian://vault/MyVault`、`vscode://file/path/to/file` |

アプリ（exe・ショートカット（.lnk）・.bat/.cmd など）は、右クリックの「🛡️ 管理者として実行」（ランチャーでは Ctrl+Shift+Enter も）で管理者として起動できます（UAC の確認が出ます。ストアアプリは除く）。登録画面のオプション設定で「常に管理者として実行」を付けると、Enter・クリック・セットの行など、どこから開いても管理者として起動します。管理者として開いたウィンドウは、権限の低い QuickDashLauncher からウィンドウ位置を当てたり前面に出したりできないことがあります。

名前は自由に付けられます。検索は名前の部分一致なので、探すときに打つ言葉を名前に入れておきます（例: `https://mail.google.com` を「メール」、`report.xlsx` を「基幹刷新 報告書」）。

アイテムごとに、開く前に探すウィンドウ（対象ウィンドウ。exe 名・ウィンドウタイトル）を決めておけます（ウィンドウ切り替え）。見つかればそのウィンドウを前に出し、無ければ開きます。ウィンドウ位置（位置・大きさ・仮想デスクトップ）も記録しておくと、見つけたウィンドウにも、開いて出てきたウィンドウにも当てます。動きも登録画面の欄も、セットの 1 行と同じです（仕組みは [ウィンドウ制御](../architecture/window-control.md)）。

対象ウィンドウを決めておけば、パスを空のまま保存することもできます（パスの無い単一アイテム）。開いたとき、そのウィンドウが開いていれば切り替え（ウィンドウ位置があれば当てます）、開いていなければ何も開かずに「開いていないので切り替えませんでした」と知らせます。ランチャー・ワークスペースではウィンドウの絵文字（🪟）で出し、親フォルダを開くなどのパスの操作は出しません。セットの行から指すと、その行は「ウィンドウを動かすだけ」の行になります。あとでパスを入れれば、普通の単一アイテムになります（形は [データファイル形式](../architecture/file-formats/data-format.md#3157-パスの無い単一アイテム)）。

以前の種別「ウィンドウ操作」は廃止しました。データファイル・ワークスペースにあるウィンドウ操作のアイテムは、読み込んだときにパスの無い単一アイテムに変換されます（id・名前・アイコン・メモはそのまま。探すタイトル・exe 名は対象ウィンドウに、位置・大きさ・仮想デスクトップはウィンドウ位置に移します。「カーソルがあるモニターの中央に配置」は引き継ぎません）。id は変わらないので、そのアイテムを指していたセットの行もそのまま動きます。

## フォルダ取込

指定したフォルダを読み込み、中のファイルやフォルダをそれぞれアイテムとして候補に並べます。フォルダの中身は読み込むたびに反映されるので、ファイルが増えても登録し直す必要はありません。

| 決められること | 例 |
| --- | --- |
| サブフォルダをどこまでたどるか | 現在のフォルダのみ、1〜3 階層下まで、無制限 |
| 取り込む種類 | ファイルのみ、フォルダのみ、両方 |
| 入れるもの（ファイル名の条件） | `*.xlsx`、`*.md` |
| 除くもの（除外する条件） | `旧*`、`temp*` |
| 表示名の前後に付ける文字（入力したとおりにつなぐ） | 「基幹刷新 」を前に付けて、プロジェクト名でも当たるようにする |

登録画面の「🔍 プレビュー」で、何が取り込まれるかを登録する前に確かめられます。

## セット

複数のアイテムをまとめて一度に開き、必要ならウィンドウを決まった位置に並べます。セットは「行」を並べたもので、行ごとに開くもの（登録済みのアイテムか、セットに書いたパス）・対象ウィンドウ・ウィンドウ位置を持ちます。アイテムを指す行は id で指すので、パスなどは個々のアイテムで管理できます。開いているウィンドウは「ウィンドウを追加」で今のウィンドウ位置ごと行にでき、並べ直したら「ウィンドウ位置を更新」で取り込み直します。何も開かずに既にあるウィンドウを動かすだけの行も作れます。詳細は [セット](./set.md) を参照してください。

旧グループと旧ウィンドウ配置は、読み込んだときにセットに変換されます。

活用例:

- 「業務開始」: メール、カレンダー、チャット、エディタをまとめて開く
- 「会議準備」: 会議ツール、議事録の雛形、プロジェクトの資料フォルダをまとめて開く
- 「開発」: エディタ・ブラウザ・ターミナルを開いて、いつもの位置に並べる

## クリップボード

登録画面で書いたテキスト、または取り込んだクリップボードの内容（テキスト、HTML、RTF、画像。画像は 10MB まで）を保存しておき、選ぶとその内容をクリップボードにコピーします（貼り付けは Ctrl+V で行います）。

活用例:

- 定型文や署名をすぐ貼り付けられるようにする
- よく使う画像をクリップボードに呼び出す

## WSグループ

ワークスペースのグループを、ランチャーの一覧と検索に 1 件ずつ並べます。並んだグループを選ぶと、そのグループの切り離しウィンドウが開きます。ワークスペースを開かずに、名前で探してグループのアイテムへたどり着けます。

| 決められること | 例 |
| --- | --- |
| 並べるグループ | すべてのグループ（あとで足したグループも並ぶ）、選んだグループだけ |
| 表示名の前後に付ける文字（入力したとおりにつなぐ） | 「WS: 」を前に付けて、普通のアイテムと見分ける |

- 作るのは管理ウィンドウのアイテム管理の「＋ アイテムを追加」の ▼ の「🪟 ワークスペースのグループを検索に出す」だけです。種類列のプルダウン・登録画面の「種別」からは作れず、ほかの種別にも変えられません（[管理ウィンドウ 5.32](../screens/admin-window.md#532-wsグループの追加と編集)）
- 並べるのはいちばん上の階層のグループだけです（サブグループは並べません）。表示名はグループの今の名前で、グループを改名すると一覧の名前も変わります
- ランチャーでは、窓の形のアイコン（上の帯がグループの色）と「ワークスペースグループ」の札で、普通のアイテムと見分けられます
- 選んでもランチャーは隠れません。ワークスペースへの追加・セットの行・CLI の `item open` の対象にはなりません

活用例:

- 「仕事」タブに仕事のグループだけを並べ、グループ名を打てば、そのグループの切り離しウィンドウがすぐ出るようにする
