# キーボードショートカット

QuickDashLauncher のキーボードショートカットの一覧です。各キーで起きることの細部は、画面ごとの仕様（画面仕様のキーボード操作の章）を正とします。

## グローバルショートカット

| キー | 動作 |
| --- | --- |
| （設定値） | メインウィンドウの表示/非表示切り替え（既定値は空。初回起動画面の初期値は `Alt+Space`） |
| （設定値） | ウィンドウ検索モードで直接起動（既定値は `Ctrl+Alt+Space`。設定画面で変更・解除できる） |

ピン留め（常に最前面・表示固定）でメインウィンドウを出したまま別の仮想デスクトップへ移った後にどちらのホットキーを押しても、メインウィンドウを今のデスクトップへ呼び寄せて前に出します（[仮想デスクトップ](./virtual-desktop.md#メインウィンドウ)）。

> **注意**: 起動ホットキーの既定値は空で、初回起動画面で `Alt+Space` が初期値として入力されています。設定画面でカスタマイズできます。他のアプリケーションとの競合を避けるため、お好みのキー組み合わせに変更してください。

**ウィンドウ検索のホットキー:**

- 既定値は `Ctrl+Alt+Space`。設定画面（設定タブ）の「ウィンドウ検索:」で変更できる
- 設定されたホットキーで起動すると、ウィンドウ検索モードが自動的に有効になります
- 空の場合は機能が無効になります

## メインウィンドウ内

画面上のボタン・表示からは気づきにくいキー（F2・Shift+Enter・Ctrl+↑/↓・Tab など）は、メインウィンドウの下のヒント行にも出る。Ctrl+E・Ctrl+W は設定メニュー（⚙）の項目名に添えてある（ヒント行は管理ウィンドウの基本設定「操作のヒントを表示」で消せる。既定は表示）。

これらのキーは、検索欄以外（リストのアイテムや余白をクリックした後など）にフォーカスがあっても効く。フォーカスがどこにも無いときにキーを押すと、検索欄にフォーカスが戻る。

### 基本操作

| キー | 動作 |
| --- | --- |
| `Enter` | 選択中のアイテムを起動 |
| `Shift+Enter` | 選択中のアイテムの親フォルダを開く（URL・カスタムURI・セットなど親フォルダの無いアイテムでは、実行せずにトーストで知らせる。ウィンドウ検索モードでは Enter と同じ） |
| `Ctrl+Shift+Enter` | 選択中のアプリを管理者として実行（UAC の確認が出る。右クリックの「🛡️ 管理者として実行」と同じ）。アプリ以外（URL・ファイル・フォルダ・セットなど）では、実行せずにトーストで知らせる。ウィンドウ検索モードでは Enter と同じ |
| `F2` | 選択中のアイテムの編集ウィンドウを開く（通常モードのみ。右クリックの「✏️ 編集」と同じ） |
| `Ctrl+C` | 選択中のアイテムのパスをコピー（通常モードのみ。右クリックの「📋 パスをコピー」と同じ）。検索欄で文字を選んでいるときは、今までどおり文字のコピー。パスの無いアイテム（セット・クリップボード・パスの無い単一アイテム）では何もしない |
| `Ctrl+Shift+C` | 選択中のアイテムの親フォルダのパスをコピー（通常モードのみ。右クリックの「📋 親フォルダのパスをコピー」と同じ。URL・カスタムURI では知らせるだけ） |
| `Shift+F10` / アプリケーションキー | 選択中の行の右クリックメニューを、その行の左下に出す（ウィンドウ検索モードではウィンドウのメニュー）。検索欄の文字のメニュー（切り取り・コピーなど）はマウスの右クリックでだけ出す |
| `F5` | 再読み込み（通常モード: 設定ファイルの再適用とデータファイルの再読み込み、ウィンドウモード: ウィンドウ一覧更新、v0.6.0以降） |
| `Escape` | ウィンドウを非表示（一部の状態では無効） |
| `↑` `↓` | アイテム選択の移動 |
| `PageUp` `PageDown` | 一覧に見えている行数より 1 つ少ない分だけ選択を動かす（端で止まる。前の画面の行が 1 つ残る） |
| `Ctrl+Home` / `Ctrl+End` | 一覧の先頭・末尾を選ぶ（`Home` `End` だけは検索欄のカーソル移動） |

**注意**: Escapeキーは、以下の状態ではウィンドウを閉じません：

- 初回起動モード（ホットキー未設定）
- モーダルモード（アイテムの登録・編集、アイコン取得結果の子ウィンドウが開いている）
- ピン留めモードが「常に最前面」または「表示固定」

### 検索とフィルタリング

| キー | 動作 |
| --- | --- |
| 文字入力 | リアルタイム検索（スペース区切りでAND検索） |
| `Shift+Tab` | 検索モード切り替え（通常→ウィンドウ→通常...） |
| `Ctrl+A` | 検索ボックスの全選択 |
| `Ctrl+↑` | 検索履歴を遡る |
| `Ctrl+↓` | 検索履歴を進む |
| `Ctrl+P` | ウィンドウ検索モード時、選択中のウィンドウを全デスクトップに表示/解除（v0.7.2以降。仮想デスクトップが使えない環境では、対応していないことをトーストで知らせる） |

**検索モード切り替え:**

- `Shift+Tab`キーで2つの検索モードを順次切り替えます（通常 ↔ ウィンドウ）
- 現在のモードは、検索ボックス左端の目印（🔍／🪟）と下部のインジケーターに表示されます（例: 「🔍 通常検索モード」「🪟 ウィンドウ検索モード」。モード名の右の「Shift+Tab: ウィンドウ検索へ切り替え」（ウィンドウ検索モードでは「通常検索へ切り替え」）はクリックでも切り替えられます）。ウィンドウ検索モードではウィンドウ全体の色が紫になります
- タブ表示の有無にかかわらず、`Shift+Tab`は常に検索モード切り替えに使われます（タブの移動は`Tab`）

**通常モード:**

- 通常検索
- スペース区切りでAND検索が可能
- `F5`キーで設定の再適用とデータファイルの再読み込みが可能（v0.6.0以降）

**ウィンドウ検索モード内での追加ショートカット:**

| キー | 動作 |
| --- | --- |
| `F5` | ウィンドウ一覧を更新 |
| `Tab` | 仮想デスクトップのタブを順に切り替え（仮想デスクトップが2つ以上のとき。検索中は一致するウィンドウがないタブを飛ばす） |
| `Ctrl+D` | 選択中のウィンドウを閉じる（続けて押すと次のウィンドウを閉じる。右クリックの「❌ ウィンドウを閉じる」と同じ） |
| `Ctrl+←` / `Ctrl+→` | 選択中のウィンドウを前後の仮想デスクトップに移動（デスクトップ番号のタブを表示中のみ。全デスクトップに表示しているウィンドウは対象外） |
| `Shift+↑` / `Shift+↓` | カーソルを動かしながら範囲を選ぶ（複数選択） |
| `Ctrl+Shift+A` | 表示中のウィンドウをすべて選ぶ |
| `Enter`（閉じる確認が出ているとき） | 選んだウィンドウを閉じる |
| `Escape` | 閉じる確認をやめる → 選択を外す → メインウィンドウを隠す（の順に効く） |

ウィンドウを選んでいるあいだは、`Ctrl+D`・`Ctrl+P`・`Ctrl+←/→` が選んだウィンドウすべてに効く（2 つ以上を閉じるときは確認を出す。`Ctrl+P` は 1 つでも固定していないものがあれば全部固定し、全部固定済みなら全部解除する）。マウスでは Ctrl+クリックで 1 つずつ、Shift+クリックで範囲を選べる。

**ウィンドウ検索モード:**

- システム内の開いているウィンドウを、タイトルと exe 名で検索できます
- 各ウィンドウにはアイコンが表示されます（Windows API + GDI+で取得）
- ウィンドウを選択すると、そのウィンドウが前面に出ます（フォーカスされます）
- 最小化されているウィンドウは自動的に復元されます
- データファイルのタブが隠れ、仮想デスクトップのタブ（仮想デスクトップが2つ以上のとき）に切り替わります
- **v0.5.22以降**: 仮想デスクトップごとのタブ + 「全デスクトップ」タブで絞り込みが可能
  - 「すべて」「全デスクトップ」「1」「2」...のタブで切り替え
  - 「全デスクトップ」タブ: すべてのデスクトップに表示するウィンドウのみ表示（該当ウィンドウがある場合のみ表示）
  - 現在アクティブなデスクトップには「（現在）」ラベルを表示（例: 「1（現在）」）
  - タブごとのウィンドウ数がカウント表示されます
- **v0.7.2以降**: `Ctrl+P`で選択中のウィンドウを全デスクトップに表示/解除

**一覧に出ないウィンドウ:** Alt+Tab と同じ考え方で、不可視のウィンドウ・ツールウィンドウ・所有されているウィンドウ・QuickDashLauncher 自身のメインウィンドウとトーストなどを除く（ワークスペース・アイテム管理のウィンドウは出る）。判定の詳細は [ウィンドウ制御 - システムウィンドウの除外](../architecture/window-control.md#システムウィンドウの除外) を参照

### タブ操作

| キー | 動作 |
| --- | --- |
| `Tab` | 次のタブへ移動（タブ表示有効時、複数タブ存在時のみ。検索中は一致するアイテムがないタブを飛ばす） |

> **注意**: `Shift+Tab` は検索モード切り替え専用です（前のタブへの移動には使用できません）。

### モード切り替え

| キー | 動作 |
| --- | --- |
| `Ctrl+E` | 管理ウィンドウの表示/非表示（タブは切り替えない） |
| `Ctrl+W` | ワークスペースウィンドウを開く/閉じる（トグル） |

## 管理ウィンドウ

### データ編集

| キー | 動作 |
| --- | --- |
| `Ctrl+S` | データを保存（アイテム管理タブ） |
| `Delete` | 選択した行を削除（アイテム管理タブ） |
| `Enter` | セル編集の確定 |
| `Escape` | セル編集のキャンセル |

**注意**: 管理ウィンドウを閉じるには、以下のいずれかの方法を使用してください：

- ウィンドウ右上の閉じるボタン（×）
- メインウィンドウで Ctrl+E キー（トグル。管理ウィンドウの中で押しても閉じない）

**重要**: Escapeキーで管理ウィンドウを閉じることはできません（誤操作防止のため）。

### 開発者向け

| キー | 動作 |
| --- | --- |
| `Ctrl+Shift+I` | 開発者ツール（DevTools）を開く/閉じる（開発モードのみ） |

> 管理ウィンドウに限らず、ワークスペースウィンドウと切り離しウィンドウでも有効です。メインウィンドウでは無効です。

## ワークスペースウィンドウ

### 基本操作

| キー | 動作 |
| --- | --- |
| `Ctrl+W` | ワークスペースウィンドウの表示/非表示切り替え（メインウィンドウ内で有効） |
| `Ctrl+V` | クリップボードの中身からアイテムを追加（ファイル・URL・テキスト・画像など。作られるアイテムは [ワークスペース機能](./workspace.md#クリップボードから追加したとき)） |
| `Ctrl+F` | 絞り込み欄を表示して入力欄にフォーカス（`Escape`で閉じる。切り離しウィンドウでは無効） |
| `Enter` | タブ名・グループ名・アイテム名の編集を確定 |
| `Escape` | タブ名・グループ名・アイテム名の編集を取り消す |

`Ctrl` を押しながらアイテムをドラッグすると、アイテムをコピーしてドロップ先に追加する。

## ダイアログ操作

### AlertDialog（通知ダイアログ）

| キー | 動作 |
| --- | --- |
| `Escape` | ダイアログを閉じる |
| `Enter` | ダイアログを閉じる（OKボタンと同等） |

### ConfirmDialog（確認ダイアログ）

| キー | 動作 |
| --- | --- |
| `Escape` | ダイアログをキャンセルして閉じる |
| `Enter` | 確認を実行してダイアログを閉じる |

### 共通（モーダル・ダイアログ）

| キー | 動作 |
| --- | --- |
| `Tab` | フォーカスを次の要素へ（末尾からは先頭へ戻る） |
| `Shift+Tab` | フォーカスを前の要素へ（先頭からは末尾へ戻る） |

### FilePickerDialog（ファイル選択ダイアログ）

| キー | 動作 |
| --- | --- |
| `Escape` | ダイアログをキャンセルして閉じる |
