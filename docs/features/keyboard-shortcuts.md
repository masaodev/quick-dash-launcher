# キーボードショートカット

QuickDashLauncherで使用可能なキーボードショートカット一覧です。

## グローバルショートカット

| キー         | 動作                                                                                        |
| ------------ | ------------------------------------------------------------------------------------------- |
| （設定値）   | ランチャーウィンドウの表示/非表示切り替え（既定値は空。初回起動画面の初期値は `Alt+Space`） |
| （設定可能） | ウィンドウ検索モードで直接起動（設定画面で指定）                                            |

> **注意**: 起動ホットキーの既定値は空で、初回起動画面で `Alt+Space` が初期値として入力されています。設定画面でカスタマイズできます。他のアプリケーションとの競合を避けるため、お好みのキー組み合わせに変更してください。

**ウィンドウ検索で起動:**

- 設定画面（基本設定タブ）の「ウィンドウ検索で起動」でホットキーを設定可能
- 設定されたホットキーで起動すると、ウィンドウ検索モードが自動的に有効になります
- 空の場合は機能が無効になります

## ランチャーウィンドウ内

### 基本操作

| キー          | 動作                                                                                                               |
| ------------- | ------------------------------------------------------------------------------------------------------------------ |
| `Enter`       | 選択中のアイテムを起動                                                                                             |
| `Shift+Enter` | 選択中のアイテムの親フォルダを開く                                                                                 |
| `F5`          | 再読込（通常モード: 設定ファイルの再適用とデータファイル再読込、ウィンドウモード: ウィンドウ一覧更新、v0.6.0以降） |
| `Escape`      | ウィンドウを非表示（一部の状態では無効）                                                                           |
| `↑` `↓`       | アイテム選択の移動                                                                                                 |

**注意**: Escapeキーは、以下の状態ではウィンドウを閉じません：

- 初回起動モード（ホットキー未設定）
- モーダルモード（アイテムの登録・編集、アイコン取得結果の子ウィンドウが開いている）
- ピン留めモードが`alwaysOnTop`または`stayVisible`

### マウス操作

| 操作               | 動作                         |
| ------------------ | ---------------------------- |
| 左クリック         | アイテムを選択して起動       |
| 右クリック         | コンテキストメニューを表示   |
| `Escape`           | コンテキストメニューを閉じる |
| メニュー外クリック | コンテキストメニューを閉じる |

### 検索とフィルタリング

| キー        | 動作                                                                    |
| ----------- | ----------------------------------------------------------------------- |
| 文字入力    | リアルタイム検索（スペース区切りでAND検索）                             |
| `Shift+Tab` | 検索モード切り替え（通常→ウィンドウ→通常...）                           |
| `Ctrl+A`    | 検索ボックスの全選択                                                    |
| `Ctrl+↑`    | 検索履歴を遡る                                                          |
| `Ctrl+↓`    | 検索履歴を進む                                                          |
| `Ctrl+P`    | ウィンドウ検索モード時、選択中のウィンドウをピン留め/解除（v0.7.2以降） |

**検索モード切り替え:**

- `Shift+Tab`キーで2つの検索モードを順次切り替えます（通常 ↔ ウィンドウ）
- 現在のモードは検索ボックス下部のインジケーターに表示されます（例: 「通常検索モード」「🪟 ウィンドウ検索モード」。右側の「Shift+Tab: モード切り替え」はクリックでも切り替えられます）
- タブ表示の有無にかかわらず、`Shift+Tab`は常に検索モード切り替えに使われます（タブの移動は`Tab`）

**通常モード:**

- 通常のアイテム検索
- スペース区切りでAND検索が可能
- `F5`キーで設定の再適用とデータファイルの再読込が可能（v0.6.0以降）

**ウィンドウ検索モード内での追加ショートカット:**

| キー                | 動作                                                                                                                   |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `F5`                | ウィンドウ一覧を更新                                                                                                   |
| `Tab`               | 仮想デスクトップのタブを順に切り替え（仮想デスクトップが2つ以上のとき。検索中は一致するウィンドウがないタブを飛ばす）  |
| `Ctrl+D`            | 選択中のウィンドウを閉じる                                                                                             |
| `Ctrl+←` / `Ctrl+→` | 選択中のウィンドウを前後の仮想デスクトップに移動（デスクトップ番号のタブを表示中のみ。ピン止めしたウィンドウは対象外） |

**ウィンドウ検索モード:**

- システム内の開いているウィンドウをタイトルで検索できます
- 各ウィンドウにはアイコンが表示されます（Windows API + GDI+で取得）
- ウィンドウを選択すると、そのウィンドウがアクティブ化（フォーカス）されます
- 最小化されているウィンドウは自動的に復元されます
- データファイルのタブが隠れ、仮想デスクトップのタブ（仮想デスクトップが2つ以上のとき）に切り替わります
- **v0.5.22以降**: 仮想デスクトップごとのタブ + ピン止めタブで絞り込みが可能
  - 「すべて」「ピン止め」「1」「2」...のタブで切り替え
  - 「ピン止め」タブ: 全仮想デスクトップにピン止めされたウィンドウのみ表示（該当ウィンドウがある場合のみ表示）
  - 現在アクティブなデスクトップには「(現在)」ラベルを表示（例: 「1 (現在)」）
  - タブごとのウィンドウ数がカウント表示されます
- **v0.7.2以降**: `Ctrl+P`で選択中のウィンドウをピン留め/解除（全仮想デスクトップに表示/解除）

**ウィンドウフィルタリング:**

- Alt+Tabと同じフィルタリングロジックを使用
- 以下のウィンドウは一覧から除外されます：
  - 不可視ウィンドウ（WS_VISIBLE フラグなし）
  - ツールウィンドウ（WS_EX_TOOLWINDOW）でAppWindowフラグがないウィンドウ
  - オーナーウィンドウを持つウィンドウ（所有されているウィンドウ）
  - DWM APIでクローキングされているウィンドウ（仮想デスクトップの切り替えで隠れているものは除く）
  - QDL 自身のメインウィンドウ
- 全仮想デスクトップのウィンドウが対象です
- これにより、「Windows 入力エクスペリエンス」などのシステムウィンドウが除外され、通常のアプリケーションウィンドウのみが表示されます

### タブ操作

| キー  | 動作                                                                                             |
| ----- | ------------------------------------------------------------------------------------------------ |
| `Tab` | 次のタブへ移動（タブ表示有効時、複数タブ存在時のみ。検索中は一致するアイテムがないタブを飛ばす） |

> **注意**: `Shift+Tab` は検索モード切り替え専用です（前のタブへの移動には使用できません）。

### モード切り替え

| キー     | 動作                                            |
| -------- | ----------------------------------------------- |
| `Ctrl+E` | アイテム管理の開始/終了                         |
| `Ctrl+W` | ワークスペースウィンドウを開く/閉じる（トグル） |

## 管理ウィンドウ

### データ編集

| キー     | 動作                                 |
| -------- | ------------------------------------ |
| `Ctrl+S` | データを保存（アイテム管理タブ）     |
| `Delete` | 選択した行を削除（アイテム管理タブ） |
| `Enter`  | セル編集の確定                       |
| `Escape` | セル編集のキャンセル                 |

**注意**: 管理ウィンドウを閉じるには、以下のいずれかの方法を使用してください：

- ウィンドウ右上の閉じるボタン（×）
- ランチャーウィンドウでCtrl+Eキー（トグル）

**重要**: Escapeキーで管理ウィンドウを閉じることはできません（誤操作防止のため）。

### 開発者向け

| キー           | 動作                                                    |
| -------------- | ------------------------------------------------------- |
| `Ctrl+Shift+I` | 開発者ツール（DevTools）を開く/閉じる（開発モードのみ） |

> 管理ウィンドウに限らず、ワークスペースウィンドウと切り離しウィンドウでも有効です。メインウィンドウでは無効です。

### テーブル操作

| 操作     | 動作           |
| -------- | -------------- |
| クリック | セル編集の開始 |

## システム操作

### アイコン取得

| 操作                                             | 動作                                                                                         |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| 🔄ドロップダウン → 🎨 アイコン取得（現在のタブ） | 現在表示中のタブのアイコンが未設定のアイテムのみを対象に一括取得（フォルダとグループを除く） |
| 🔄ドロップダウン → 🎨 アイコン取得（全タブ）     | すべてのタブのアイコンが未設定のアイテムを対象に一括取得（フォルダとグループを除く）         |

### ウィンドウ制御

| 操作                         | 動作                                                            |
| ---------------------------- | --------------------------------------------------------------- |
| 📌ボタンクリック             | ピン留めモードを切り替え（通常 → 常に最上面 → 表示固定 → 通常） |
| システムトレイダブルクリック | ウィンドウ表示                                                  |
| システムトレイ右クリック     | システムトレイメニューを表示                                    |

## 設定メニュー（⚙ボタン）

| 項目                    | 動作                                                             |
| ----------------------- | ---------------------------------------------------------------- |
| ⚙️ 基本設定             | 管理ウィンドウの設定タブを開く（ホットキー、ウィンドウサイズ等） |
| ✏️ アイテム管理         | 管理ウィンドウの編集タブを開く（データファイル編集）             |
| 🗂️ ワークスペースを表示 | ワークスペースウィンドウを開く/閉じる（トグル）                  |
| 🚪 アプリを終了         | アプリケーションを終了                                           |

## システムトレイメニュー（右クリック）

| 項目                 | 動作                                                           |
| -------------------- | -------------------------------------------------------------- |
| バージョン情報       | 現在のバージョンを表示（選択不可）                             |
| 表示 (ホットキー)    | メインウィンドウを表示（設定されたホットキーも表示）           |
| 画面中央に表示       | 設定に関係なく強制的に画面中央に表示                           |
| 設定...              | 管理ウィンドウの設定タブを開く                                 |
| データフォルダを開く | データフォルダをエクスプローラーで開く                         |
| ヘルプ               | GitHubリポジトリをブラウザで開く                               |
| 再起動               | アプリケーションを再起動（開発モードでは警告ダイアログを表示） |
| 終了                 | アプリケーションを終了                                         |

## ワークスペースウィンドウ

### 基本操作

| キー     | 動作                                                                                       |
| -------- | ------------------------------------------------------------------------------------------ |
| `Ctrl+W` | ワークスペースウィンドウの表示/非表示切り替え（ランチャーウィンドウ内で有効）              |
| `Ctrl+V` | クリップボードからファイル・フォルダ・URLをペーストして追加（v0.5.1以降）                  |
| `Ctrl+F` | フィルターバーを表示して入力欄にフォーカス（`Escape`で閉じる。切り離しウィンドウでは無効） |
| `Enter`  | 編集モードで名前を確定                                                                     |
| `Escape` | 編集モードをキャンセル                                                                     |

### マウス操作

| 操作                       | 動作                                 |
| -------------------------- | ------------------------------------ |
| アイテムをクリック         | アイテムを起動                       |
| アイテムをダブルクリック   | アイテム名の編集モードに移行         |
| アイテムを右クリック       | コンテキストメニューを表示           |
| アイテムをドラッグ         | アイテムの並び替え・グループ間移動   |
| アイテムを`Ctrl`+ドラッグ  | アイテムをコピーしてドロップ先に追加 |
| グループヘッダーをドラッグ | グループの並び替え                   |

## ダイアログ操作

### AlertDialog（通知ダイアログ）

| キー     | 動作                                 |
| -------- | ------------------------------------ |
| `Escape` | ダイアログを閉じる                   |
| `Enter`  | ダイアログを閉じる（OKボタンと同等） |

### ConfirmDialog（確認ダイアログ）

| キー     | 動作                             |
| -------- | -------------------------------- |
| `Escape` | ダイアログをキャンセルして閉じる |
| `Enter`  | 確認を実行してダイアログを閉じる |

### FilePickerDialog（ファイル選択ダイアログ）

| キー     | 動作                             |
| -------- | -------------------------------- |
| `Escape` | ダイアログをキャンセルして閉じる |
