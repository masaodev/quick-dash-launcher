# ブックマークの取り込み

ブラウザのブックマークをランチャーのアイテムにする入口は 1 つの画面にまとまっています。アイテム管理の「アイテムを一括取り込み ▼ › ブラウザのブックマークを追加」（メインウィンドウの ➕ メニュー「🔖 ブラウザのブックマークを追加」からも、管理ウィンドウでこの画面が開きます）を開くと、設定「ブックマーク自動取込」のルール編集と同じ条件（ブラウザ／プロファイル／フォルダ／URL・名前のパターン／表示名）で絞り込み、**「今回だけ取り込む」か「ルールとして保存」か**を選びます（v0.7.38 以降）。

## 「今回だけ取り込む」と「ルールとして保存」

|                      | 今回だけ取り込む                                                                                    | ルールとして保存（＝自動取込）                                                                                                                                    |
| -------------------- | --------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 向いている用途       | 一度だけ取り込んで、あとは自分で名前や並びを編集する                                                | 同じフォルダを毎回取り込み、ブラウザ側の変更に追従させる                                                                                                          |
| 取込元               | Chrome / Edge から直接、または HTML ファイル（他ブラウザからのエクスポート）                        | Chrome / Edge から直接（HTML ファイルはルールにできない）                                                                                                         |
| 取り込んだアイテム   | 通常のアイテムと同じ（印は付かない）                                                                | `autoImportRuleId` が付き、アイテム管理で「自動取込」と表示される                                                                                                 |
| 実行のタイミング     | 押したとき                                                                                          | 保存した直後に 1 回実行。以後は起動時（設定で ON のとき）、設定の「今すぐ全ルール実行」「実行」、メイン画面の 🔄 メニュー「ブックマーク取込」「完全リフレッシュ」 |
| 既存アイテムとの関係 | 取込先に同じ URL があれば「スキップ」か「上書き」を選ぶ。上書きは既存の ID と自動取込の印を引き継ぐ | **そのルールで入れたアイテムを全削除して入れ直す**（置き換え）。手動で入れたアイテムは触らない                                                                    |
| 保存                 | アイテム管理の「変更を保存」で確定（未保存の編集として入る）                                        | 実行時にデータファイルへ直接書き込む                                                                                                                              |

- 取込画面のプレビューは条件を変えるたびに更新されます（マッチ件数と先頭 50 件）。「今回だけ取り込む」のボタンにも件数が出ます。
- ルール名は「ルールとして保存」のときだけ必要です。
- 設定「ブックマーク自動取込」の「+ ルールを追加」「編集」も同じ画面ですが、フッターは「キャンセル」「保存」です（保存しても実行はしません）。

## 自動取込の注意

- ルールで取り込んだアイテムを手で編集しても、次の実行で置き換えられて消えます（編集画面で警告が出ます）。名前を変えたいときはルールの接頭辞・接尾辞・フォルダ名付与を使ってください。
- 手動で（または別のルールで）登録済みの URL と同じものをルールが取り込むと、同じ URL のアイテムが 2 つになります。ルールは自分が入れた分しか入れ替えないためです。実行結果に「手動分と重複 N 件」と出るので、どちらかを整理してください。
- 取込先のデータファイルを削除すると、そのファイルを取込先にしたルールは無効になります。

## 画面のあいだの導線

- 取込画面の上部に「自動取込の設定を開く」ボタンがあります（既存ルールの確認用。取込画面を閉じて設定の該当カテゴリを開く）。
- アイテム管理の「アイテムを一括取り込み ▼」に「ブックマーク自動取込の設定…」があります。
- メインウィンドウの ➕ メニュー「🔖 ブラウザのブックマークを追加」から、管理ウィンドウを開いてこの取込画面を表示できます。
- 設定「ブックマーク自動取込」の上部に「手動で取り込む」ボタンがあります（アイテム管理タブに切り替えて取込画面を開く）。
