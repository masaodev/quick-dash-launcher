# ブックマークの取り込み

ブラウザ（Chrome / Edge）のブックマークをランチャーのアイテムにする方法は 2 つあります。目的が違うので、使い分けを先に示します。

## 使い分け

|                      | 手動取込（アイテム管理 › アイテムを一括取り込み › ブラウザのブックマークを追加）            | 自動取込（設定 › ブックマーク自動取込）                                                                                            |
| -------------------- | ------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 向いている用途       | 一度だけ取り込んで、あとは自分で名前や並びを編集する                                        | 同じフォルダを毎回取り込み、ブラウザ側の変更に追従させる                                                                           |
| 選び方               | プロファイルを選び、一覧から 1 件ずつチェック（検索・表示中を選択）                         | ルールにブラウザ・プロファイル・フォルダ・URL／名前のパターン・表示名の接頭辞などを指定                                            |
| 取り込んだアイテム   | 通常のアイテムと同じ（印は付かない）                                                        | `autoImportRuleId` が付き、アイテム管理で「自動取込」と表示される                                                                  |
| 実行のタイミング     | 押したとき                                                                                  | 起動時（設定で ON のとき）、設定の「今すぐ全ルール実行」「実行」、メイン画面の 🔄 メニュー「ブックマーク取込」「完全リフレッシュ」 |
| 既存アイテムとの関係 | 同じ URL があれば「スキップ」か「上書き」を選ぶ。上書きは既存の ID と自動取込の印を引き継ぐ | **そのルールで入れたアイテムを全削除して入れ直す**（置き換え）。手動で入れたアイテムは触らない                                     |
| 保存                 | アイテム管理の「変更を保存」で確定（未保存の編集として入る）                                | 実行時にデータファイルへ直接書き込む                                                                                               |

## 自動取込の注意

- ルールで取り込んだアイテムを手で編集しても、次の実行で置き換えられて消えます（編集画面で警告が出ます）。名前を変えたいときはルールの接頭辞・接尾辞・フォルダ名付与を使ってください。
- 手動で登録済みの URL と同じものをルールが取り込むと、同じ URL のアイテムが 2 つになります。ルールは手動分を消さないためです。実行結果に「手動分と重複 N 件」と出るので、どちらかを整理してください。
- 取込先のデータファイルを削除すると、そのファイルを取込先にしたルールは無効になります。

## 画面のあいだの導線

- 手動取込モーダルの上部に、自動取込への案内と「自動取込の設定を開く」ボタンがあります（モーダルを閉じて設定の該当カテゴリを開く）。
- アイテム管理の「アイテムを一括取り込み ▼」に「ブックマーク自動取込の設定…」があります。
- 設定「ブックマーク自動取込」の上部に「手動で取り込む」ボタンがあります（アイテム管理タブに切り替えて手動取込モーダルを開く）。
