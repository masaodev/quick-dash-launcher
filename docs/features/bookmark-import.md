# ブックマークの取り込み

ブラウザのブックマークをランチャーのアイテムにする画面は 2 つあります。

- **アイテム管理から**（「＋ アイテムを追加」の右隣の ▼ › 「🔖 ブラウザのブックマークから追加」。ランチャーの ➕ メニュー「🔖 ブラウザのブックマークから追加」からも、管理ウィンドウでこの画面が開きます）: ブックマーク取込画面。アプリ取込と同じく、フォルダの木にチェックを入れて選びます。**今回だけ取り込む**のが基本で、フォルダごと選んだときだけ**これからも自動で取り込む**（自動取込のルールとして保存）を選べます
- **設定「ブックマーク自動取込」の「＋ ルールを追加」「編集」から**: ブックマークの取込ルールの追加・編集画面。フォルダ（取り込む／除く）・名前と URL に含む文字・表示名を決めた、細かいルールを作ります

## 今回だけ取り込むか、これからも自動で取り込むか

| | 今回だけ取り込む | これからも自動で取り込む（＝自動取込のルール） |
| --- | --- | --- |
| 向いている用途 | 一度だけ取り込んで、あとは自分で名前や並びを編集する | 同じフォルダ・条件のブックマークを毎回取り込み、ブラウザ側の変更に追従させる |
| 作る画面 | アイテム管理から開く取込画面 | 取込画面で「〜を、これからも自動で取り込む」（フォルダごと選んだときだけ）、または設定の「＋ ルールを追加」 |
| 取込元 | Chrome / Edge から直接、または HTML ファイル（他ブラウザからの書き出し） | Chrome / Edge から直接（HTML ファイルはルールにできない） |
| 選び方・条件 | フォルダや 1 件ずつのチェック。名前・URL で探して選ぶこともできる | フォルダ（取り込む／除いて残りを取り込む。サブフォルダも含む）、名前・URL に含む文字（正規表現は使わない） |
| 取り込んだアイテム | 通常のアイテムと同じ（印は付かない） | 自動取込の印が付き、アイテム管理で「自動取込」と表示される |
| 実行のタイミング | 押したとき | 取込画面から保存したときはすぐ 1 回実行。以後は起動時（設定で ON のとき）、設定の「今すぐ全ルール実行」「実行」、ランチャーの 🔄 メニュー「🔁 ブックマーク自動取込を実行」（v0.8.0-beta.22 までは「🔄 完全リフレッシュ」でも実行した） |
| 既存アイテムとの関係 | 取込先に同じ URL があれば「スキップ」か「上書き」を選ぶ。上書きは既存の ID と自動取込の印を引き継ぐ | **そのルールで入れたアイテムと URL で突き合わせ、差分だけ反映する**（ブックマークに無くなった URL は削除、新しい URL は追加、表示名が変わったものは表示名だけ更新）。残るアイテムの ID・メモ・アイコンなどはそのまま。手動で入れたアイテムは触らない |
| 保存 | アイテム管理の「変更を保存」で確定（未保存の編集として入る） | 実行時にデータファイルへ直接書き込む |

- どちらの画面も、取込先はアプリ取込と同じ「取込先タブ [タブ ▼] › [ファイル ▼]」の帯で選びます。初期値はタブの先頭のデータファイルで、新しいデータファイル（名前の初期値は「ブックマーク」）や新しいタブも作れます。
- 取込画面から作ったルールには、名前の条件とフォルダ名の付け方は付きません（頭・後ろに付ける文字は取込画面で入れたものが付きます）。あとで設定の「編集」から足せます。

## 自動取込の注意

- ルールで取り込んだアイテムの表示名と URL は、次の実行でブックマークの内容に戻ります（編集画面で警告が出ます）。名前を変えたいときは、ルールの編集画面のオプション設定（表示名）を使ってください。メモ・アイコン・引数・ウィンドウの設定は、ブックマークが残っている間は次の実行でも残ります。
- 同じ URL のブックマークが複数あるときは、前回のアイテムと出現順で対応づけます。
- 実行結果は「N 件追加、N 件更新、N 件削除」と出ます（0 件の区分は省き、どれも無ければ「変更なし」）。起動時の自動実行は、変わったとき（とエラーのとき）だけトーストで知らせます。
- 手動で（または別のルールで）登録済みの URL と同じものをルールが取り込むと、同じ URL のアイテムが 2 つになります。ルールは自分が入れた分しか入れ替えないためです。実行結果に「手動分と重複 N 件」と出るので、どちらかを整理してください。
- プロファイルは 1 つだけ選びます。複数のプロファイルから取り込みたいときは、プロファイルごとにルールを作ってください。選んだプロファイルが無くなると、実行がエラーになります（取り込み済みのアイテムは残ります。編集画面で選び直してください）。
- 取込先のデータファイルを削除すると、そのファイルを取込先にしたルールは無効になります。

## 画面のあいだの導線

- 取込画面の下の自動取込の帯の右端に「ブックマーク自動取込（ルール N 件）」のリンクがあります（ルールが無くても出ます。取込画面を閉じて設定の該当カテゴリを開く）。
- アイテム管理の「＋ アイテムを追加」の右隣の ▼ に「⚙️ ブックマーク自動取込の設定…」があります。
- ランチャーの ➕ メニュー「🔖 ブラウザのブックマークから追加」から、管理ウィンドウを開いてこの取込画面を表示できます。
- 設定「ブックマーク自動取込」の上部に「手動で取り込む」ボタンがあります（アイテム管理タブに切り替えて取込画面を開く）。
