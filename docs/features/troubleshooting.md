# 困ったとき

よくある問題と対処です。ここで解決しないときは [GitHub Issues](https://github.com/masaodev/quick-dash-launcher/issues) で報告してください。

## ランチャーが起動しない

- タスクマネージャーで、QuickDashLauncher のプロセスがすでに動いていないか確認してください
- タスクトレイのアイコンをダブルクリックしてみてください

## ホットキー（Alt+Space）が効かない

- ほかのアプリとホットキーが競合している可能性があります。設定画面で別のキーに変えてみてください（[キーボードショートカット](./keyboard-shortcuts.md)）
- 管理者権限で実行してみてください

## ウィンドウ配置が正しく動作しない

- ウィンドウの位置は仮想スクリーン座標（メインモニターの左上が原点）で指定します。ディスプレイ設定でモニターの配置を確認してください
- ウィンドウ制御設定の「ウィンドウから取得」を使うと、いま開いているウィンドウの位置・サイズを取り込めます

## フォルダ取込が展開されない

- フォルダのパスが正しいか確認してください
- フォルダへのアクセス権限を確認してください

## アイコンが表示されない

- Web サイトのファビコンは、初めて表示するときに自動で取得します
- 設定フォルダの `icon-cache\favicons\` の権限を確認してください（設定フォルダは既定で `%APPDATA%\quick-dash-launcher\config\`。詳細は [アイコンシステム](./icons.md)）
