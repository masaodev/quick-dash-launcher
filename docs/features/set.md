# セット

複数のアイテムをまとめて開き、必要ならウィンドウを決まった位置に並べる種別「セット」の説明です。旧グループ（まとめて開く）と旧ウィンドウ配置（ウィンドウの位置を記録して並べる）を 1 つにまとめたものです。

## 概要

セットは「行」を上から並べたものです。行は 1 つずつ、次の 3 つを持ちます。

| 行が持つもの | 意味 |
| --- | --- |
| 開くもの | 登録済みのアイテムか、セットに書いたパス。無ければ何も開かない |
| 対象ウィンドウ | 行が使うウィンドウを、exe 名とウィンドウタイトルで探す条件 |
| ウィンドウ位置 | ウィンドウを置く場所と大きさ・最大化・仮想デスクトップ。無ければ開くだけ |

セットを起動すると、行ごとに開くものを開き、ウィンドウ位置のある行はウィンドウが出るのを待ってその位置へ動かします。

- まとめて開くだけなら、アイテムを行に足すだけでよい（旧グループと同じ使い方）
- 開いているウィンドウを並べたいときは、「ウィンドウを追加」で選んだウィンドウを今のウィンドウ位置ごと行にする。足した行は、開くものを持たない動かすだけの行になる
- ウィンドウを並べ直したら、「ウィンドウ位置を更新」で今ある行の位置を取り込み直す（行は足さない）
- 1 つのセットの中で、ウィンドウ位置のある行と無い行を混ぜられる

使い方の例:

- 「業務開始」: メール・カレンダー・チャットを開くだけ
- 「開発」: エディタを左半分、ブラウザを右半分、ターミナルを右下に開いて並べる

## 行の種類

| 行 | 開くもの | 起動したとき |
| --- | --- | --- |
| アイテムを指す行 | 登録済みのアイテム（通常のアイテムかウィンドウ操作）。id で指すので、アイテムの名前やパスを直すとセットにも効く | アイテムと同じように開く。ウィンドウ操作のアイテムは、そのウィンドウを探して前に出す |
| パスを書いた行 | セットの中だけに書いたパス（と引数）。ファイル・フォルダ・exe・URL・カスタム URI | パスを開く |
| 動かすだけの行 | なし | 何も開かず、既に開いているウィンドウを位置へ動かす。開いていなければ何もしない（失敗とは数えない） |

- アイテムを指す行は、どのタブのアイテムでも指せる。ワークスペースのセットは、ワークスペースのアイテムも指せる
- フォルダ取込で展開したアイテムは id を持たないので、行に足すとパスを書いた行になる
- セット・クリップボードのアイテムは行にできない（セットの中にセットは入らない）
- 指したアイテムが消えた行は「アイテムが見つかりません」と表示され、起動したときはその行だけ失敗する
- 「ウィンドウを追加」で足した行は動かすだけの行になる。ほかのアプリが起動したときの引数は取れず、exe を開いても開いていたファイルは開かないため。閉じていても開きたいときは、行の詳細で開くもの（アイテムかパス）を後から足せる

## 開き方

| 開き方 | 動き |
| --- | --- |
| 順番に開く（既定） | 上の行から 1 行ずつ開く。行を開いてから次の行を開くまで 100 ミリ秒あける。ウィンドウが出るのを待って位置を合わせる処理は裏で続け、次の行を開くのはその完了を待たない |
| 同時に開く | 全部の行を一度に開き、ウィンドウが出たものから位置を合わせる |

開き方はセットごとに決めます。

同じセットを開いている途中（ウィンドウを待っている間も含む）にもう一度開いても、重ねては開きません（Enter の二度押しで、どのアプリも 2 つずつ開かないように）。別のセットは並行して開けます。

## 対象ウィンドウの探し方

ウィンドウ位置のある行は、次の条件に合うウィンドウを探して動かします。

- **exe 名**: 部分一致（大文字小文字は区別しない）
- **ウィンドウタイトル**: タイトル全体と一致するものを探す。`*` は任意の文字列、`?` は任意の 1 文字（大文字小文字は区別しない）。例: `*Obsidian` は末尾が Obsidian のタイトルに合う。空ならタイトルは問わない
- **タイトルの一部だけで探す**: 前後に `*` を付ける（例: `*一時メモ.txt*`）。タブの切り替え・アプリの更新などでタイトルの一部が変わるウィンドウ向け。`*` だけにすると、タイトルを問わず exe 名だけで探す。行の詳細に、タイトルを区切りで分けた部品からこの形を作る候補と「タイトルを問わない」がある
- 両方あるときは、両方に合うものを探す

「ウィンドウを追加」「ウィンドウ位置を更新」で取り込むとき、対象ウィンドウの条件は次のように決まります。

- exe 名とタイトル全体をいつも保存する（記録したときに開いていたウィンドウの数では変えない。「そのページ・そのファイルのウィンドウ」をその位置に置く）
- タイトルが変わるもの（ブラウザのタブ・版番号の入るアプリなど）は、行の詳細で一部だけ・タイトルを問わないにする

行の詳細では、1 行ずつ取り込み直せます。「🔍 開いているウィンドウから選ぶ」は選んだウィンドウの exe 名・タイトル・ウィンドウ位置をまとめて入れ、「📍 ウィンドウ位置を更新」は今の条件に合うウィンドウの位置だけを記録し直します（条件は変えない。合うウィンドウが 2 つ以上なら選ぶ）。

行に対象ウィンドウの条件が無いときは、開くものから探します。

- 起動時: 開くものが exe なら、その exe 名で探す。それ以外（URL など）は探せないので、位置があっても開くだけにする
- 記録時: exe はパス、フォルダはエクスプローラーのタイトル、ファイルはタイトルに含まれるファイル名で結び付ける。URL・カスタム URI はどのウィンドウに開くか決まらないので自動では結び付けない（ウィンドウ位置を更新の画面で手で選べば記録できる）

## 位置合わせ

- **ウィンドウを待つ**: 開いてからウィンドウが出るのを、0.5 秒おきに探して待つ。待つ時間は行ごとに決められる（既定 30 秒）。出なければその行は失敗する
- **同じアプリのウィンドウを取り合わない**: 1 回の起動の中で、ある行が動かすと決めたウィンドウは、ほかの行の候補から外す。同じアプリのウィンドウを 2 行で別々の位置に置ける
- **置く先のデスクトップのウィンドウを先に使う**: 対象ウィンドウの条件に合うウィンドウが複数の仮想デスクトップにあれば、行の仮想デスクトップにあるものを先に使う（ほかのデスクトップのウィンドウを引き抜かない）。ウィンドウ位置を更新・ウィンドウを追加（追加済みの見分け）の自動の結び付けと、右クリックのウィンドウ位置を更新も同じ
- **動かす順番**: 最小化されていれば元に戻し、位置と大きさを変え、仮想デスクトップを移し、行の「前面に出す」が「出す」なら前面に出す（既定は「出さない」）
- **最大化**: 最大化した状態で記録した行は、記録した位置へ動かしてから最大化する（その位置の画面で最大化される）
- **仮想デスクトップ**: 記録したときの仮想デスクトップ番号へ移す。番号が無い行は仮想デスクトップを変えない。今は無いデスクトップの番号（デスクトップを減らした後など）の行は、デスクトップを移さず位置だけ合わせ、失敗として知らせる。仮想デスクトップが 1 つのときは、記録しても番号を残さない（後でデスクトップを増やして別のデスクトップから開いたとき、見えないデスクトップ 1 へ引き戻さないため）
- **最小化中のウィンドウ**: 最小化中は今の位置が取れないので、「ウィンドウ位置を更新」では位置を入れない（元の大きさに戻してから更新する）。「ウィンドウを追加」では選べるが、足した行は位置を持たない
- **全デスクトップに表示**: 行の詳細で「📌 全デスクトップに表示」を入れた行は、セットを開いたときにそのウィンドウを全デスクトップに表示する（位置のある行・無い行のどちらも）。この行はデスクトップの番号を持たず、仮想デスクトップは移さない

ウィンドウ位置は保存した座標から、「画面 1・左半分」「右上」「最大化」のような言葉で表示します。言葉は保存せず、表示のたびに今の画面の構成から計算します（記録したときの画面が今は無ければ「今は無い画面」）。仮想デスクトップの番号がある行は「・デスクトップ N」を添えます。今は無い画面の位置の行を起動すると、見えない所へ動かさないよう、主画面の作業領域に収めて中央に置きます。

## 開いていたときの動き

行ごとに「開いていたら」を選べます。

| 選択 | 動き |
| --- | --- |
| 開かずに、そのウィンドウを使う（既定） | 対象ウィンドウが既に開いていれば、開き直さずにそのウィンドウをウィンドウ位置へ動かす。開いていなければ開いて待つ |
| もう 1 つ開く | 既に開いているウィンドウは除いて、新しく開いたウィンドウを待って位置を合わせる |

ウィンドウ位置の無い行でも、行に対象ウィンドウの条件があるか、指したアイテムにウィンドウ制御の設定があれば、「開かずに、そのウィンドウを使う」のときは開いているウィンドウを前面に出すだけにします（アイテムのウィンドウ制御に位置があれば、それも当てる。見つからなければ開く）。

## 失敗の知らせ方

- 1 つの行が失敗しても、ほかの行は続ける
- 動かすだけの行（ウィンドウ操作のアイテムを指す行を除く）は、ウィンドウが開いていなければ失敗にせず飛ばす。進み具合では灰色の「－」と「開いていないので動かしませんでした」を出す。同じ exe のウィンドウは開いていてタイトルだけ合わないときは「タイトルが合うウィンドウがありません（{exe 名} は開いています）」を出す（どちらも失敗とは数えない）。失敗とは数えないので、ほかが成功なら進み具合は自動で閉じ、警告のトーストにも出ない。ウィンドウ操作のアイテムを指す行と、指したアイテムが見つからない行は今までどおり失敗する
- ウィンドウ位置のある行を持つセットは、起動すると画面の隅に進み具合を出す。行ごとの成否（ウィンドウが見つからない・待ちきれなかった・アイテムが見つからない・ウィンドウを動かせなかったなど）はそこに出し、途中で中止できる
- 位置を当てても動かないウィンドウ（管理者権限で動くウィンドウなど）は「ウィンドウを動かせませんでした」で失敗にする。大きさが固定のウィンドウで誤って失敗にしないよう、確かめるのは位置だけ
- 今は無い仮想デスクトップの番号の行は、位置だけ合わせて「デスクトップ N がありません。位置だけ合わせました」で失敗にする
- ウィンドウ位置のある行を持たないセットは、開けなかった行があると、行の名前を並べた警告のトーストを出す

## 右クリックでウィンドウ位置を更新

ウィンドウ位置のある行を持つセットは、メインウィンドウの右クリックの「ウィンドウ位置を更新」で、編集画面を開かずに行の位置だけを今のウィンドウから取り直せます。

- 行の追加・削除はしない。位置と対象ウィンドウの条件を持つ行ごとに、その条件でウィンドウを探し、見つかった行の位置を上書きする（1 つのウィンドウは 1 行にだけ使う）
- 見つからない行は前のウィンドウ位置のまま。最小化中のウィンドウは使わない
- 仮想デスクトップは、編集画面の「📍 ウィンドウ位置を更新」と同じく今のデスクトップの番号を入れる（番号が空だった行にも入れる。全デスクトップに表示中で番号が無ければ空にし、仮想デスクトップが 1 つなら入れない）

## 旧グループ・旧ウィンドウ配置からの変換

旧グループ（`type: "group"`）と旧ウィンドウ配置（`type: "layout"`）は、読み込んだときに 1 回だけセットに変換し、ファイルに書き戻します（データファイルとワークスペースの両方）。動きは変えないように変換します。

| 元 | 変換後 |
| --- | --- |
| 旧グループ | 書かれていたアイテムの名前ごとに、そのアイテムを指す行にする。開き方は、削除した設定「グループアイテムを並列起動」がオンなら同時に開く、オフなら順番に開く |
| 旧グループの、フォルダ取込で展開したアイテムの名前 | パスを書いた行 |
| 旧グループの、見つからない名前 | 名前だけを残した行（「アイテムが見つかりません」と表示される） |
| 旧ウィンドウ配置 | ウィンドウ 1 つごとに、対象ウィンドウとウィンドウ位置を持つ行にする。アプリを起動する設定だったものは、その exe を開くものにする。タイトルは前後に `*` を付けて部分一致にし、元のタイトルを行の名前にする。開き方は同時に開く |

- 変換は元に戻せないので、変換する前に設定フォルダのファイル一式を `backup/<日時>_pre-set-migration/` に残す。バックアップの設定がオフでも作る。これを作れなければ変換しない
- 変換すると、この版より前の QuickDashLauncher ではそのファイルを読めなくなる。前の版に戻すときは、このバックアップを使う
- ワークスペースの旧グループは、名前をデータファイルのアイテムから探す。フォルダ取込で展開したアイテムの名前は見つからない行になる

## 既知の制限

- **タブで開くもの**: フォルダや URL は、既にあるエクスプローラーやブラウザのウィンドウにタブとして開くことがある。そのときは位置を合わせるとウィンドウごと動く
- **エクスプローラー・ストアアプリ**: exe 名が共通なので、タイトルで見分ける
- **管理者権限のウィンドウ**: QuickDashLauncher が管理者権限で動いていないと、管理者権限で動いているウィンドウは動かせないことがある（ウィンドウを追加・ウィンドウ位置を更新の画面で知らせる）
- **アイコン**: セットのアイコンは 📦。カスタムアイコンを設定すると、メインウィンドウ・ワークスペース・アイテム管理の一覧でそれを出す
