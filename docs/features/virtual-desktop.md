# 仮想デスクトップ

Windows の仮想デスクトップに関わる機能のまとめです。仮想デスクトップに関わる操作は、ウィンドウ検索・アイテムのウィンドウ制御・ワークスペース・メインウィンドウの 4 か所にあります。ここでは何ができるかと、使える環境だけを書き、操作の手順と細かい挙動は各文書に任せます。

## 使える環境

Windows 10 以降で、Windows が仮想デスクトップの情報を記録していて、仮想デスクトップを操作する同梱の部品（DLL）を読み込めたときに使えます。使えない環境では、ウィンドウ検索のデスクトップのタブ・全デスクトップに表示のメニューとヒントを出さず、右クリックの「仮想デスクトップへの移動」は押せない状態で出します。ウィンドウ検索の Ctrl+P（全デスクトップに表示）は、押すと「この環境は仮想デスクトップに対応していません。」とトーストで知らせます。

## 用語

| 用語 | 意味 |
| --- | --- |
| デスクトップ番号 | 仮想デスクトップの並び順の番号（1 から） |
| 全デスクトップに表示 | ウィンドウをすべての仮想デスクトップに表示すること（Windows の「このウィンドウをすべてのデスクトップに表示する」と同じ）。メインウィンドウのピン留め（📌）とは別のもの |

## ウィンドウ検索

ウィンドウ検索モードでは、ほかの仮想デスクトップにあるウィンドウも一覧に出し、仮想デスクトップをまたいで切り替えられます。

- **デスクトップごとのタブ**: 仮想デスクトップが 2 つ以上あるとき、「すべて」「全デスクトップ」と、デスクトップ番号ごとのタブで絞り込める。開いたときは今のデスクトップのタブを選んでいる
- **デスクトップの呼び方**: 名前を付けたデスクトップは「2: 仕事」のように番号と名前、名前が無ければ番号だけで出す。ウィンドウ検索のタブ・右クリックの移動先・ウィンドウを選ぶ画面・セットの位置の表示で同じ形にする（名前が「デスクトップ 2」のように番号を繰り返しているだけなら番号だけ）
- **ほかのデスクトップへ移す**: 個別のデスクトップのタブで Ctrl+←/→ を押すと、隣のデスクトップへ移す。右クリックでは移す先の番号を選べる
- **全デスクトップに表示**: Ctrl+P か右クリックで、表示と解除を切り替える
- 複数のウィンドウを選んでいるときは、移す・全デスクトップに表示がまとめて効く
- **別のデスクトップのウィンドウを選ぶ**: そのデスクトップへ切り替えてから前に出す

操作と細かい挙動はメインウィンドウの画面仕様（ウィンドウ検索モードの節）、キーの一覧は [キーボードショートカット](./keyboard-shortcuts.md#検索とフィルタリング)。

## アイテムのウィンドウ制御

アイテムを開いたとき・ウィンドウを前に出したときに、ウィンドウを決まった仮想デスクトップへ移したり、すべてのデスクトップに固定したりできます。

- **単一アイテム**（アプリ・ファイルなど。パスの無い単一アイテムも）: 登録画面のウィンドウ切り替え（ウィンドウ位置の枠）で、移す先の仮想デスクトップの番号と「📌 全デスクトップに表示」を指定する
- **セット**: 複数のウィンドウの位置・サイズと仮想デスクトップを行ごとに記録し、開くときに並べ直す。仮想デスクトップの番号が無い行は、デスクトップを変えない（[セット](./set.md#位置合わせ)）

ウィンドウは、どの仮想デスクトップにあっても探して見つける。位置・サイズを合わせてから移し、移った先でもう一度合わせるので、今のデスクトップを切り替えずに並べられる。

移す先のデスクトップ番号を指定していないアイテムで、既に開いているウィンドウを前に出すときは、ウィンドウが別のデスクトップにあればそのデスクトップへ切り替える（そのままでは見えないため）。番号を指定しているときは、ウィンドウをそのデスクトップへ移し、今のデスクトップは切り替えない。セットの実行中は切り替えない。

種別ごとの説明は [アイテムの種別](./item-categories.md)、入力欄は [登録画面の画面仕様（ウィンドウ切り替え・ウィンドウ位置）](../screens/register-modal.md#55-ウィンドウ切り替えウィンドウ位置を入力)、データの形式は [ウィンドウ切り替え](../architecture/file-formats/data-format.md#315-ウィンドウ切り替えitemwindowswitch)、仕組みは [ウィンドウ制御 - 仮想デスクトップ移動機能](../architecture/window-control.md#仮想デスクトップ移動機能)。

## ワークスペース

ワークスペースウィンドウと、ワークスペースから切り離したグループのウィンドウは、既定ですべての仮想デスクトップに表示します。どちらも管理画面の設定で切り替えられます。

- 全デスクトップに表示しない設定で、ワークスペースを出したまま別のデスクトップへ移り、そこで表示を切り替える（または自動表示する）と、隠さずに今のデスクトップへ呼び寄せる
- 切り離したグループのウィンドウは、表示するたびに全デスクトップへの表示を当て直す（メインウィンドウと一緒に隠して出し直しても保つ）

詳細は [ワークスペース](./workspace.md#ウィンドウの表示の設定)、設定のキーと既定値は [設定ファイルの形式 - ワークスペース設定](../architecture/file-formats/settings-format.md#38-ワークスペース設定)。

## メインウィンドウ

メインウィンドウ（ランチャー）は、ピン留め（常に最前面・表示固定）で出したまま別のデスクトップへ移ってから起動のホットキー（ウィンドウ検索のホットキーも）を押すと、今のデスクトップへ呼び寄せて前に出します。

## できないこと

- メインウィンドウ（ランチャー）自体をすべてのデスクトップに固定する設定は無い
- 仮想デスクトップを作る・消す・名前を変える操作は無い（Windows の機能で行う）
