# ワークスペース機能

よく使うアイテムをワークスペースに追加して、画面の端に置く専用ウィンドウから素早く開く機能です。この文書は、ワークスペースの構成と、どこから何を追加すると何が起きるかを説明します。ボタンやメニューの操作は画面仕様（ワークスペースウィンドウ）を正とします。

## 概要

メイン画面のアイテムやファイル・URL・ウィンドウなどをワークスペースに追加し、グループに分けて整理します。ワークスペースウィンドウは画面の端（既定は右端）に縦長に表示し、メイン画面のヘッダーの ⭐ ボタンや `Ctrl+W`、⚙️ メニューで開く・閉じるを切り替えます（トレイメニューの「ワークスペースを表示」でも開く）。

### 主な特徴

- **参照とコピー**: メインウィンドウのアイテムは、既定で参照として追加する。参照はメインウィンドウのアイテムを指すだけで、メインウィンドウで直すとワークスペースにも反映する。ワークスペースでの表示名を付けられる。メインウィンドウと切り離したいときはコピーで追加する（[参照とコピー](#参照とコピー)）
- **複数のワークスペース**: タブで切り替える。前回表示していたワークスペースを次に開いたときも選ぶ
- **グループとサブグループ**: アイテムを色付きのグループに分け、グループの中にさらにグループを作れる
- **アーカイブ**: 当面使わないグループを、アイテムごと別の場所へ退避して後で戻せる
- **切り離し**: グループを独立したウィンドウとして切り離し、画面の好きな場所に置ける

## 構成

```
ワークスペース（タブ）
├── グループ（色・折りたたみ）
│   ├── サブグループ
│   │   ├── サブサブグループ
│   │   └── アイテム
│   └── アイテム
└── グループ …
アーカイブ（🗄️ タブ。アーカイブしたグループとアイテム）
```

- **ワークスペース**: 1 つ以上必要。最後の 1 つは削除できない。ワークスペースを削除すると、属するグループとアイテムもすべて削除する
- **グループ**: 入れ子は 2 階層まで（トップレベル → サブグループ → サブサブグループ）。グループを別のグループの中へ動かすときも、自分の子孫の中へは動かせず、深さの上限を超える動かし方もできない。既定の色は階層で変わる（トップレベルは青、サブグループは青緑、その下は灰色）。読み込んだファイルに深すぎる・循環するグループがあれば最上位へ移し、読み込みのトーストで件数を知らせる（[ワークスペースファイル形式](../architecture/file-formats/workspace-format.md#24-workspacegroup)）。色の一覧は [ワークスペースファイル形式](../architecture/file-formats/workspace-format.md#24-workspacegroup) を参照
- **アイテムは必ずグループに入る**: グループの外にアイテムを置く場所（以前の「未分類」の区画）は無い。読み込みのとき、グループに入っていないアイテム（古い版で書いたファイル・手編集など）は、ワークスペースごとに「未分類」という名前のグループ（作るときの表示言語の名前。ワークスペースの最後に作る）に入れ、読み込みレポートに「グループに入っていないアイテム {N} 件を、グループ「未分類」に入れました」と出す。このグループは普通のグループで、改名も削除もできる
- **グループの削除**: 子孫のサブグループと中のアイテムをまとめて削除する（アイテムを移す先は無い）。確認には赤字で「中に入っているものもすべて消えます。残したいときは、削除せずに「アーカイブ」を使ってください。」と出す
- **アイテムの削除**: 右クリックの「ワークスペースから削除」・カードの ×・編集画面の「ワークスペースから削除」のどれも、確認（「「{名前}」をワークスペースから削除しますか？」）を通してから消す
- **アーカイブ**: グループ単位で、子孫のサブグループとアイテムをまとめて移す。アーカイブ中のグループは閲覧・起動・復元・完全削除だけができ、名前や色は変えられない
- **ワークスペース間の移動**: アイテムとグループは別のワークスペースへ移せる。アーカイブ済みのグループは、移動先を選んで復元する

## アイテムの追加元と、作られるアイテム

| 追加元 | 操作 | 作られるアイテム |
| --- | --- | --- |
| メインウィンドウのアイテム | 右クリックの「⭐ ワークスペースに追加 ▸」、ワークスペースへドラッグ、ワークスペースの「➕ アイテムを追加」（グループの右クリック）→「🔍 メインウィンドウのアイテムから選ぶ…」 | 参照（[参照とコピー](#参照とコピー)）。フォルダ取込で展開したアイテムは参照できないので、コピーで足して「参照できないアイテムなので、コピーで追加しました」と知らせる |
| メインウィンドウのアイテム（コピーで） | 右クリックの「📄 ワークスペースにコピーを追加 ▸」、Ctrl を押しながらワークスペースへドロップ、「メインウィンドウのアイテムから選ぶ」の画面で「コピーで追加（メインウィンドウと切り離す）」をチェック | 同じ種類のアイテム（コピー）。ウィンドウ切り替え（対象ウィンドウ・ウィンドウ位置など）もコピーする。セットは行もそのままコピーし、起動するとメインウィンドウと同じく行ごとに開いて位置を合わせる。行が指すアイテムは、ワークスペースのアイテムを先に、データファイルのアイテムを後に探す。クリップボードアイテムは保存データも複製する（[メインウィンドウとの間でのクリップボードアイテム](#メインウィンドウとの間でのクリップボードアイテム)） |
| メイン画面のウィンドウ検索の結果 | 右クリック、ワークスペースへドラッグ | パスの無い単一アイテム（下記） |
| エクスプローラーのファイル・フォルダ、ブラウザの URL | ワークスペースへドラッグ | ファイル／フォルダ／アプリ／URL のアイテム |
| クリップボード | ワークスペースで `Ctrl+V` | 中身による（下記） |
| 新しく入力したもの | ワークスペースの「➕ アイテムを追加」（上と同じ入口）→「✏️ 新しく入力して追加…」 | 入力した種別のアイテム（単一アイテム・セット・クリップボード） |

足したアイテムは、どれもグループに入ります。入れる先は次のとおりです。

- 右クリックの「⭐ ワークスペースに追加 ▸」などは、サブメニューでその場でワークスペースとグループを選ぶ（ワークスペースが 1 つならワークスペースの段は省く。「➕ 新しいグループを作って入れる」も選べる）
- ドラッグはドロップしたグループに入る。グループの外に落としたときは足さずに「グループの上に落としてください（グループの外には置けません）」と知らせる
- `Ctrl+V` は、最後に見出しをクリックしたグループに入る。グループを選んでいないときは足さずに「貼り付ける先のグループの見出しをクリックしてから、貼り付けてください」と知らせる
- 「➕ アイテムを追加」は、右クリックしたグループに入る
- グループが 1 つも無いワークスペースへ足すときだけは、「未分類」という名前のグループを作って入れる（ドラッグ・貼り付けも同じ）

メインウィンドウのアイテム以外から足したもの（ウィンドウ検索の結果・ファイルや URL のドロップ・貼り付け・新しく入力したもの）は、どれもコピーになります。

### ウィンドウ検索の結果から追加したとき

- exe 名とタイトル全体を対象ウィンドウにした**パスの無い単一アイテム**（[アイテムの種別](./item-categories.md#単一アイテム)）になる。開くと、そのウィンドウが開いていれば切り替え、開いていなければ何も開かない。exe のパスは使わない（後でパスを入れれば、開いていないときに開ける）。ウィンドウそのもの（ハンドル）は覚えないので、閉じて開き直したウィンドウも見つかる
- 既定ではウィンドウ位置を記録しない（後でウィンドウを動かしたときに、勝手に元の場所へ戻るのを避けるため）。Ctrl を押しながらドロップするか、右クリックの「⭐ ウィンドウ位置ごとワークスペースに追加 ▸」で入れるグループを選ぶと、今の位置と大きさも記録し、前面に出すたびにその場所へ戻す
- ブラウザのように表示中の内容でタイトルが変わるウィンドウは、後で見つからないことがある。アイテムを編集して、タイトルにワイルドカード（例: `* - Google Chrome`）を使う
- 複数のウィンドウの配置をまとめて再現したいときは、セットを使う（[セット](./set.md)）

### クリップボードから追加したとき

| クリップボードの中身 | 作られるアイテム |
| --- | --- |
| エクスプローラーでコピーしたファイル・フォルダ | ファイル／フォルダ／アプリのアイテム（アイコン付き） |
| URL（`http://`、`https://`、`ftp://`） | URL アイテム（ファビコンを自動取得） |
| カスタム URI（`obsidian://`、`ms-todo:`、`vscode://` 等） | カスタム URI アイテム |
| Windows のパス（`C:\...`、`\\server\...`、`shell:...`、`%APPDATA%\...`） | ファイル／フォルダ／アプリのアイテム。「パスのコピー」の引用符は外す |
| それ以外のテキスト（複数行を含む） | クリップボードアイテム（全文を保存。起動するとクリップボードに戻す） |
| 画像（スクリーンショット等） | クリップボードアイテム（画像を保存。起動するとクリップボードに戻す） |

- 入力欄の中でのペーストは、通常の文字入力として扱う
- パスは実在を確かめずに追加する（ネットワークパスの応答待ちを避けるため）。見つからないパスは、アイテム管理画面の「リンク切れの確認」で分かる
- 「TODO: 買い物」のように空白を含む文は、URI ではなくテキストとして扱う

## 参照とコピー

ワークスペースのアイテムには、メインウィンドウのアイテムを指す**参照**と、中身を自分で持つ**コピー**があります。ファイルの書き方は [ワークスペースファイル形式 2.6](../architecture/file-formats/workspace-format.md#26-参照アイテムtype-ref) を参照してください。

| | 参照 | コピー |
| --- | --- | --- |
| 中身（パス・引数・ウィンドウ切り替え・アイコン・メモなど） | メインウィンドウのアイテムのものを使う | 自分で持つ |
| メインウィンドウでアイテムを直したとき | ワークスペースにも反映する | 変わらない |
| 表示名 | ワークスペースでの表示名。無ければメインウィンドウのアイテムの表示名 | 自分の表示名 |
| できるとき | メインウィンドウのアイテムを追加したとき（既定） | コピーで追加したとき、メインウィンドウのアイテム以外から足したとき |

### 参照できるアイテム

- 参照できるのは、id を持つメインウィンドウのアイテム（通常アイテム・パスの無い単一アイテム・クリップボードアイテム・セット）
- フォルダ取込で展開したアイテム・ウィンドウ検索の結果は参照できない。参照で足そうとすると、コピーで足す
- メインウィンドウの右クリックの「📄 ワークスペースにコピーを追加」は、参照できるアイテムにだけ出る

### 参照の動き

- **表示**: データファイルを読み直すたびに、参照を指す先のアイテムの今の中身で表示し直す。id・グループ・並び順・追加日時はワークスペースのもの、メモはメインウィンドウのもの。カードに印は付けず、ツールチップの先頭に指す先のアイテムの表示名とタブを出す
- **起動**: 指す先のアイテムの今の中身で開く。開いた記録（アイテム管理の最終起動・起動回数）は、メインウィンドウのアイテムの id で残す（コピーはパスで残す）
- **表示名**: その場で名前を変えると、ワークスペースでの表示名になる（メインウィンドウのアイテムの表示名は変わらない）。空にして確定するか、メインウィンドウの表示名と同じ名前にすると、ワークスペースでの表示名を消し、以後はメインウィンドウの表示名に追随する
- **絞り込み**: ワークスペースでの表示名と、メインウィンドウの表示名の両方で当たる
- **編集**: 中身はワークスペースでは直さない。右クリックの「✏️ 編集（メインウィンドウのアイテム）」で、メインウィンドウの編集画面を開いて直す。編集画面は、ワークスペースから参照されているアイテムなら、ワークスペースの何か所に反映されるかを見出しの下に出す
- **セット**: 参照のセットを開くと、メインウィンドウのセットを開く。ワークスペースのセットの行に入れるアイテムを選ぶとき、参照は候補に出さない（指す先のメインウィンドウのアイテムが候補にあるため）
- **クリップボードアイテム**: 参照は、メインウィンドウのアイテムの保存データをそのまま使う（複製しない）
- **アーカイブ**: アーカイブ・復元しても参照のまま
- **見た目**: カードの右下の角に小さな灰色の矢印（ショートカットの印）を出す。マウスを載せると削除の × と入れ替わりに消える。どのアイテムを指しているかはツールチップの先頭行に出る
- **メインウィンドウへ移す**: 参照はもうメインウィンドウにあるので、移さない（右クリックに「🚀 メインウィンドウへ移して参照にする」を出さず、メインウィンドウへドラッグしても知らせるだけ。[メインウィンドウへ移す](#メインウィンドウへ移す)）

### 元のアイテムが見つからない参照

メインウィンドウのアイテムを削除したり、データファイルを外で書き換えて id が変わったりすると、参照は指す先を失います。参照そのものは消さずに残します。

- カードを点線の枠・薄い黄色の背景で薄く出し、アイコンは ❔（右下の矢印は出さない）。表示名は、ワークスペースでの表示名、無ければ最後に見たメインウィンドウの表示名
- クリックしても開かず、トーストで「「{名前}」は開けません。元のアイテムが見つかりません」と知らせる。指す先がフォルダ取込のときは、理由が「フォルダ取込は参照できません」になる
- 右クリックで、別のアイテムを指し直すか、ワークスペースから削除する
- メインウィンドウでアイテムを削除するとき（編集画面の削除・アイテム管理の削除・アイテム管理でデータファイルを消すとき）、ワークスペースから参照されていれば、削除の確認に参照の件数と、参照が「元のアイテムが見つかりません」になることを添える
- アイテム管理の「重複を削除」で消したアイテムを指す参照は、保存したときに、残したアイテムを指すように付け替える（保存せずに戻したときは付け替えない）

### 参照とコピーを行き来する

| 変え方 | 操作 | 変わること |
| --- | --- | --- |
| 参照 → コピー | 右クリックの「📄 コピーにする（メインウィンドウと切り離す）」 | メインウィンドウのアイテムの今の中身をワークスペースに書く（ショートカットはリンク先を読んだ形）。表示名はワークスペースでの表示名があればそれ、メモはメインウィンドウのものを写す。クリップボードアイテムは保存データを複製する |
| コピー → 参照 | 右クリックの「🚀 メインウィンドウへ移して参照にする」（[メインウィンドウへ移す](#メインウィンドウへ移す)。移す先に同じアイテムがあればそれを指す）。ワークスペースのタブの右クリックの「🔗 メインウィンドウと同じアイテムを参照に変える…」で、パスと引数が同じメインウィンドウのアイテムがあるコピーをまとめて変える（候補が 2 件以上なら、行ごとに指す先を選ぶ） | id・グループ・並び順・追加日時は保つ。表示名がメインウィンドウの表示名と違えば、ワークスペースでの表示名にする。コピーのメモは、メインウィンドウのアイテムにメモが無ければメインウィンドウへ移す（両方にあれば、コピーのメモは消える） |
| 参照の指し直し | 右クリックの「🔁 別のアイテムを指す…」 | 指す先だけを変える。ワークスペースでの表示名は引き継ぐ |

QuickDashLauncher CLI では `workspace item convert` で行き来する（[CLI](./cli.md)）。

### 参照の限界

- 参照はメインウィンドウのアイテムの id で指す。データファイルを外で書き換えて id が重複したり形式が崩れたりすると、後から読んだ側の id が振り直され、参照が別のアイテムを指すか、見つからなくなる
- ブックマーク自動取込のアイテムは、URL が同じ間だけ id が保たれる。URL が変わると、元のアイテムが見つからない参照になる
- 同じタブの中で重複していて一覧に出ないアイテムは、見つからない扱いになる

## メインウィンドウへ移す

「ワークスペースに追加」の逆向きで、ワークスペースのアイテム（コピー）をメインウィンドウのアイテム（データファイル）へ移し、ワークスペース側をその参照に変えます。登録画面は開きません。

- **操作**: アイテムの右クリックメニューの「🚀 メインウィンドウへ移して参照にする」から、移す先のタブを選ぶ。データファイルが 2 つ以上あるタブは、その下に並ぶデータファイルから選ぶ。アイテムをメインウィンドウへドラッグ&ドロップしたときは、メインウィンドウで今選んでいるタブの先頭のデータファイルへ移す。コピーのすべての種別（通常アイテム・セット・クリップボード）でできる
- **移したあと**: 移す先のデータファイルの末尾に、同じ中身（表示名・パス・引数・ウィンドウ切り替え・メモなど）のアイテムを新しい id で足す。ワークスペースのアイテムは、id・グループ・並び順を保ったままそのアイテムの参照になる（[参照とコピーを行き来する](#参照とコピーを行き来する)の「コピー → 参照」と同じ）。ワークスペースのセットの行がこのアイテムを指していれば、メインウィンドウのアイテムを指すように付け替える。終わるとトーストで「「{名前}」をメインウィンドウの「{タブ}」タブへ移し、ワークスペースのアイテムは参照にしました」と知らせる
- **同じアイテムがあるとき**: 通常アイテムで、移す先のデータファイルにパスと引数（大文字・小文字と末尾の区切り文字は区別しない）が同じアイテムが既にあれば、新しく作らずにそのアイテムを指す参照にする（メインウィンドウとワークスペースの両方に登録していたアイテムを移しても、重複を作らない）。トーストは「メインウィンドウの「{タブ}」タブに同じアイテムがあったので、「{名前}」はそれを指す参照にしました」。ほかのデータファイルにあるだけのときと、ウィンドウ切り替え・カスタムアイコン・常に管理者として実行が違うとき（参照にするとコピーの設定が消えるため）は、選んだ先に新しく足す
- **参照**: もうメインウィンドウにあるので移さない。右クリックに項目を出さず、ドラッグすると「「{名前}」はメインウィンドウのアイテムを参照しています（もうメインウィンドウにあります）」と知らせる。元のアイテムが見つからない参照をドラッグしたときは「「{名前}」は元のアイテムが見つからないので、メインウィンドウへ移せません」と知らせる
- **セットの行**: メインウィンドウのセットは、行が指すアイテムをデータファイルからしか探さない。そこで、ワークスペースのアイテムを指す行は、そのアイテムのパス・引数を書いた行（パスの無い単一アイテムなら動かすだけの行）に置き換えて移す。行に対象ウィンドウもウィンドウ位置も無ければ、アイテムのウィンドウ切り替えも行に写す。ワークスペースの参照を指す行は、参照が指すメインウィンドウのアイテムの id の行にする。データファイルのアイテムを指す行は、id で指したまま写す。ワークスペースで開くときと同じく、同じ id のアイテムが両方にあればワークスペースのアイテムとして扱う
- **CLI**: `qdl workspace item move-to-main <id か表示名>`（`--file`・`--tab` で移す先。[CLI](./cli.md)）
- **対象**: 1 つのアイテム単位。グループごと移すことや、メインウィンドウのタブの上にドロップして移す先を選ぶことはできない

## メインウィンドウとの間でのクリップボードアイテム

クリップボードアイテムの中身（保存データ）は、アイテムとは別のファイルに保存されています（[データファイル形式 3.5.3](../architecture/file-formats/data-format.md#353-データファイル)）。メインウィンドウからワークスペースへクリップボードアイテムをコピーとして写すときは、このファイルを複製し、写した先のアイテムは複製を指します。参照は、メインウィンドウのアイテムの保存データをそのまま使います（複製しない）。

- **メインウィンドウ → ワークスペース**（コピーで追加したとき・参照をコピーにしたとき）: そのときに複製する
- **ワークスペース → メインウィンドウ**（[メインウィンドウへ移す](#メインウィンドウへ移す)）: 複製しない。保存データはメインウィンドウへ移したアイテムが引き継ぎ、ワークスペース側は参照になってファイルを持たなくなる
- 元のファイルが無くて複製できないときは、元と同じファイルを指したまま写す

1 つのファイルを共有すると、メインウィンドウのアイテムを消したときにファイルも消え、コピー側が復元できなくなるためです（以前はファイルを共有していた）。

## 切り離しウィンドウ

グループをワークスペースウィンドウの外へドラッグするか、グループを右クリックして「別のウィンドウに切り離す」を選ぶと、そのグループ（子孫のサブグループとアイテムを含む）だけを表示する独立したウィンドウになります。切り離せるのは一番上のグループだけです（サブグループは切り離せない）。

- 同じデータを表示するだけで、グループはワークスペースウィンドウにも残る。どちらで変更しても両方に反映する
- 📌 なしのものはメインウィンドウと一緒に出て一緒に隠れ、📌 ありのものは隠れずに残る（下の「メインウィンドウとの連動」）。⚙️ メニューでまとめて隠すこともできる
- 位置・📌・折りたたみを覚えていて、アプリを終了したときに開いていたものは、次に起動したときに開き直す（📌 ありはすぐに出て、なしは最初のホットキーでメインと一緒に出る）。× で閉じたもの（右クリックの「ワークスペースに戻す」も同じ）は忘れる
- 表示位置が「メインウィンドウと同じディスプレイ」（既定）なら、メインウィンドウと一緒に出すたびに、メインと同じディスプレイの同じ位置へ移る。ディスプレイの端にくっつけたものは端に、それ以外はディスプレイの中央からの距離を保つ（ピン留めしたものは動かさない。[ウィンドウ制御](../architecture/window-control.md#切り離しウィンドウの表示位置)）

## メインウィンドウとの連動

ワークスペースと切り離しウィンドウは、同じ決まりでメインウィンドウと一緒に出たり隠れたりします。

| 📌 | 動き |
| --- | --- |
| なし | メインウィンドウと一緒に出て、一緒に隠れる |
| あり（表示固定・常に最前面） | 隠れずに残る。ホットキーでメインウィンドウを出すと、ほかのウィンドウの下にあっても手前に出る |

- **閉じる**: × で閉じる（📌 に関係なく閉じる）。ワークスペースは ⭐・`Ctrl+W` でも閉じる。閉じたものはメインウィンドウと一緒に出てこない。一度も開いていないワークスペースも出てこない
- **ワークスペースの 📌**: 最初から表示固定。開けば開きっぱなしで使える。閉じても 📌 の状態は覚えている
- **切り離しウィンドウの 📌**: 最初はなし。× で閉じると位置・📌・折りたたみを忘れる
- **再起動**: 直前と同じ状態に戻す。閉じていないワークスペース・切り離しウィンドウのうち、📌 ありのものは起動した直後から出ていて、なしのものは最初のホットキーでメインと一緒に出る（`restoreWindowsOnStartup()`）
- 📌 のクリックで表示固定のオン・オフ、右クリックで常に最前面を選ぶ（メインウィンドウの 📌 も同じ）

## 絞り込み

ワークスペースウィンドウでは、グループ名・アイテム名の一部で表示を絞り込めます（大文字小文字を区別しない）。参照は、ワークスペースでの表示名とメインウィンドウの表示名の両方で当たります。グループ名が一致したグループは、子孫のサブグループとアイテムも表示します。切り離しウィンドウでは使えません。

## 保存

- ワークスペース・グループ・アイテムは `workspace.json`、アーカイブは `workspace-archive.json`、折りたたみと切り離しウィンドウの位置は `workspace-ui-state.json` に保存する。追加・編集・削除・並べ替えのたびにすぐ保存する
- 形式と置き場所、読み込み・書き込みの仕組み（外部変更の検知・壊れていたときの扱い）は [ワークスペースファイル形式](../architecture/file-formats/workspace-format.md) を参照
- バックアップが有効なら、データファイルと同じく日次のスナップショットと外部変更前のスナップショットの対象になる。消えたデータは管理画面のスナップショット一覧から戻す

## ウィンドウの表示の設定

表示位置（ディスプレイの左端・右端・固定位置。端に置くディスプレイは既定で「メインウィンドウと同じディスプレイ」）、不透明度、背景だけの透過、全仮想デスクトップへの表示は、管理画面の設定で変えます。メインウィンドウと一緒に出る・隠れるは 📌 で決めます（下の「メインウィンドウとの連動」）。項目と既定値は [設定ファイルの形式 - ワークスペース設定](../architecture/file-formats/settings-format.md#38-ワークスペース設定) を参照してください。

全仮想デスクトップに表示しない設定で、ワークスペースウィンドウを出したまま別のデスクトップへ移り、そこで表示を切り替える（または自動表示する）と、隠さずに今のデスクトップへ呼び寄せます。切り離しウィンドウは、表示するたびに全仮想デスクトップへの表示の設定を当て直すので、メインウィンドウと一緒に隠れて出し直しても設定どおりに表示します。
