# ワークスペース機能

よく使うアイテムをワークスペースに追加して、画面右端の専用ウィンドウで素早くアクセスできる機能です。

## 概要

ワークスペース機能を使うと、メイン画面のアイテムをワークスペースに追加し、グループ化して整理できます。ワークスペースウィンドウは画面右端に固定表示され、ホットキーで素早く表示/非表示を切り替えられます。

### 主な特徴

- **専用ウィンドウ**: 画面右端に固定配置される縦長UI（幅380px）
- **ショートカット対応**: ランチャーウィンドウ内で`Ctrl+W`で表示/非表示を切り替え
- **グループ管理**: アイテムをグループに分類して整理
- **名前変更**: ワークスペース内で独自の名前を設定可能
- **ドラッグ&ドロップ**: アイテムの並び替えやグループ間移動が可能
- **独立管理**: 元のアイテムが変更・削除されても影響を受けない

## 基本的な使い方

### ワークスペースウィンドウの表示

ワークスペースウィンドウを表示するには以下の方法があります：

- **ショートカット**: ランチャーウィンドウ内で`Ctrl+W`を押す
- **設定メニュー**: 設定メニュー（⚙ボタン）から「ワークスペースを表示」を選択

### アイテムの追加

ワークスペースにアイテムを追加するには以下の方法があります：

#### メイン画面から追加

1. メイン画面でアイテムを右クリック
2. 「ワークスペースに追加」を選択
3. ワークスペースウィンドウに自動的に追加されます

**ウィンドウ設定の引き継ぎ（v0.5.5以降）:**

- アイテムにウィンドウ設定（ウィンドウタイトル、位置・サイズ）が設定されている場合、ワークスペースへの追加時にその設定も自動的にコピーされます
- ワークスペースからアイテムを起動する際、既存ウィンドウの検索・アクティブ化が正しく機能します

#### ドラッグ&ドロップで追加

1. エクスプローラーからファイル・フォルダをワークスペースウィンドウにドラッグ
2. ブラウザからURLをワークスペースウィンドウにドラッグ
3. ドロップした場所（グループまたは未分類セクション）に追加されます

#### クリップボードからペースト（Ctrl+V）（v0.5.1以降）

クリップボードの内容をワークスペースに素早く追加できます：

1. **URL・ファイルパス・カスタムURIをコピー**: テキストとしてコピーしたURL、ファイルパス、カスタムURI（`obsidian://`、`vscode://`等）を`Ctrl+V`でペースト
2. **ファイルをコピー**: エクスプローラーでファイル/フォルダを選択して`Ctrl+C`でコピー後、ワークスペースウィンドウで`Ctrl+V`でペースト
3. **自動判定**: ペーストされた内容から自動的にアイテムタイプ（URL、アプリ、ファイル、フォルダ等）を判定
4. **ファビコン自動取得**: URLの場合、ファビコンを自動取得

**対応形式:**

- URL（`http://`、`https://`）
- カスタムURIスキーマ（`obsidian://`、`ms-excel://`、`vscode://`等）
- ファイルパス（絶対パス・相対パス）
- ファイルオブジェクト（エクスプローラーからコピー）

**注意:**

- Input/Textarea要素内でのペーストは通常のテキスト入力として処理されます
- テキストペーストの場合、最初の行のみが使用されます

#### グループアイテムの追加（v0.5.19以降）

メイン画面のグループアイテムもワークスペースに追加できるようになりました：

1. メイン画面でグループアイテムを右クリック
2. 「ワークスペースに追加」を選択
3. グループアイテムとして追加されます
4. ワークスペースから起動すると、含まれるアイテムが順次実行されます

**グループアイテムの特徴:**

- グループアイテムはアイテム名のリスト（`itemNames`）を保持します

### アイテムの起動

ワークスペース内のアイテムをクリックすると起動します。

### アイテム名の変更

ワークスペース内でアイテム名を変更できます（元のアイテム名は保持されます）：

1. **ダブルクリック**: アイテムをダブルクリックして編集モードに入る
2. **コンテキストメニュー**: 右クリック → 「✏️ 表示名を変更」

### アイテムの削除

- **削除ボタン**: アイテムの右上の「×」ボタンをクリック
- **コンテキストメニュー**: 右クリック → 「🗑️ ワークスペースから削除」

## 複数ワークスペース（タブ）

ワークスペースは複数作成でき、ウィンドウ上部のタブバーで切り替えられます。

### タブの切り替え

タブバーのタブをクリックすると、そのワークスペースのグループ・アイテムに切り替わります。

### ワークスペースの作成

タブバー右端の「+」ボタンをクリックすると、「ワークスペース N」という名前で新しいワークスペースが作成されます。

### ワークスペースの名前変更

- **ダブルクリック**: タブをダブルクリックして編集モードに入る
- **コンテキストメニュー**: タブを右クリック → 「名前を変更」

### ワークスペースの削除

タブを右クリック →「削除」で削除できます。

- **最後の1つは削除不可**: ワークスペースが1つしかない場合、削除メニューは表示されません
- **所属データも削除**: 削除すると、そのワークスペースに属するグループ・アイテムも全て削除されます（確認ダイアログあり）

### ワークスペースの並べ替え

タブをドラッグ&ドロップして順序を変更できます。

### アクティブなワークスペースの記憶

現在表示中のワークスペースは`localStorage`の`activeWorkspaceId`に保存され、次回開いたときも復元されます。保存されたIDのワークスペースが存在しない場合（削除された場合など）は、先頭のワークスペースにフォールバックします。

### アイテム・グループのワークスペース間移動

アイテムまたはグループを右クリック →「📁 ワークスペースを移動」サブメニューから移動先のワークスペースを選択できます（他にワークスペースが存在するときだけメニューに表示されます）。アーカイブ済みのアイテムに対しても使用でき、その場合は復元しつつ指定したワークスペースに入ります（アーカイブ済みのグループでは「📤 ワークスペースへ復元」という名前で表示されます）。

## グループ機能

### グループの作成

1. 「+ グループを追加」ボタンをクリック
2. グループが作成され、名前の編集モードになります
3. グループ名を入力してEnterキーを押すか、外側をクリックして確定

### グループ名の編集

- **右クリック →「✏️ グループ名を変更」**: コンテキストメニューから編集モードに入る

### グループの色設定

グループヘッダーを右クリック →「🎨 カラーを変更」で、以下の12色から選択できます：

- プライマリ（デフォルト）
- サクセス
- ダンジャー
- ワーニング
- インフォ
- セカンダリ
- パープル
- ティール
- ピンク
- インディゴ
- オレンジ
- シアン

### グループの折りたたみ

グループヘッダーの「▼」または「▶」ボタンをクリックして、グループを折りたたみ/展開できます。

### グループのアーカイブ

グループヘッダーを右クリック →「📦 グループをアーカイブ」で、グループとその中のアイテムをアーカイブできます（子孫サブグループも含む）：

- グループとアイテムはアーカイブに移動
- ワークスペースからは削除され、ワークスペースウィンドウのタブバー「📦」タブで確認可能
- アーカイブされたグループは後で復元できます

### グループの削除

グループヘッダーを右クリック →「🗑️ グループを削除」でグループを削除できます（子孫サブグループも連鎖的に削除されます）。
グループ内のアイテムは未分類セクションに移動します。

### グループの並び替え

グループヘッダー（名前部分以外）をドラッグ&ドロップして、グループの順序を変更できます。

## サブグループ

グループの中に、さらにグループ（サブグループ）を作ることができます。

### 階層の深さ

サブグループは最大2階層まで作成できます（トップレベル → サブグループ → サブサブグループ、`MAX_GROUP_DEPTH = 2`）。

### サブグループの追加

グループヘッダーを右クリック →「📂 サブグループを追加」を選択します。深さの上限（2階層）に達しているグループでは、このメニュー項目自体が表示されません。

### 親グループの変更

グループヘッダーをドラッグ&ドロップして別のグループの中に移動できます。以下の移動はできません：

- 自分自身の子孫グループへの移動（循環参照になるため）
- 移動先で深さの上限（2階層）を超えてしまう移動

### サブグループの削除

グループを削除すると、その子孫サブグループも連鎖的に削除されます。削除時のアイテムの扱い（未分類に移動するか完全に削除するか）は、通常のグループ削除と同じです。

### サブグループのアーカイブ・復元

サブグループを含むグループをアーカイブすると、子孫サブグループとその中のアイテムもまとめてアーカイブされます。復元時も同様に、子孫サブグループごと一括で復元されます。

## アイテムの整理

### グループ間の移動

アイテムをドラッグして別のグループにドロップすることで、所属グループを変更できます。

### 同じグループ内の並び替え

同じグループ内でアイテムをドラッグ&ドロップして、順序を変更できます。

### 未分類アイテム

グループに所属していないアイテムは「未分類」セクションに表示されます。

## アイテムのフィルタリング（v0.6.0以降）

ワークスペース内のアイテムをタイプ別にフィルタリングできます：

### フィルタの種類

ワークスペースヘッダーのドロップダウンで以下のフィルタを選択できます：

| フィルタ        | 表示されるアイテム                                      |
| --------------- | ------------------------------------------------------- |
| **すべて**      | すべてのアイテムを表示（デフォルト）                    |
| **URL**         | URL（http://, https://）アイテムのみ表示                |
| **アプリ**      | アプリケーション（.exe）のみ表示                        |
| **ファイル**    | ファイルアイテムのみ表示                                |
| **フォルダ**    | フォルダアイテムのみ表示                                |
| **カスタムURI** | カスタムURIスキーマ（obsidian://, vscode://等）のみ表示 |

### 使い方

1. ワークスペースヘッダーのフィルタドロップダウンをクリック
2. 表示したいアイテムタイプを選択
3. 該当するアイテムのみが表示されます

**注意:**

- フィルタはグループ化されたアイテムと未分類アイテムの両方に適用されます
- フィルタ条件に一致するアイテムがないグループは空として表示されます

## ツールチップ

### ワークスペースアイテム

アイテムにマウスオーバーすると以下の情報を表示：

- パス（種別に応じて「ウィンドウ操作: タイトル」「グループ: N件」「クリップボード: プレビュー」「レイアウト: N件」等の説明）
- リンク先（ショートカットの場合）
- 引数（設定されている場合）
- メモ（設定されている場合）
- 追加日時

## アーカイブ機能

一時的に使わないグループとアイテムをアーカイブして整理できます。

### アーカイブの方法

**グループ単位でアーカイブ:**

1. ワークスペースウィンドウでグループヘッダーを右クリック →「📦 グループをアーカイブ」を選択
2. グループとその中のすべてのアイテム（子孫サブグループを含む）がアーカイブに移動

### アーカイブの確認

ワークスペースウィンドウのタブバーにある「📦」タブをクリックすると、アーカイブ一覧を表示できます：

- アーカイブされたグループをカード形式で一覧表示
- 各カードにグループ名、色、アーカイブ日時、アイテム数を表示

### グループの復元

アーカイブタブから復元できます：

1. ワークスペースウィンドウで「📦」タブをクリック
2. アーカイブされたグループを右クリック →「📤 ワークスペースへ復元」から復元先のワークスペースを選択
3. グループとアイテム（子孫サブグループを含む）がワークスペースに復元される
4. 復元時に同名のグループが存在する場合、グループ名に「(復元)」が付加される

### アーカイブからの削除

アーカイブタブから完全削除できます：

1. ワークスペースウィンドウで「📦」タブをクリック
2. アーカイブされたグループを右クリック →「🗑️ アーカイブから削除」
3. 確認ダイアログで削除を確定（元に戻せないため、空のグループでも必ず確認が出る）
4. グループとアイテム（子孫サブグループを含む）がアーカイブから完全に削除される

アーカイブ済みグループの右クリックメニューは「📋 テキストでコピー」「📤 ワークスペースへ復元」「🗑️ アーカイブから削除」の 3 つだけです（名前や色の変更、サブグループの追加はできません）。

## データ保存

ワークスペースのデータは以下のファイルに保存されます：

| ファイル                    | 内容                                                        | 形式                            |
| --------------------------- | ----------------------------------------------------------- | ------------------------------- |
| **workspace.json**          | ワークスペース（タブ）・グループ・アイテム                  | JSON（`WorkspaceFileStore`）    |
| **workspace-archive.json**  | アーカイブされたグループとアイテム                          | JSON（`WorkspaceFileStore`）    |
| **workspace-ui-state.json** | グループの折りたたみ状態・切り離しウィンドウの位置/ピン留め | JSON（`WorkspaceUiStateStore`） |

### 保存場所

```
%APPDATA%/quick-dash-launcher/config/
├── workspace.json
├── workspace-archive.json
└── workspace-ui-state.json
```

### データ形式

詳細なデータ形式は[ワークスペースファイル形式](../architecture/file-formats/workspace-format.md)を参照してください。

## ウィンドウのカスタマイズ

### 表示位置カスタマイズ

ワークスペースウィンドウの表示位置を2つのモードから選択できます（設定画面で変更可能）：

#### ディスプレイ端配置（デフォルト）

- 任意のディスプレイを選択して左端または右端に配置可能
- デフォルトはプライマリディスプレイの右端
- マルチディスプレイ環境でも任意のモニターを選択可能
- 設定項目：
  - **配置位置**: 左端 / 右端（デフォルト: 右端）
  - **ディスプレイ**: ディスプレイ一覧から選択（デフォルト: プライマリ）

#### 固定位置（手動設定）

- ワークスペースを移動した位置を記憶
- 次回起動時も同じ位置に表示
- マルチディスプレイ環境でモニター構成が変更された場合、自動的にプライマリモニターの右端にフォールバック
- フォールバック後も手動で移動すれば、その位置が記憶される

#### 自動表示機能

- 「メイン画面表示時にワークスペースを自動表示」チェックボックスを有効にすると、メイン画面を開いたときにワークスペースが非表示なら自動で表示されます

詳細は管理画面（`Ctrl+E`）の設定タブから「ワークスペースウィンドウ」カテゴリで変更できます。

### 透過機能

ワークスペースウィンドウの透過度を調整できます（設定画面で変更可能）：

- **透過度スライダー**: 0-100%で調整（デフォルト: 100%）
- **背景のみ透過モード**: ウィンドウ背景のみを透過し、アイテムやボタンは不透明のまま表示
- **即座反映**: 設定変更は即座にワークスペースウィンドウに反映されます

詳細は管理画面（`Ctrl+E`）の設定タブから「ワークスペースウィンドウ」カテゴリで変更できます。

### サイズ変更

ワークスペースウィンドウはカスタムサイズ変更ハンドルで自由にリサイズできます：

- **8方向のハンドル**: 4隅（左上、右上、右下、左下）+ 4辺（上、右、下、左）
- **最小サイズ**: 幅300px × 高さ400px
- **ドラッグ操作**: ハンドルをドラッグしてウィンドウをリサイズ

### ウィンドウ制御

- **ピン留め**: ヘッダーの📌ボタンで常に最前面表示の切り替え
- **閉じる**: ヘッダーの×ボタンでウィンドウを非表示（`Ctrl+W`でランチャーウィンドウから再表示可能）

## キーボードショートカット

| キー     | 動作                                                                          |
| -------- | ----------------------------------------------------------------------------- |
| `Ctrl+W` | ワークスペースウィンドウの表示/非表示切り替え（ランチャーウィンドウ内で有効） |
| `Ctrl+V` | クリップボードからアイテムを追加（URL、ファイルパス、ファイルオブジェクト）   |
| `Enter`  | 編集モードで名前を確定                                                        |
| `Escape` | 編集モードをキャンセル                                                        |

## 技術仕様

### ウィンドウ仕様

- **初期サイズ**: 幅380px × 高さ（画面の高さに合わせて自動調整）
- **サイズ変更**: 8方向のカスタムハンドルで自由にリサイズ可能（最小: 300x400px）
- **位置**: 画面右端に固定（初期配置）
- **表示**: デフォルトは通常ウィンドウ、ピン留めボタンで最前面表示（AlwaysOnTop）に切り替え可能
- **フレーム**: フレームレス（カスタムヘッダー、ドラッグ移動・リサイズ対応）
- **透過度**: 0-100%で調整可能（デフォルト: 100%）
- **背景のみ透過**: ウィンドウ背景のみを透過するモード（オプション）

### データ永続化

- **ストレージ**: 自前のJSONストア（`WorkspaceFileStore`）。データファイルと同じ寛容パース・外部変更検知・楽観ロックの仕組みを使う
- **保存タイミング**: アイテム追加・編集・削除・並び替え時に即座に保存
- **バックアップ**: `backupEnabled`が有効なら、他の設定ファイルと同様にバックアップ対象・外部変更時の変更前スナップショット（`config/backup/`）の対象に含まれる

### パフォーマンス

- **最大アイテム数**: 制限なし（推奨: 50アイテム程度）
- **最大グループ数**: 制限なし（推奨: 10グループ程度）

## トラブルシューティング

### ワークスペースウィンドウが表示されない

- ランチャーウィンドウで`Ctrl+W`を押して表示を試みる
- システムトレイから「ワークスペースを表示」を選択

### アイテムが起動しない

- アイテムのパスが正しいか確認
- 元のアイテム（ファイル・アプリ）が削除されていないか確認

### データが消えた

- `%APPDATA%/quick-dash-launcher/config/workspace.json`が存在するか確認
- バックアップから復元する場合は、workspace.jsonをconfig/フォルダにコピー
