# ワークスペース機能

よく使うアイテムをワークスペースに追加して、画面の端に置く専用ウィンドウから素早く開く機能です。この文書は、ワークスペースの構成と、どこから何を追加すると何が起きるかを説明します。ボタンやメニューの操作は画面仕様（ワークスペースウィンドウ）を正とします。

## 概要

メイン画面のアイテムやファイル・URL・ウィンドウなどをワークスペースに追加し、グループに分けて整理します。ワークスペースウィンドウは画面の端（既定は右端）に縦長に表示し、メイン画面の `Ctrl+W` や ⚙️ メニューで表示/非表示を切り替えます。

### 主な特徴

- **独立したコピー**: 追加したアイテムはメイン画面のアイテムのコピーで、元のアイテムを変更・削除しても影響を受けない。ワークスペース内で独自の名前を付けられる
- **複数のワークスペース**: タブで切り替える。前回表示していたワークスペースを次に開いたときも選ぶ
- **グループとサブグループ**: アイテムを色付きのグループに分け、グループの中にさらにグループを作れる
- **アーカイブ**: 当面使わないグループを、アイテムごと別の場所へ退避して後で戻せる
- **切り離し**: グループを独立したウィンドウとして切り離し、画面の好きな場所に置ける

## 構成

```
ワークスペース（タブ）
├── グループ（色・折りたたみ）
│   ├── サブグループ
│   │   ├── サブサブグループ
│   │   └── アイテム
│   └── アイテム
└── 未分類（どのグループにも属さないアイテム）
アーカイブ（🗄️ タブ。アーカイブしたグループとアイテム）
```

- **ワークスペース**: 1 つ以上必要。最後の 1 つは削除できない。ワークスペースを削除すると、属するグループとアイテムもすべて削除する
- **グループ**: 入れ子は 2 階層まで（トップレベル → サブグループ → サブサブグループ）。グループを別のグループの中へ動かすときも、自分の子孫の中へは動かせず、深さの上限を超える動かし方もできない。既定の色は階層で変わる（トップレベルは青、サブグループは青緑、その下は灰色）。読み込んだファイルに深すぎる・循環するグループがあれば最上位へ移し、読み込みのトーストで件数を知らせる（[ワークスペースファイル形式](../architecture/file-formats/workspace-format.md#24-workspacegroup)）。色の一覧は [ワークスペースファイル形式](../architecture/file-formats/workspace-format.md#24-workspacegroup) を参照
- **グループの削除**: 子孫のサブグループもまとめて削除する。中のアイテムは、確認画面の選択に応じて未分類へ移すか一緒に削除する
- **アイテムの削除**: 右クリックの「ワークスペースから削除」・カードの ×・編集画面の「ワークスペースから削除」のどれも、確認（「「{名前}」をワークスペースから削除しますか？」）を通してから消す
- **アーカイブ**: グループ単位で、子孫のサブグループとアイテムをまとめて移す。アーカイブ中のグループは閲覧・起動・復元・完全削除だけができ、名前や色は変えられない
- **ワークスペース間の移動**: アイテムとグループは別のワークスペースへ移せる。アーカイブ済みのグループは、移動先を選んで復元する

## アイテムの追加元と、作られるアイテム

| 追加元 | 操作 | 作られるアイテム |
| --- | --- | --- |
| メイン画面のアイテム | 右クリックの「⭐ ワークスペースに追加」、ワークスペースへドラッグ | 同じ種類のアイテム。ウィンドウ切り替え（対象ウィンドウ・ウィンドウ位置など）もコピーする。セットは行もそのままコピーし、起動するとメイン画面と同じく行ごとに開いて位置を合わせる。行が指すアイテムは、ワークスペースのアイテムを先に、データファイルのアイテムを後に探す。クリップボードアイテムは保存データも複製する（[メインウィンドウとの間でのクリップボードアイテム](#メインウィンドウとの間でのクリップボードアイテム)） |
| メイン画面のウィンドウ検索の結果 | 右クリック、ワークスペースへドラッグ | パスの無い単一アイテム（下記） |
| エクスプローラーのファイル・フォルダ、ブラウザの URL | ワークスペースへドラッグ | ファイル／フォルダ／アプリ／URL のアイテム |
| クリップボード | ワークスペースで `Ctrl+V` | 中身による（下記） |

ドラッグで追加したアイテムは、ドロップした場所のグループ（または未分類）に入ります。

### ウィンドウ検索の結果から追加したとき

- exe 名とタイトル全体を対象ウィンドウにした**パスの無い単一アイテム**（[アイテムの種別](./item-categories.md#単一アイテム)）になる。開くと、そのウィンドウが開いていれば切り替え、開いていなければ何も開かない。exe のパスは使わない（後でパスを入れれば、開いていないときに開ける）。ウィンドウそのもの（ハンドル）は覚えないので、閉じて開き直したウィンドウも見つかる
- 既定ではウィンドウ位置を記録しない（後でウィンドウを動かしたときに、勝手に元の場所へ戻るのを避けるため）。Ctrl を押しながらドロップするか、右クリックの「⭐ ウィンドウ位置も記録してワークスペースに追加」を選ぶと、今の位置と大きさも記録し、前面に出すたびにその場所へ戻す
- ブラウザのように表示中の内容でタイトルが変わるウィンドウは、後で見つからないことがある。アイテムを編集して、タイトルにワイルドカード（例: `* - Google Chrome`）を使う
- 複数のウィンドウの配置をまとめて再現したいときは、セットを使う（[セット](./set.md)）

### クリップボードから追加したとき

| クリップボードの中身 | 作られるアイテム |
| --- | --- |
| エクスプローラーでコピーしたファイル・フォルダ | ファイル／フォルダ／アプリのアイテム（アイコン付き） |
| URL（`http://`、`https://`、`ftp://`） | URL アイテム（ファビコンを自動取得） |
| カスタム URI（`obsidian://`、`ms-todo:`、`vscode://` 等） | カスタム URI アイテム |
| Windows のパス（`C:\...`、`\\server\...`、`shell:...`、`%APPDATA%\...`） | ファイル／フォルダ／アプリのアイテム。「パスのコピー」の引用符は外す |
| それ以外のテキスト（複数行を含む） | クリップボードアイテム（全文を保存。起動するとクリップボードに戻す） |
| 画像（スクリーンショット等） | クリップボードアイテム（画像を保存。起動するとクリップボードに戻す） |

- 入力欄の中でのペーストは、通常の文字入力として扱う
- パスは実在を確かめずに追加する（ネットワークパスの応答待ちを避けるため）。見つからないパスは、アイテム管理画面の「リンク切れの確認」で分かる
- 「TODO: 買い物」のように空白を含む文は、URI ではなくテキストとして扱う

## メインウィンドウへの登録

「ワークスペースに追加」の逆向きで、ワークスペースのアイテムをメインウィンドウのアイテム（データファイル）として登録できます。

- **操作**: アイテムをメインウィンドウへドラッグ&ドロップするか、アイテムの右クリックメニューの「🚀 メインウィンドウに登録」を選ぶ。すべての種別（通常アイテム・セット・クリップボード）でできる
- **登録画面**: アイテムを初期値にした登録画面（新規登録）を、メインウィンドウの子ウィンドウで開く。保存先はメインウィンドウで今選んでいるタブで、登録画面で変えられる。右クリックから選んだときは、先にメインウィンドウを表示する
- **元のアイテム**: ワークスペース側のアイテムはそのまま残る。登録したアイテムはコピーで、後でどちらを変えても、もう片方は変わらない
- **対象**: 1 つのアイテム単位。グループごとの登録や、メインウィンドウのタブの上にドロップして保存先を選ぶことはできない

## メインウィンドウとの間でのクリップボードアイテム

クリップボードアイテムの中身（保存データ）は、アイテムとは別のファイルに保存されています（[データファイル形式 3.5.3](../architecture/file-formats/data-format.md#353-データファイル)）。メインウィンドウとワークスペースの間でクリップボードアイテムを写すときは、どちらの向きでもこのファイルを複製し、写した先のアイテムは複製を指します。

- **メインウィンドウ → ワークスペース**（「⭐ ワークスペースに追加」・ドラッグ）: 追加するときに複製する
- **ワークスペース → メインウィンドウ**（「🚀 メインウィンドウに登録」・ドラッグ）: 登録画面で保存するときに複製する。登録画面でクリップボードを取り込み直したときは、取り込んだデータを使うので複製しない
- 元のファイルが無くて複製できないときは、元と同じファイルを指したまま写す

1 つのファイルを共有すると、メインウィンドウのアイテムを消したときにファイルも消え、ワークスペース側が復元できなくなるためです（以前はファイルを共有していた）。

## 切り離しウィンドウ

グループをワークスペースウィンドウの外へドラッグすると、そのグループ（子孫のサブグループとアイテムを含む）だけを表示する独立したウィンドウになります。

- 同じデータを表示するだけで、グループはワークスペースウィンドウにも残る。どちらで変更しても両方に反映する
- 📌 で「通常」「表示固定」「最前面固定」を切り替える。通常のものはメインウィンドウと一緒に隠したり、まとめて隠したりできる
- 位置・📌・折りたたみを覚えていて、アプリを終了したときに開いていたものは、次にワークスペースウィンドウを開いたときに開き直す。× で閉じたものは忘れる

## 絞り込み

ワークスペースウィンドウでは、グループ名・アイテム名の一部で表示を絞り込めます（大文字小文字を区別しない）。グループ名が一致したグループは、子孫のサブグループとアイテムも表示します。切り離しウィンドウでは使えません。

## 保存

- ワークスペース・グループ・アイテムは `workspace.json`、アーカイブは `workspace-archive.json`、折りたたみと切り離しウィンドウの位置は `workspace-ui-state.json` に保存する。追加・編集・削除・並べ替えのたびにすぐ保存する
- 形式と置き場所、読み込み・書き込みの仕組み（外部変更の検知・壊れていたときの扱い）は [ワークスペースファイル形式](../architecture/file-formats/workspace-format.md) を参照
- バックアップが有効なら、データファイルと同じく日次のスナップショットと外部変更前のスナップショットの対象になる。消えたデータは管理画面のスナップショット一覧から戻す

## ウィンドウの表示の設定

表示位置（ディスプレイの左端・右端・固定位置）、透過度、背景だけの透過、メイン画面を開いたときの自動表示、全仮想デスクトップへの表示は、管理画面の設定で変えます。項目と既定値は [設定ファイルの形式 - ワークスペース設定](../architecture/file-formats/settings-format.md#38-ワークスペース設定) を参照してください。

全仮想デスクトップに表示しない設定で、ワークスペースウィンドウを出したまま別のデスクトップへ移り、そこで表示を切り替える（または自動表示する）と、隠さずに今のデスクトップへ呼び寄せます。切り離しウィンドウは、表示するたびに全仮想デスクトップへの表示の設定を当て直すので、メインウィンドウと一緒に隠れて出し直しても設定どおりに表示します。
